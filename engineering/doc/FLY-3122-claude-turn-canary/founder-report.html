1 · 这次到底做什么

金丝雀（canary）是一项很小、隔离运行的探针，用来确认传输链路真的把任务送到了正确执行体。

TURN是服务器授予某个工作流节点的独占写入权；它只说明“这个节点现在可以写”，不提供 marker 内容。

marker是必须逐字匹配的一整行文字。它只能来自明确发给当前 execution 的 Lead instruction，不能从 issue title 或另一个 driver execution 推导。

当前事实：vendor=codex、phase=eng_design、TURN 返回 yours、mailbox 没有 marker instruction、probe.txt 不存在。

  1. 采用 TURN receipt + 条件式 marker。Design 记录自己真正收到的 TURN；只有当前 implement execution 收到 exact Lead instruction 才能写 probe。

  3. 拒绝 design 直接实现。Design review 必须挡在交付物变更前；probe.txt 归 implement node。
  4. 拒绝默认沿 tpl_code ship。Template 有 creates-PR / founder-gate / land，但 issue 明示 no shipping；Lead 必须先 re-route、cancel 或施加 no-PR/no-ship 限制。
