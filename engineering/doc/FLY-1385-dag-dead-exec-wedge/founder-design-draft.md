# 流水线卡死修复 — 设计稿(给 Annie 过目)
Issue: FLY-1385 (https://linear.app/geoforge3d/issue/FLY-1385/bugdag引擎-死-exec-永久楔死-node失败无-completion-receipt-teardown-held-node-卡)
日期: 2026-07-20
基于: plan.md(工程细节都在那里,这份只讲清楚三件事:之前怎么坏、现在怎么顶着、改后什么样)

## 一句话

昨晚两单(FLY-1335 / FLY-1356)的工人死在半路,流水线不但不换人重干,还把整条道锁死 1.5 小时,最后只能手工开数据库解锁。这次修:**普通意外死亡自动换人重试(最多 3 次),3 次都死就停下来喊人;额度/账单/登录问题不空烧重试,直接停下告警;并且给你和 Lead 一个正式的「停这条流水线」按钮,不用再动数据库。**

## 之前(怎么坏的)

```mermaid
flowchart TD
    A[工人(runner)干到一半死了<br/>—— 昨晚是因为 codex 额度用完] --> B[流水线没收到「完工回执」<br/>就把这次失败整个忽略掉]
    B --> C[台账上这一步永远显示「进行中」<br/>其实人早没了]
    C --> D[这单被锁死:不换人、不重试、<br/>新的开工请求也全被拒绝]
    D --> E[Lead 也没有任何按钮可按<br/>只能手工开数据库改状态]
    style D fill:#ffebe9
    style E fill:#ffebe9
```

更糟的是:昨晚重新开的两条新流水线,工人**又**死在同一个地方(codex 额度还是空的),又锁死了一遍。因为流水线开工时把「这一步必须用哪家模型」**焊死**在了配置快照里,额度用完也换不了。

## 现在(临时顶着的办法,不可持续)

- Lead 手工连数据库,把卡死的流水线改成「停下待裁」状态,才放开锁;
- 再手工重开一条新流水线 —— 但模型焊死的问题还在,新流水线照样死;
- 每次都是深夜人肉手术,没有审计、没有按钮、不能再来一次。

## 改后(这次要做成的样子)

```mermaid
flowchart TD
    A[工人死了] --> B[流水线每秒巡检一次:<br/>发现「台账写进行中、人已确认死亡」]
    B --> C[自动换新工人重干这一步<br/>(间隔 1/5/15 分钟,最多 3 次)]
    C -->|干成| OK[流水线继续走]
    C -->|3 次都死| HOLD[流水线自动停下 + 告警喊人<br/>(不再无声卡死)]
    style OK fill:#e6ffec
    style HOLD fill:#fff8e0
```

配套五件事:

1. **失败必留痕**:工人死亡的事件、原因,全部落进台账,不再被忽略。
2. **正式按钮**:Lead 可以一条命令「暂停」或「终结」任何一条流水线,自动留审计记录(谁、为什么、什么时候)——替代手工数据库手术。报错提示也会直接告诉操作者按哪个按钮。
3. **旁观账本不再锁道**:老式(非 DAG)任务的观察用影子记录,以后不再有资格锁住整条道(昨晚 FLY-1356 就是被它锁的)。
4. **换人重干不再误伤**:接手同一个工作目录时,允许「进度往前走过一点」的正常情况(昨晚 4 次重试全被这个过严的检查打死)。
5. **模型按当前配置开工,但不盲切**:流水线快照锁「工序形状」并保留一份模型兜底;**每一步开工时先读当前正式配置**,读不到就用快照兜底,紧急开关可直接回快照。额度/账单/登录问题默认停下告警,不自动乱换模型。唯一批准的自动替补是**设计这一步的 Fable 不可用时换 GPT-5.6**,同时告警;可替补名单只有 Fable / GPT-5.6,其他替换一律拒绝。

## 追加安全护栏(Annie 2026-07-21 裁定)

- 死 exec 自动恢复默认开启,但 `FLYWHEEL_ENGINE_DEAD_EXEC_SWEEP` 每轮现场读取；控制台改值后下一轮立即生效,不需要重启 Bridge。
- 每次判死并换人后继续盯住旧 execution。它如果又出现绑定到自身身份的 commit marker、session commit 或 CommDB 写入,系统会把它定性为已证实误判,同时通知 issue thread 与 Lead 升级链；tmux 是可能被替补复用的物理窗口,输出变化只记诊断日志、不单独触发升级。同一节点连续死人仍同样升级。
- watch 不会永久积累：所属 run 一结束就立即清理；run 仍 active 时最多保留 24 小时,每轮清理与探测都有限额。
- 探针或基线拿不准时宁可继续 hold,不在没有误判绊线的情况下换人。
