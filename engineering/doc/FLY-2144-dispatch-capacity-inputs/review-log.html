第 1 轮 · CHANGES REQUESTED BLOCKER 2 / HIGH 4 / MEDIUM 2

  • BLOCKERfail-soft 行为无法由当前类型和依赖合同表达。
  • BLOCKER“零豁免”残留守卫按计划会命中自己和计划新增的 build 命令。
  • HIGH损坏的 Claude quota store 会被伪装成健康的空账号池。
  • HIGH两套生效中的 Lead 规则对 `patrol_tick` 的权威性直接冲突。
  • HIGH内存解析器并没有实现 B5 所称的“只接受末行”。
  • MEDIUM容量采样放在 project loop 前会把“每次实际 patrol 事件一次”变成“每次 poll pass 一次”。
  • HIGHR8 的当前 sweep 清单不足以让 active tree 诚实归零。
  • MEDIUM`formatPatrolTick` 有两个独立 return 路径，计划的渲染步骤和测试没有明确同时覆盖。
