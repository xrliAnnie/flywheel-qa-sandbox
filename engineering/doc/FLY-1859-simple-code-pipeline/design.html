FLY-1859 「简单代码」两节点流水线 — 设计

Issue: FLY-1859 · 日期: 2026-08-18 · 设计节点交付 · 评审: Claude 独立交叉评审(R1→R2) + Antigravity 第二意见(Codex 今晚额度满,按 Tadashi 轮级政策以交叉评审收口)

1. 一句话总结

给「改代码的小活」新开一条两节点流水线 simple_code(实现 → QA,实现默认用 GPT-5.6、QA 默认用 Opus 5):一张 issue 里自己把活干完、自己验完、只给你一张审批卡;同时把 generic 还原成纯非代码工作 —— 单节点做完即止,系统不再自动另开 QA 单。

名词:「节点」= 流水线上的一个独立工序,每个工序由一个自动跑的 AI Runner 完成;「QA」= 独立于实现者的验证工序;「ship 卡 / 审批卡」= 最后请你批准合并的那张 Discord 卡片。

2. 今晚暴露的问题(你点名的那个「怪麻烦」)

现在改代码的小活跑在单节点 generic 上。系统给它配 QA 的方式是自动另开一张 QA·FLY-XXXX 新 issue、再起第二个 Runner —— 于是 Tadashi 得在两张 issue 之间人工衔接:把验收标准喂给 QA、盯凭据、代投报告。今晚的 FLY-1830 / 1852 / 1853 三张小活全是这个形态。

3. 新流水线长什么样

2026-08-19 founder 最终订正:implement 节点固定默认 Codex GPT-5.6,qa 节点固定默认 Claude Opus 5。下图内 Opus → Codex 的模型标签保留为本轮评审时方案记录,已由本订正取代;拓扑不变。

simple_code 把三段式里的「设计」工序压掉(小活不需要独立设计稿),保留「实现」和「独立 QA」两个工序,外加你已经熟悉的审批卡和自动合并:

  • 一张 issue、一张卡:QA 是流水线内的一个节点,不再另开 issue;账本不再分散。
  • 实现默认 GPT-5.6(2026-08-19 最终直令),Tadashi 派工时仍可在合法组合内改用其他模型。
  • QA 默认 Opus 5:系统有一条硬规则 —— 写代码的和验代码的不能是同一家厂商的模型(保证验证独立);实现用 Codex(OpenAI 家),QA 交给 Opus(Anthropic 家)。
  • QA 不过会自动打回实现重修(最多 3 轮,超限升级给 Tadashi),你打回也走同一条返工路。
  • 重活不受影响:需要独立设计的工程活仍走原三段式 code 流水线,行为一字不变。

4. 系统里怎么落地(结构模型)

流水线形状是一个 YAML 定义文件;Bridge(调度服务)启动时把它编译成模板、自动补齐派工映射;Tadashi 判档后一条命令派工;旧的「自动另开 QA 单」管线(FLY-579)从此只留给引擎外的旧式会话,引擎内的 run 一律不再触发。

名词:「引擎 / DAG 引擎」= 按流程图自动推进各节点的调度器(DAG = 有向无环图,即流程图);「模板」= 一种流水线形状的正式登记;「判档」= Tadashi 给每张 issue 选流水线档位。

5. Tadashi 以后怎么选(判档三档)

档位什么活走这里形状
保留code需要独立设计的重活:架构、跨模块、新机制、高风险改动设计 → 实现 → QA(三节点)
新增simple_code改代码但不需要设计稿:小 bug、局部重构、补测试、配置/脚本、按既有模式加小功能实现 → QA(两节点,实现默认 GPT-5.6、QA 默认 Opus 5)
回归本义generic纯非代码:调研、盘点、分析、一次性运维单节点,做完即止,无 QA

两条边界规则写进 Lead 规则:改代码的活永远不走 generic(再小也至少 simple_code);code 和 simple_code 拿不准就取 code(宁重勿漏)。

6. 关键取舍与被否掉的做法

取舍点选了否掉了 · 为什么
QA 归谁管QA 拓扑归流水线模板所有:模板里有 QA 节点才有 QA否继续用「自动另开 QA 单」给单节点活配 QA —— 正是你点名的协调成本来源
generic 去 QA 的做法从机制上把「引擎内的 run」整体摘出旧 auto-QA 触发面否靠 Lead 每次手工打 no-qa 标签 —— 靠人记不住,还是协调成本

副作用范围prd / design / prototype 单节点活也一并不再被挂 QA 单(和「非代码不用 QA」同一条原则)已在方案里明示为待你确认的假设 A3;若只想豁免 generic 也能收窄,代价是多一张白名单

7. 诚实边界 —— 这个设计做什么、不做什么

  • 做:新增 simple_code 档(含派工判档标准、implement 默认 GPT-5.6、qa 默认 Opus 5);generic / prd / design / prototype 不再自动开 QA 单;修一处「流水线第一个节点必须是设计」的旧假设。
