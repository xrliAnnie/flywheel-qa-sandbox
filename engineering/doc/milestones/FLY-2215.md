# FLY-2215 — publish-report 报告页泄漏收口

**Status**: ✅ Implementation complete; needs review
**PR**: pending creation from this milestone commit
**Date**: 2026-09-02

`publish-report` 现在按 tab id 的前后集合差回收 ProofShot 本轮创建的全部同 URL 报告页，覆盖 recording retry 遗留页，并严格执行「只收自己开的」：自起 browser 只关自己的整棵树；附着 shared browser 只在 preflight baseline 可信时逐 id 关闭本轮新增页，绝不猜 active tab、绝不因 recording cleanup 失败关闭别人的 browser。

## 交付内容

- 截图前用 `agent-browser session list --json` 判定 browser ownership；shared/unknown session 独立采集 tab baseline，避免 session probe 失败吞掉仍可用的 tab 证据。
- `proofshot start` 成功或失败后重新读取 tab，按稳定 id 差集并精确匹配本次 unguessable report URL，一次覆盖 open page、record page 与内部 retry page。
- cleanup 先 `agent-browser record stop`，失败时重试一次，再执行 page/browser cleanup；所有失败只 warning，不遮蔽既有截图降级与 link delivery。
- command-owned browser 直接整树 `close`，避免 agent-browser 拒绝关闭最后一个 tab；整树 close 失败时才回退逐 id 回收已证明归属本轮的 report tabs。
- shared browser 只在 baseline 可用时逐 id 关闭新增 report tabs；baseline 不可用时明确 warning 并跳过，不以潜在泄漏换取误关外来 tab。
- 没有修改 reaper、TMPDIR/owner 约定、Bridge、公共 CLI 参数、依赖、feature flag 或 `CLAUDE.md`。

## R2–R4 advisory 处置与已知项

- R2：owned browser 最后一页必然 close warning → 改为整树优先；record stop failure 会影响下一轮 → 加一次重试；preflight JSON 失败会丢截图 → 改为 warning 降级。
- R3：session probe 失败时空 baseline 会误关被 `open` 导航的外来 tab → session/tab probe 拆开；double-stop recovery 会关闭 shared browser → 禁止；owned whole close 失败无 fallback → 只对已证明自有的 ids 尽力回收。
- R4 LOW 已知项：shared tab baseline 不可用时，本轮 report page 可能残留。Lead 明确裁定宁可 warning + 漏关，也不能猜测归属并关别人的 tab；reviewer 标记 no code change required。后续可把 `skipping report tab cleanup` 与 `recording may remain active` warning 接入 ops alert，本单不扩 scope。

## 独立 QA handoff（同台架对照臂）

在同一隔离 host/browser harness 上分别跑 BEFORE 与 AFTER：

1. BEFORE 使用 `origin/main` 的 built `publish-report`，连续发布 3 份报告；AFTER 使用本 PR built bytes，同样连续发布 3 份。
2. 两组各包含一次人为让 2x screenshot 失败并触发 1x retry；逐轮记录全部 tab 数、本报告 URL tab 数与 Chrome `--type=renderer` 进程数。
3. AFTER 通过条件：每轮回到同一 report-tab baseline，tab 与 renderer 不随 N 单调增长，下一轮 ProofShot start 仍成功并能截图。
4. shared-session 阴性对照：测试前预置一个外来 tab，三轮后它仍存在且未被导航/关闭；同时验证本轮 report tabs 被关闭。
5. baseline probe 故障注入：确认截图继续、warning 可见、零 tab close 与零 whole-browser close；这是已知 fail-safe 取舍，不计作正常路径泄漏通过。
