# FLY-2352 — Codex 恢复使用 current workflow activation

## 交付

- `prepareCodexRecoveryCapabilities` 不再用只能处理单条 binding 的旧查询；它在恢复 claim 的同一事务内解析仍拥有 active run 最新 attempt 的唯一 current activation。rework 后保留多个历史 binding 的 Codex execution 因此会对当前 activation 轮换能力，而不再误降为 unenrolled 后撞 immutable launch snapshot 的 capability drift。
- current activation 为零个或多个时以 `activation_ambiguous` fail closed；pinned snapshot / node 分类损坏时以 `activation_invalid` fail closed。两条路径都在轮换凭据和写 recovery event 前退出。
- immutable launch capability guard 保留；异常现在同时打印 snapshot/current 两侧布尔值，既有 `workflow capability drift for ` 前缀不变。
