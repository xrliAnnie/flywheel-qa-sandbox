# FLY-2168 — 恢复 Codex 原生交互 TUI

**Status**: ⏳ Pending ship
**PR**: #998
**Date**: 2026-08-30

将 Codex runner 的 founder 窗口从被动 `tail -F` 事件流水恢复为原生
`codex resume --remote` 交互 TUI；窗口在同一 App Server、同一 owned thread 上重连，保留
machine client 对 `/goal` 的自动驱动、transcript audit、CommDB window pin、daemon restart
恢复和 fail-open 可见性合同。terminal/controlled shutdown 会主动收割 TUI，orphan reaper
则只把精确 App Server holder 当 survivor，不会被仍连接 socket 的 TUI client 误阻塞。

真实 tmux rejoin 证明窗口显示完整 Codex chrome、沿用 `workspace-write` / `never` policy，
且没有新增 root/fork rollout。针对性 159 项测试、全仓 lint/build 通过；全包并发中的既存
real-tmux/慢测 timeout 均在隔离复跑通过。完整 nested fresh-thread E2E 在当前 resident macOS
Codex sandbox 中早于 TUI 路径被 `sandbox-exec: Operation not permitted` 阻断，原始失败结果与
同 resident App Server 的 live rejoin 证据均随 PR 提交。

QA R1 后，真实机器验收脚本补上 `pretrustWorkspace: true`，避免新工作区被信任弹窗阻塞。
Codex sandbox 内的无效短任务尝试已原样披露；修复头上的 3 次 / 8 分钟短任务可靠性复验由
可运行真实机器验收的 QA 宿主接棒。
