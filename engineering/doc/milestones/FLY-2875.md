# FLY-2875 — 额度页加 Vercel 一块：报告托管号的档位、在用、下次扣费日、Blob 状态

**Status**: ⏳ Pending review, exact-head CI and QA
**PR**: 本分支的 FLY-2875 PR（创建时绑定）
**Date**: 2026-09-25

founder 2026-09-24 升级 personal 号到 Vercel Pro 做报告托管，要在「账号额度一览」上看到这个付费订阅。本单在 Codex 表下加一张 Vercel 表，行式样与 Claude/Codex 相同。

1. **在用号**：用 `.env` 里的 `REPORT_HOSTING_VERCEL_TOKEN` 只读 GET 三个接口：`/v2/user`、`/v2/teams/{defaultTeamId}`、`/v1/storage/stores/{注册表当前 store}`。只有当前托管 store 的 `ownerId` 等于这个号的 team 时才标「在用」并整行染绿。
2. **只显示别名**（Lead 裁定，沿用 FLY-2688 的不变量）：store 只存邮箱的 sha256，GET 时和 Claude 账号邮箱比对，对上就显示 `personal`，对不上就显示 Vercel username。页面上不出现邮箱。
3. **下次扣费日**：只有 Pro 才把账期结束日 `billing.period.end` 当作扣费日（现在是「10/24 周六」）。Hobby 写「不扣费（Hobby 免费）」；enterprise 和未知档位写「读不到（接口未给扣费日）」；已取消、非 active、没有账期、账期已过也各有固定的「读不到（原因）」。不猜日期。
4. **Blob**：显示正常 / 已超额 / 超额被停，外加已存大小和对象数。占比写「读不到（接口不给额度上限）」，因为 Pro 没有 Blob 额度上限字段。
5. **旧号**：本机没有 personal2（旧 Hobby 号）的 token，所以写死一行「Hobby · 已停用，不再使用」。
6. **失败降级**：接口失败时这一块显示「读不到（原因）」，不染绿，整页照常渲染。每次刷新先把本轮结果放进 Bridge 内存，再写 `~/.flywheel/vercel-quota/vercel-account.json`。写盘失败时删掉旧文件，所以旧的成功读数不会盖过本轮失败（设计评审 R1 BLOCKER）。
7. **token 不外泄**：token 只出现在 Authorization 头里；刷新失败只打印固定文案。响应字段里如果回显了 token（全文或前 8 个字符），reader 直接按 malformed 处理，不落盘也不渲染（代码评审 R1 HIGH）。测试检查 store、HTML、warn 输出中都没有 token 的前 8 个字符。
