Date: 2026-09-18
Issue: https://linear.app/geoforge3d/issue/FLY-2697
Status: PR #1254 has a formatter-only CI repair; new exact-head review and CI pending.

Adds a managed `preflight` / `execute` / `verify` wrapper around the existing
FLY-2619 historical migration. Execution is bound to an exact authorization
payload, deploy lock, database identity, explicit state root, source digests,
per-sequence dispositions, and S4-aligned auditable receipts. Completed rows
are read-only idempotent no-ops; non-`raya/raya` targets are rejected before
filesystem or database access. The existing updater migration path remains
unchanged.

Review round 1 exposed a v2 fallback asymmetry: a journal round without a
pre-admitted eligible row could be migrated to `needs_reconciliation` but then
rejected by the wrapper verifier. The verifier now preserves v2 eligibility
only for a current eligible/claimed row and independently classifies every
other row, with an end-to-end regression covering execute, receipt, and verify.
Round 2 completed the matrix for an operator decision that makes the fallback
v2 round eligible with non-null evidence: verification now independently
recomputes that decision-backed evidence while leaving admitted and claimed v2
semantics unchanged.

Review round 3 approved the behavior at `a42b59b95`. After the account-level
Actions outage was repaired, exact-head run `35314819668` reached real jobs and
Quick Gate exposed one Biome-only line-wrap error in the new regression test.
The formatter-prescribed wrap is the only subsequent code change; root lint,
35 focused tests, and teamlead typecheck pass locally.

Focused verification passed 35 gate/migration/store tests, teamlead typecheck,
root build and lint, 9 retention-consumer tests plus inventory audit, 40 updater
shell regressions, protected-path checks, and a compiled-dist digest smoke.
The unrelated aggregate failures seen under nine-runner host contention passed
20/20 in isolation. Per Lead's FLY-2467 ruling, the interrupted local full gate
was not restarted; exact-head CI is the aggregate authority.

This PR deploys code only. Merge does not authorize production execution. No
production database was accessed or migrated, and every production instance
still requires the separate founder authorization defined by FLY-2680 §11.1a.
