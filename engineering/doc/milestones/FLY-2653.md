# FLY-2653 — Raya cutover update recovery

**Status**: ⏳ Pending ship
**PR**: #1268
**Date**: 2026-09-18

Unblocks the Raya cutover path without weakening its ownership, persona,
quiet-window, canonical-manifest, or fast-forward guards. One-time migration
continues to deploy the founder-authorized SHA when it remains on current main;
standard updates bind their ledger and receipt to the actually deployed Raya
SHA; stale Flywheel/manifest pins fail before checkout, build, projection, or
Lead lifecycle work. A successful urgent Flywheel deploy now invokes the same
host-gated Raya pass as the scheduled cadence, while failed or indeterminate
urgent cycles remain zero-call.

Focused shell verification passed 21 prestop cases, 60 Raya deploy transaction
cases, and 41 updater-source cases. No production state was written, no service
was restarted, and this PR does not authorize deployment or cutover execution.
