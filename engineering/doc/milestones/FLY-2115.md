# FLY-2115 — land 授权不再依赖待删除 worktree

**Status**: ⏳ Pending ship
**PR**: #1065
**Date**: 2026-09-03

land 在核验 `founder_review` 时，`__main__` 绑定现在优先使用项目注册表中的主仓路径，
并继续把已冻结的 exact head 作为唯一授权 commit；只有仓路径求值抛错时才回退到绑定
worktree，明确的 negative verdict 不会被第二个根覆盖。两个根都不可用时会记录项目、run、
binding、候选路径及错误类型/消息，保留稳定的
`founder_review_authority_unavailable` 外部 reason。

该 unavailable reason 同时被归入 land retry 的 terminal hold：不再重复增加 retry count 或
安排下一次无意义重试，等待已有告警/人工恢复路径处理。改动没有触碰 gate、claim、
approval 写入，也没有修改 `close-runner.ts` 或 `post-ship-finalization.ts`。

验证覆盖已删除 worktree、主仓优先、合法回退、明确拒绝不被翻转、stale artifact、双根失败
诊断及非 main 兼容路径；目标套件 72/72 通过，两组 mutation control 均按预期变红。
`pnpm lint` 与 `pnpm -r build` 通过。`pnpm test:packages:run` 在本机无头环境进入 teamlead
后由 5 个非本单测试失败收尾；merge-base 对照在相同的 StructuredInboxRouter 与两条
createLeadRuntime preflight 满载用例上复现，同时隔离四文件 47/47 通过，证明这些结果受
满载/共享环境影响。完整逐项证据保存在 PR 的“本单未修的既有基线失败”小节。
