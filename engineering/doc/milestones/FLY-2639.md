# FLY-2639 — Mobile-safe Epic page Discord links

**Status**: ⏳ Pending ship
**PR**: #1236
**Date**: 2026-09-17

Epic progress pages now render the primary action for child threads, attention cards, Lead issue rows, and judgment-history cards with the canonical `https://discord.com/channels/...` URL. That default remains usable when JavaScript is disabled and lets mobile browsers, including Discord's iOS WebView, use the platform universal link.

A compact inline script bearing the existing CSP nonce upgrades those primary links to `discord://-/channels/...` only for known desktop Chrome and Safari clients. iOS Safari, Discord iOS WebView, Android, iPadOS desktop-mode, unknown clients, and no-script rendering retain HTTPS. The adjacent “网页版” link remains unchanged, and static Markdown/history output stays HTTPS-only.

Verification covers the rendered HTTPS default, no-script usability, the real nonce script across the mobile/desktop UA matrix, hostile noncanonical URLs, and the hosted-page byte ceiling. Focused Epic suites passed; lint and recursive build passed.
