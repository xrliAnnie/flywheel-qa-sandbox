# FLY-2245 — CI 文档分类与脚本测试分片

**Status**: ⏳ Implementation complete; pending review
**PR**: [#1026](https://github.com/xrliAnnie/flywheel/pull/1026)
**Date**: 2026-09-01

`engineering/doc/**` 下的普通 tracked file 现在按目录语义分类为 inert，不再因为 `.sh`、`.py`、
`.js`、`.json`、`.yaml`、无扩展名或 100755 mode 自动触发重车道。分类器仍对 symlink/gitlink、
目录外文件、其他 doc root 的非白名单后缀和 Git 不确定状态 fail closed；全仓 consumer sweep 找出的
5 个 no-code-gated 机器输入进入精确 fence，FLY-1278 fixture JSON 与真实 consumer 顺序保持 exact
parity。FLY-1987/2074 的机器输入继续由 always-on quick gate 验证，不需要重车道 fence。

原两条 Script Tests 拆为四条 required shard，当前 76 个 named test step 按 19/25/31/1 分布且
每条只出现一次。四片保留 `timeout-minutes: 20`、首步真实计时、末步 `if: always()` 的
FLY-1870 `--threshold-pct 85` tripwire，以及同一 dependency/setup contract；只有包含 FLY-2007
历史 commit 检查的 1/4 保留 full checkout，其余使用 shallow checkout。`ci-ok` 同时等待四片，
只有 classifier 明确给出 `no_code=true` 才接受 heavy job skipped。

## 容量与保护语义

基于 2026-09-01 六轮 GitHub Actions step timestamps，每个 step 取最大值并统一加 149 秒最大
公共开销，四片投影为 624/605/626/633 秒，即 FLY-1870 1020 秒预算的
61.2%/59.3%/61.4%/62.1%，均低于 714 秒验收线。没有提高 cap、threshold，没有删减、
条件化或缩短 suite。最终以本 PR exact head 的四个 job elapsed 为权威证据；若 FLY-1364 独占片
仍受慢 VM 影响超线，获批计划已预写保持 22 条命令 exactly-once 的第五片 fallback。
