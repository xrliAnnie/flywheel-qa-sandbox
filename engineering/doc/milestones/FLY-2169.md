# FLY-2169 — socket Codex runner 在 cmux 可见

**Status**: ⏳ Pending ship
**PR**: #992
**Date**: 2026-08-29

为 socket-hosted Codex runner 增加了 founder 可直接点开的 canonical tmux observer window:
Bridge 将 app-server 的 thread/turn/item/goal 通知经过终端控制序列清洗后写入每个 execution 的
durable transcript,窗口只做被动 `tail -F`;CommDB 同步记录真实 `session:@window-id`,窗口随 runner
生命周期保留现场或按既有 close 规则收束。实现同时补齐了失败隔离、背压、rotation、nested thread
归属、unscoped goal 标记和真实 tmux capture 验收。

为避免 socket runner 的 app-server 在 crash 后成为长期孤儿,Bridge maintenance 新增双轴清理:
只有 canonical CODEX_HOME、精确 argv/socket、fresh `lsof` holder、稳定 pgid、PPID=1 且超过两小时
全部成立时才允许 TERM/KILL,并在进程组与 socket holder 都消失后才 unlink。R2 跨模型 code review
已 APPROVED;lint、全仓 build、两个 package typecheck、100 个 Codex transcript/adapter 测试和 16 个
orphan reaper 测试通过,并在真实 `runner-flywheel` tmux session 中捕获到实时实现输出。
