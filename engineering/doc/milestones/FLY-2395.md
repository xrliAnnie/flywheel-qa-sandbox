# FLY-2395 — docs-only 判定覆盖全部 target repo

**Status**: ⏳ Implementation complete; final exact-head code review pending at freeze
**PR**: https://github.com/xrliAnnie/flywheel/pull/1108
**Date**: 2026-09-06

docs-only 现在按一单的完整 PR 集合判定：主仓 PR 与节点声明的每个 nested target-repo PR 都必须取得
classifier v2 快照、全部文件都位于既有 6 个文档前缀、且合计文件数不超过 `MAX_DOCS_ONLY_FILES`。
任一快照缺失、过期、版本不匹配或分类失败都会令整单 `unknown`，不会获得 docs-only 豁免。

实现新增按 repository/PR/head 定位的 `ship_relevant_pr_snapshot`，以及只承载分类证据的
`ship_relevant_declared_pr`。后者由 generalized node 通过 `complete --declare-pr <target>:<pr>` 原子写入，
服务端在落库前解析 target-repo authority 并冻结真实 GitHub head；没有复用 landing/merge manifest，也没有
修改 `workflow_node_pr_binding` 的授权主键。两张表均登记为 `protectedCurrentOrReference`，不在 retention
deleteTarget 中。历史 classifier v1 行保持不动，由版本提升自然失效。

GatePoller 在既有节拍中以批次、并发、单次 deadline 与 rolling-hour process budget 刷新完整 PR 集合；所有
repo-qualified GitHub API 请求共享绑定到稳定 project root 的 client。`review-hold.ts` 消费聚合结果，因此
主仓 docs-only 加 nested 代码会继续 hold，只有完整集合都确认 docs-only 才释放。
