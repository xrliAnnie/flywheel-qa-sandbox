# FLY-2045 — 里程碑账本从 CLAUDE.md 搬进 per-issue 文件

**Status**: ⏳ Pending ship
**PR**: #947
**Date**: 2026-08-25

`CLAUDE.md` 的里程碑表要求每个 PR 在**表头正下方**插一行,于是两个并行分支从同一 base 切出后,
都在**同一个 hunk 的同一位置**做加性修改 —— **冲突率 100%,不是偶尔**。而 PR 一旦冲突,
GitHub 算不出 merge commit,`pull_request` 工作流**根本不排队**,分支**失去 CI 能力**,
QA 硬门变得不可测量。实测:最近 5 个带里程碑的 merge 全部落在同一 hunk(`@@ -38..39,6 +38..39,7 @@`),
最近 40 次改动里 38 次是纯加性,这张表占 `CLAUDE.md` 的 **93.9%**(172,521 / 183,740 字节,量于 cutover source `origin/main@6978e2ee9`;
搬迁草稿开始时是 167,009 / 178,228 = 93.7%,期间旧表又被合进两行)。

**做法**:历史 179 条**逐字节**搬进 `engineering/doc/milestones/ARCHIVE-pre-FLY-2045.md` 并冻结,
从 `CLAUDE.md` **删净**(183.7 KB → 11.8 KB,每个 session 少装载 172 KB);新里程碑改成**一 issue 一文件**。
两个 PR 各建**不同路径**的新文件 —— 不是「冲突概率低」,是**没有可冲突的对象**。

**实测排除的两个候选**(`merge-evidence.md` / `cutover-merge-probe.sh` 可复跑,自带控制组):
issue 原文提的「**追加到表底部**」实测**同样 100% 冲突**(两边都在 EOF 追加,与顶部插入同构,
与「是否同刻」无关);`merge=union` 能合,但会**静默保留两条互相矛盾的规则**且不报冲突 ——
`CLAUDE.md` 同时是全项目指令文件,不能接受这个失败模式。

**零丢失怎么证**:archive 的哨兵之间有 **sha256 + 字节数双 pin**,而且 pin 的权威由
`scripts/fly2045-pin-archive.sh` **绑定 `origin/main` 的实际 SHA**(先 fetch、断言等于 origin/main、
断言是 HEAD 祖先、验证 block 完整性,再 `cmp`,一致才盖章)。**不能拿搬完的结果给自己盖章** ——
那只证明「它和自己一致」,证不了「相对权威 main 零丢失」。

**写入面只改 Flywheel 专属的**:`engineer-executor.md`、`spin.md` 的两个 flywheel 说明块、
`orchestrator.md` 的 A0/F。`spin.md:359` 位于 **non-Flywheel generic path**,其它仓库仍靠自己的
`CLAUDE.md` 表 —— **一字不动**,守卫还正向锚住它。`orchestrator.md` A0 改为**幂等 ensure**:
base 里已有 ⇒ fail(canonical ID 撞车);本分支自己刚加的 ⇒ 校验后 handoff、**绝不覆盖**;
两者皆无 ⇒ 补建并 `git add`(它的 commit 闸是 `git diff --cached`,不 add 就永远进不了 PR)。
Flywheel 判定按 **repo** 而不是 issue 前缀 —— Flywheel 的历史有一部分在 GEO team 下。

**cutover 分两阶段**:B 删整块、旧 writer 往块里插行 ⇒ modify/delete 冲突,所以旧 PR 在 B 落地后
**必然 DIRTY、合不进去**(这是机制,不是承诺)。ship 前只要求逐条**已分类并被 fence**;
ship 后逐条迁移并各自取得新守卫下的 exact-head green,**全部完成前本单不算 Done**。
`unrelated CLAUDE edit` 若完全在被删块之外**可能干净合入、不受 fence 保护**,须单独 disposition。

**顺带记两件**:① 设计评审 17 轮,前 15 轮对抗性打验证脚本,第 16 轮换成**纯计划级**评审,
当场抓出三个前 15 轮没碰到的**计划自相矛盾**(其中一个会让正常交付必然失败,另一个会让验收闸跑在错误产物上)
—— 对抗性探测会把注意力锁在最近改过的那个东西上;② 同一轮指出验证装置已大于它保护的迁移,
已裁掉重复证明同一谓词的那一层,**承重检查一条没减**。
