## Note on `pnpm-lock.yaml`

The sandbox worktree had no `node_modules`, so `pnpm --filter … install --offline` was required to
obtain `vitest`. That install revealed that `packages/runner-test-discipline-fixture/package.json`
had been added to the workspace **without** a matching `pnpm-lock.yaml` importer entry.

This was first judged an unrelated pre-existing gap and reverted to keep the diff scoped. CI on the
PR head then failed both jobs at `pnpm install --frozen-lockfile` with `ERR_PNPM_OUTDATED_LOCKFILE`
before any test could run, so the entry is genuinely required and was restored in
`fix(FLY-2853): add missing fixture importer entry to pnpm-lock.yaml`. It pins the already-resolved
vitest 3.2.4 and adds nothing else; `pnpm install --frozen-lockfile` then exits 0 locally.
