## 交付

- Bridge 新增受 master bearer 保护的只读 `GET /api/workflow/menu-policies`，直接从
  `.flywheel/agents/registry.yaml` 的 graph policies 投影每个 taskCategory / template / node 的
  canonical `{vendor, model, effort}` 集合、alias、默认 effort 与安全来源；未配置 master token 时明确
  返回 503。
- 管理台 DAG 节点按精确 `(taskCategory, templateId, nodeId)` 绑定同一份 shape policy。型号与 effort
  下拉只提供该节点允许项，并显示 registry fragment 来源；历史 `*` binding 保持既有行为。
- 具名 shape 缺失、template 漂移、node 缺失或 registry 解析失败时，当前值仍可见，但节点 fail-closed
  为只读且 writer preflight 拒绝。已持久化的越界 model/provider/effort 或空 effort 只作为 disabled
  marker 如实显示，不会伪装成首个合法值。
- provider/model change handler 从同一 policy 选择 alias 与 default effort；合法 `max` effort 可发布，
  canonical/alias 等价重选仍为 no-op，不制造 revision、publication 或 ownership 变化。
