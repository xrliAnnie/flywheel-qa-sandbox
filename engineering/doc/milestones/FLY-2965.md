① restart 的「非生产 tmux 残留只读审计」把任何 ppid=1、名字像 tmux 的进程持有的 Unix socket
都当成 tmux server 去 `tmux -S <path> list-sessions`,撞上了 cmux app 的换行 JSON 控制 socket;
该审计没有任何部署/回滚授权,整段连同其保留名告警与 allowlist 旋钮一起退役(旋钮墓碑化)。

对端不放手时杀掉客户端也结束不了 probe。改为匿名 0600 文件捕获、以受管子进程被回收为结束、
按回收瞬间的固定长度 pread 回放;捕获/启动等基础设施故障统一 125(不再冒充 has-session 的「不存在」)。
