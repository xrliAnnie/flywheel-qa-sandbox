# FLY-2269 — visual-capture Chrome 泄漏收口

**Status**: ✅ Implementation complete; needs review
**PR**: pending creation from this milestone commit
**Date**: 2026-09-03

`visual-capture` 现在即使 `proofshot start` 失败，也会进入按 ownership 证据约束的清理路径；所有直接 `agent-browser` 子进程统一受 15 秒上限保护。清理遵守「只收自己开的」：附着共享 session 只关闭可信前后快照差集中的本轮 tab，自起 session 才允许整树关闭，ownership 探针失败则继续截图并明确 warning，绝不猜测后关闭外来资源。

## 交付内容

- 在 start 前后读取 `agent-browser session list --json`，并冻结 start 前 tab baseline；shared session 只按稳定 tab id 的 post-minus-pre 差集关闭本轮新增页，外来 tab 保持存活。
- start 前 session 不存在时按 bootstrap ownership 处理；只有 post membership 证明本次创建了目标 session，才执行整树 `close`，失败时回退关闭已经证明归属本轮的稳定 tab id。
- session/tab 探针异常或 malformed JSON 统一降级为 ownership unknown：capture 主路径继续，清理只 warning，不执行 tab close 或 whole-browser close。
- `record stop` 只在 start 已返回且 post membership 存在时执行，失败重试一次；删除了会重入 session 生命周期的 `proofshot stop`。
- 新增共享 `defaultRunAgentBrowser`，JSON 与非 JSON 调用都使用固定 `15_000ms` timeout，并把同一显式 env/cwd 传给 ProofShot 和所有直接 agent-browser 调用。
- ProofShot 使用项目 cwd 启动并写入独立绝对 session root；只接受本轮新鲜、真实、非 symlink 的 `.session.json.sessionDir`，递归发现该目录内工件，零 PNG 时显式失败。
- 仅清理由本命令新建的 `.session.json` 与兼容 config；拒绝 stale/malformed/outside/symlink session state，保留调用方已有配置。
- 没有修改公共 CLI 旋钮、Bridge/Lead 服务、reaper、依赖、secret 或 `CLAUDE.md`。

## 独立 QA handoff（同台架 BEFORE/AFTER）

在同一隔离 host/browser harness 上分别验证 `origin/main` 与本 PR built bytes：

1. 每组连续运行至少 3 轮 visual capture，其中一轮注入 `proofshot start` 失败；逐轮记录 tab 总数、目标 session tab 数与 Chrome `--type=renderer` 进程数。
2. AFTER 通过条件：每轮回到同一 baseline，tab 与 renderer 不随 N 增长；对已获清理授权的常规失败轮，下一轮 start 仍成功并产出非空 PNG。post membership unknown 的歧义臂按第 5 项单独判定。
3. shared-session 阴性对照：预置一个外来 tab，完成所有轮次后它仍存在且未被导航/关闭；本轮新增 tab 均按 id 回收。
4. bootstrap 对照：start 前目标 session 不存在、start 后存在时，确认整棵自起 browser 被关闭；whole-close 失败时只回退本轮已证明 tab。
5. probe-failure 对照：pre probe unknown 时确认 capture/manifest 继续、warning 可见、零 tab/browser close；若 post 明确 present 且 start 已返回，record stop 仍执行。post probe unknown 的歧义臂确认零 tab/record/whole close，并记录残留状态与 owner-confirmed 隔离恢复路径；该臂不要求清理前下一轮 start 成功。另测 start-before-open 且 post absent 时全程零 tab 命令。
6. timeout 对照：令 agent-browser 调用挂起，确认单次在固定 15 秒附近退出，不再出现约 2 分钟单次卡住；逐次记录正常 session/tab probe elapsed、最大值及其与 15 秒的比值，若最大值超过 5 秒则说明仍保留 15 秒常量的依据与误超时风险。
7. 至少一轮通过 UI `--run` 真正启动 dev server，证明 ProofShot 从含项目 metadata 的项目 cwd 执行；同一 outputDir 连跑两轮时，第二轮 manifest 不含第一轮 sessionDir 路径。
