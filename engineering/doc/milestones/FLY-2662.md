`flywheel-comm land reclose` 现在能接回部署前遗留的 held/partial closeout：事务内从不可伪造的持久事实重建 `targets = NULL` 的目标快照，绑定精确 merge SHA，并继续执行“执行体确认 gone → worktree 清理 → 记录关闭 → thread 归档 → Linear Done”的既有顺序。`runner-*:pending` 不再永久等同于身份待定；只有 marker、窗口、进程树和 daemon 四路受限探针都证明不存在时才判 gone，任一路活体或不可完整枚举仍 fail-closed。真实旧形状 fixture 同时覆盖 NULL targets、`:pending`、held retry exhaustion 与下一 dispatcher tick，sandbox replay 为 5/5 通过且不写生产库。

手动正门不再接受共享 master token 单独授权。Codex 路径绑定当前 capability token、activation、owner instance 与 generation；Claude 路径由 Darwin Node-API 模块持有 Unix listener/accepted FD，并用内核 peer PID、audit token、pidversion、process start 与父进程 incarnation 在准备前和提交前双重校验。native 构建是可选且 fail-closed 的：目标 Darwin 从源码真实构建，缺工具链、非 Darwin 或故意失败只令 Claude reclose 返回 `peer_adapter_unavailable`，不阻断 Bridge 或其它 closeout 路径。`pnpm pack` 的发布 tarball 已核实包含 `dist/native/reclose-peer-darwin-arm64.node`。

2616 复审留下的收口项一并落地：非 land run 不再被扩进裸 finalize inventory；shipped husk claim 带 owner instance；窗口探针补 exec marker/process-tree discovery；CommDB identity revision 改为单调 epoch；owner heartbeat 增加 progress health 去重告警；围栏 owner 不再发送 retry；replay 在 thread archive 前校验 owner/generation/lease；closeout attribution 变化会升版并强制重建目标；NULL-target existing operation 可被正门恢复；finalization 不再借同 issue sibling session；closeout-only 身份不再写死；请求 replay 绑定 merge SHA。realpath/stat 与 host-process probe 错误也保留 typed fail-closed 分类，owner deadline 使用统一持久计划。
