# FLY-2758 — Raya 割接 bootstrap EIO：等 label 离开 launchd 再 bootstrap，失败必恢复标准 Lead

**Status**: ⏳ Pending effective code review and exact-head CI
**Date**: 2026-09-22

三班 Raya 班车（09-19 00:09、09-21 00:07、09-21 19:56）都在 15 项 preflight
全 PASS 之后死在同一处：`flywheel-lead.sh install` 对刚被 restart 窗口拉起的
`com.flywheel.lead.raya-raya` 先 `launchctl bootout`、紧接着 `launchctl
bootstrap` 同一 label。launchd 此时还在 teardown（Codex TUI Lead 收 SIGTERM 后
要关 TUI 窗口和 daemon），于是回 `Bootstrap failed: 5: Input/output error`。
`raya_fail` 只写回执和告警，没有任何恢复动作；旧壳 brain/voice 早在 P2 按授权
disable（brain 自 09-04 起就因 ENOSPC 没在跑），标准 Lead 又被 bootout 卸掉，
Raya 于是「谁都不在」，直到下一次 restart 窗口再拉起 2 分钟、再被班车杀掉。

修法两处，不改 P0–P7 状态机、v2 回执 key 集合或 shuttle-reasons 注册表：

* `scripts/lib/supervisor.sh:_sup_darwin_install` 在 bootout 后轮询
  `launchctl print` 直到 launchd 报 `Could not find service`（默认 40×1s，
  大于 20s ExitTimeOut），再 bootstrap，bootstrap 失败有界重试（默认 5 次）。
  三个调节量 `FLYWHEEL_SUPERVISOR_BOOTOUT_WAIT_ATTEMPTS` /
  `FLYWHEEL_SUPERVISOR_BOOTSTRAP_ATTEMPTS` /
  `FLYWHEEL_SUPERVISOR_LAUNCHD_POLL_INTERVAL` 登记进 feature-flags truth 的
  非开关清单。所有走 `install` 的 Lead 同时受益。
* `scripts/lib/updater-raya-deploy.sh` P4b 两臂的 `install` 失败后调用
  `raya_recover_standard_lead_after_install_failure`：Lead 仍 live → 不动
  （`not_needed`）；不 live → 用同一 public `install` 拉回并按既有 30×2s 等
  live（`restored` / `not_restored`）。`raya_fail` 据此写 `rolled_back` 或
  `failed` 回执，告警正文明确写「已恢复，Raya 仍可对话」或「未恢复，Raya
  OFFLINE」，updater 日志同步一行 recovery state。账本不写
  `lead_restart_installed_at`，下一班仍走 verify live → install。

验证：`supervisor.test.sh` 新增 S8–S11（状态化 launchctl 桩：等到 label 消失才
bootstrap、等待有界、重试有界、非法调节量回退默认）；
`updater-raya-deploy.test.sh` 60 → 75 用例，覆盖 preexisting/fresh 两臂的
install 失败三态、恢复后下一班只 install 一次、以及 `updater_raya_pass` 级的
回执 outcome 与告警正文；`flywheel-lead.test.sh` 与 `packaged-seams.test.sh`
的 launchctl 桩改为 bootout 后 absent。新增 Darwin-only
`fly2758-launchd-install-real.test.sh` 用隔离 label
`com.flywheel.fly2758-eio-probe-<pid>` 在本机真实 launchd 上复现了竞争
（bootout 后立即 bootstrap → rc=5 EIO），并证明修复后的 install 在运行中的服务
上 5 秒内换出新 pid、无 EIO、清理后 label 不残留。config 包
feature-flags drift/registry/truth 109 用例通过，`pnpm lint` 通过。
