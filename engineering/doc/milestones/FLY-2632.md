Founder 首次批准现绑定同一 issue 的文件集与逐 hunk 内容指纹，而不是永久绑定旧 head。land 准备可并行刷新到最新 main，自动冲突无法处理时才派只解冲突的返工体；精确新头 CI 与独立复审通过、非冲突 hunk 和文件集未变、原 founder gate 有效且 QA 证据可安全沿用时，系统记录 `approval_carried_from` / `qa_carried_from` 并以签名、单次消费的 merge ticket 进入既有最终 land。冲突解决触及非测试代码会重跑 QA，任何内容或权威证明不满足都会回到重新立卡路径。只有最终合入 main 的步骤按仓库串行，其他待 land 项在每次合入后重新检查可合性；轮数上限仍由 `engine_land_rework_cycle_limit` fail closed 并产生 Lead 可读告警。

实现以 FLY-2632 聚焦回归及安全路径回归红绿覆盖；首轮且唯一一次全包门暴露的环境变量登记、retention 分类、workflow timeout 断言与规则 bundle 黄金夹具漂移均已修复，相关 5 组单文件复跑共 60/60 通过，Bridge 启动夹具单跑 13.16 秒通过，确认 aggregate 的 15 秒失败为宿主争用。lint、全仓 build 在实现头通过，契约修复后的 config、edge-worker、teamlead 三个受影响包也分别 build 通过；最终代码评审与 CI 以本里程碑提交所在的精确 head 为准。

代码复审 round 1 的两个 HIGH 已修复：冲突限定 implement/QA 持有 `current_step=conflict_resolution` 时 land sweep 不再领取或推进其 generation；签名评论尚未投递、评论缺席已证明、或 workflow 已明确失败且未合入时，Bridge 会重新核当前 founder/CI/review/QA 权威后签发新 nonce，成功合入、在途或无法证明无副作用的票据仍不可重用。新增回归先分别在 sweep 领取与 ticket reset/reissue 处红，再转绿；FLY-2632 六个相关文件最终 107/107 通过，TeamLead build 与 changed-file formatter/lint 通过。仓库级 `pnpm lint` 本轮仍因本分支未修改的历史文件诊断退出 1，不把该结果记作 green；精确新头 aggregate 以 GitHub CI 为准。
