# FLY-2339 — delivery maintenance 单次同步工作有界化

**Status**: ⏳ Base-refresh rework complete; fresh exact-head code review pending
**PR**: https://github.com/xrliAnnie/flywheel/pull/1089
**Date**: 2026-09-04

Bridge 的 delivery-contract projector、watch 与 operations 维护链现按 64 行 keyset 页运行，每页都在独立
`delivery-contract:*` marker 内完成并在页间让出 event loop；游标必须严格前进，单次 drain 最多 10,000 页。
投影器使用每轮 drain 内存去重，StateStore 与 CommDB 查询获得与筛选/排序一致的索引，避免历史规模增长时
在主线程执行无界全表扫描。没有修改 EventLoopGuard 阈值，也没有新增告警层或生产表。
