1. **读法**（`claude-quota/charge-receipt-*`）：Bridge 用 gog 按号先只取元数据检索 Anthropic 收据与订阅通知，按精确发件人地址和锚定主题过滤，再只对决定本期的收据（每号至多 6 封）用 `gmail get --select=body,headers.from,headers.subject` 取正文，解析 `Paid`、本期起止、`Amount paid`。正文只在内存里用完即丢。
2. **只存字段**：`~/.flywheel/claude-quota/charge-receipts.json`，封闭 schema（读写共用一个校验器，写前自检，0600），装不下主题、发件人、收据号、邮箱地址或正文；日志只有号名、计数、枚举码。
3. **判定**：最新订阅收据的本期结束日 = 下次扣费日；之后有取消邮件且没有更晚的重订邮件 → 「已取消 · 到期日」；OAuth 明细在最新收据后读到 canceled 也算取消。较新的明细 active 不清掉取消邮件（Stripe 期末取消到期前仍是 active）。免费号只看当前明细套餐。
4. **失败闭合**：检索按 `nextPageToken` 至多翻 3 页，翻不完、信封损坏、正文预算用完都写明原因，不冒充「没有收据」；同周期没读全就不展示金额。读不到写真实原因（未授权 gog / 授权失效 invalid_grant / 没找到收据 / 格式没认出 / 超时…）；48 小时内沿用上次读数并注明。邮箱改绑后旧读数不再显示。
5. **频率**：每天至少一次（GatePoller tick，扣费日次日 00:05 太平洋时间再补读一次），FLY-2830 切号全量刷新时作为第三条独立的腿顺带读，页面按需刷新也读。
6. **页面**：Claude「下次扣费日」格显示 `10/16 周五` + `本期 9/16–10/16 · 已付 $200.01` + 「收据读于 HH:MM」；切号标记改用收据读取时间。
