本地 `pnpm test:packages:run` 现在有一个默认关闭、可即时启停的主机级 FIFO 信号量。启用后，调用先写入 SQLite 权威账本并持有 per-request owner flock；容量默认 2，实际启用值由主机校准后写入 control。拿不到名额时 pane 会持续打印“等待第 k 位 / 前面 n 个 / 已等 s / 运行 x/N”，同时生成只读 `ledger.json`。工作进程在独立 process group 中运行；supervisor 消失后，由独立 lifeline watcher 清理孤儿组，只有 owner lock 已释放且 PGID 返回 ESRCH 才回收 occupied 名额。正常结束也会 TERM → 宽限 → KILL 清掉残留后再释放。CI、显式 env 回退和 host control disabled 均走既有 core，并打印可见 bypass 原因；本 PR 不启用主机控制、不重启服务。
