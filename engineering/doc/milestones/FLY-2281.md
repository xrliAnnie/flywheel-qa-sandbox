## 交付

launchd watcher 过去看不到 FLY-2264 已持久化到 `.env` 的
`FLYWHEEL_CMUX_ATTACH_TMUX_BIN`，因此生成的 cmux `processTitle` 没有携带原生 tmux
二进制身份。workspace 即使仍有活 tmux client 和 Codex 进程，birth census 也无法从持久化命令
稳定恢复 workspace UUID、surface UUID、kind、target 与 token；既有精确授权链缺证时，
`title_source_authorized` 正确 fail-closed 为 topology proof refused，进而形成 row/receipt false-dead
与重复重建循环。

实现提交 `bbf4ee6bb` 让 watcher 通过现有单-key `.env` parser 读取 inherited-first 配置，并在每个
bootstrap/additive/once/converge/verify pass 固化一个受校验 snapshot。command builder、历史
variants、普通 carrier classifier 与 birth-record classifier 四个 consumer 共用该身份；有效 pin
进入新 surface 的 immutable `processTitle`。相对路径、不可执行路径、单引号/CR/LF 均 fail-closed，
日志与告警只暴露 reason 和 value hash；恢复后重新 armed。历史 unpinned view 与 private Lead
grammar 保持可解析。

本单没有修改 `title_source_authorized`、receipt/UUID/CAS guard、verifier verdict、helper、launchd
plist 或生产状态，也没有 restart watcher、close/rebuild live workspace、deploy、merge 或 dispatch QA。
