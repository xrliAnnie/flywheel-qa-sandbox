# FLY-2164 — 让 529 残留 fixture 不再卡死 step 2

**Status**: ⏳ Pending ship
**PR**: #1005
**Date**: 2026-08-31

generalized 529 stub 的 design fixture 现在带 run / execution 身份标记：同一次执行重入仍保持
幂等，不同 run 或 replacement 则必然生成不同字节，因此共享 `qa-sandbox` main 上即使残留旧
FLY-202 fixture，也不会再让 design 提交塌成空区间。driver 同时会监测当前未完成节点的
stub fatal；确认当前执行体已死后，先写 `diagnosed_stub_fatal` step evidence，再输出明确分类与
整改提示并以独立退出码 21 结束，不再静默等待 15 分钟通用超时。生产 FLY-1404 闸、real-runner
路径、step 2 的 512 KB 独立问题与 FLY-2158 step 8 A3 均保持原边界。
