# FLY-2644 — voice launchd 顶层 state 识别

**Status**: ⏳ Pending ship
**PR**: [#1228](https://github.com/xrliAnnie/flywheel/pull/1228)
**Date**: 2026-09-16

`install-voice-launchd.sh` 现在只从唯一的顶层 `state` 字段判断 voice job 是否 running，不再被 `launchctl print` 两处嵌套 `state = active` 误伤；path、program、arguments、PID 与条件回滚保护保持原样。真实层级夹具覆盖顶层 running 加两行嵌套 active，并以“顶层非 running、正 PID、嵌套 running”证明不会错误取用嵌套状态。

本 PR 未执行生产安装、bootstrap、bootout、部署、重启或真实语音房间验证。合入与标准 updater 部署后，仍需在独立授权窗口重跑安装器并读取实际 launchd identity，才能证明主机激活恢复。
