# FLY-2190 — 原生 Homebrew PATH 全舰收敛与防回退门

**Status**: ✅ S1+S2 implementation complete; needs review
**PR**: pending (created after this required last commit)
**Date**: 2026-08-31

本批次在已合入的 S0 安全层（PR #1002）之上完成获批计划的 S1+S2：12 个生产 carrier
和 1 个 QA carrier 的 PATH 全部改为 Apple Silicon Homebrew 优先；QA 落地回传选择的 `gh`
也改为原生优先。新增 source-tree CI 门会扫描受约束源码并 fail closed，防止登记 carrier
消失、顺序回退或新的混合 Homebrew 声明绕过检查。

本批次没有安装或 link 原生 tmux，没有重启任何 fleet server，也不声称性能收益。
`/opt/homebrew/bin/tmux` 仍不存在，当前 tmux 仍是 `/usr/local/bin/tmux` 3.5a x86_64。

## 交付内容

- 12 个生产声明与 1 个 QA 声明统一为 `/opt/homebrew/bin` 在 `/usr/local/bin` 之前；同步更新
  claude-runner、teamlead、rescue 与 host-selection 的精确断言。
- `packages/flywheel-comm/src/commands/qa-result.ts` 通过导出的确定性候选表原生优先解析 `gh`。
- `scripts/check-global-path-hygiene.sh --source-tree <root>` 增加只读源码门；判断逻辑集中在
  `scripts/lib/path-hygiene.sh`，覆盖获批的扩展名与 executable-no-extension shebang 枚举、
  显式生产注册表、精确例外与非 PATH priority list。
- 真实生产声明 positive control：把 Bridge wrapper 暂时改回 Intel-first 后，门以文件名失败；
  恢复原生优先后重新变绿。
- 完整 overlap sweep 保持获批基线：373 个共享 basename、372 个不同 realpath、1,440 个
  非测试源码文件；真实命令重叠仍为 `python3`、`npx`、`gh`、`ffmpeg`、`ffplay`、`npm`、
  `openssl`、`brew`，carrier-critical 四项不变。
