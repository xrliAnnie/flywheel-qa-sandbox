# FLY-2207 — cmux-watcher 生命周期自愈

**Status**: ⏳ Pending ship
**PR**: pending

cmux watcher 的进程生命周期现在有完整闭环：外部 `cmux --json` 调用受独立超时约束且不会让
主循环累计退出，现有 Bridge patrol 会在 label 消失、owner 失配或 heartbeat 停滞时确认
generation，并通过专用 rebuild 正门恢复 launchd job；异常继续借既有统一告警通道上报，没有
新增告警层，也不再经过 FLY-913 的部署面护栏。

runner 视图生命周期也从“只创建”补齐为可收束、可重建。终态 runner 的 source window 与
Flywheel-owned workspace 按精确 execution/registry/tmux 身份事务化关闭；死窗期或 watcher
恢复后缺失的 viewer 用现有 build WAL、UUID receipt ledger 和 attach-heal 原语重建。每次突变前
都会重验 kill switch、lease、cmux generation、workspace UUID 与 source `@id`，失败按首次突变
边界决定重试或锁存，避免 founder 同名 workspace、重复 execution 和 stale receipt 被误伤。
