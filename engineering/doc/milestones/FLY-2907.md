# FLY-2907 — 整仓 Git 清单不再触发 Node 默认缓冲上限

**Status**: ⏳ Pending code review, exact-head CI, and QA
**PR**: #1345
**Date**: 2026-09-25

main 的 tracked 文件名输出已经超过 Node 同步子进程默认的 1 MiB `maxBuffer`，因此
`feature-flags-drift` 与 `required-wall-clock-thresholds` 在任何 PR 的 full CI 中都会确定性
报 `ENOBUFS`。本单把这两处整仓 `git ls-files`、同类 standing-authority 打包脚本，以及
resume progress 的间接整仓 `git ls-tree` 路径统一提高到 64 MiB；路径限定或已有显式大缓冲
的调用保持不动。

新增 AST 回归测试会扫描 tracked JavaScript/TypeScript，要求直接通过 `execFile`、
`execFileSync` 或 `spawnSync` 执行的整仓 `git ls-files` / `git ls-tree` 显式声明
`maxBuffer`。目标测试、Config 与 Teamlead 受影响构建、lint、Config related 以及 Teamlead
related（104 个文件、1188 条测试）均通过。

本实现节点只跑相关测试，没有请求 full CI、派发 QA、合并或部署。main 同 run 的 Script
Tests 5/6 与 `fly-1998-database-retention-sweep.test.ts` 红项不在本单范围；其精确头结果留给
正常 PR CI 与独立 QA 记录。
