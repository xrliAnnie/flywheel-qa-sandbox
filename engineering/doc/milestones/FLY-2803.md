# FLY-2803 — 额度页页面 E1–E19 改版

**Status**: ✅ QA E5 rework code reviewed; ⏳ pending exact-head QA retest
**Date**: 2026-09-23

本单只改额度页页面层与受信手填输入。两张 provider 表现在按机器周额度分组，
组内严格按周重置日升序；当前在用账号整行绿底、绿点、在用标和左轨的优先级
高于打满与读不到状态。周/Fable 各自显示百分比和进度条，满维度单独标红，
不再用合成“打满”标签改变分组。周重置日和 5h reset 都保留并统一为
`MM/DD 周几 HH:mm`。页面删掉的只有 spec 点名的顶部灰字、格内来源/读取时间、
footer/legend、余额、恢复文字和合成标签；账号、档位、token 状态、两类 reset、
卡片、订阅到期与既有错误原因均保留。

订阅到期支持未取消、已取消加日期、未知三态。手填记录绑定 provider、profile
和非秘密身份摘要，并强制保留确认人、确认时间与来源；读取限制在 state dir 内，
拒绝 symlink、越界、宽权限、超大、畸形、未来或身份不匹配输入。GET 只读该文件，
失败时页面继续以安全未知状态返回；唯一写盘入口是显式 validate/install CLI，
不碰凭据、不刷新额度、不把旧 `retiresAt` 反写或迁移。

首轮精确头 code review 通过后留下的 3 个 MEDIUM advisory 也已用失败测试收口：
provider 级读取原因会在对应表内安全转义显示；身份解析失败会记录仅含别名和错误码
的安全日志；Codex 手填确认会与 quota reading 的已存身份交叉核对，明确不一致时
降级为未知，同时兼容尚无身份字段的旧 reading。

量测覆盖 Claude/Codex 各两处，共 4/4 个视觉间隔和 4/4 个结构 spacer 都是 10px。
