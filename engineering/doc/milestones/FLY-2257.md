# FLY-2257 — 管理台 DAG、花名册与 Flag 语义

**Status**: ✅ Implementation complete; needs review
**PR**: [#1054](https://github.com/xrliAnnie/flywheel/pull/1054)
**Date**: 2026-09-03

生产管理台现在把 DAG 模板按产品 / 工程切换展示，分类直接读取完整 manifest graph，所有模板共用同一套节点框尺寸；宽度不足时保持最小框宽并换行，不以缩框换取单行。花名册只消费后端 `sourceLink`，没有链接的角色保持不可点并显示原因。重复的项目面板已删除。Feature Flags 合并为一个列表，每行说明当前状态和“打开代表什么”，并只把显式 `project_row` 计为项目覆盖。

## 交付内容

- Management snapshot 升到 schema v2：DAG 增加只读完整 graph；Flag 增加 `polarity`、`default`、`valueKind`、`onMeans`，项目投影保留 `via` / `isDefault`。
- DAG 产品 / 工程分类只依赖后端节点类型；工程集合严格按产品定义为 `design` / `implement` / `qa`。框尺寸取样覆盖当前项目的全部模板而非当前 tab，低于 76px 下限时换行。
- 花名册链接逐字采用后端 `sourceLink`，只接受 `https://github.com/` 链接；前端没有角色到路径的映射，也没有拼 GitHub 路径。
- 删除页面里的重复项目面板和“跑过 N 次”；保留原有模型、Cron、Flag stage/apply 写路径。
- Flag registry 为 18 个 bool flag 显式登记 `onMeans`：16 个 `enables`、2 个 `_disabled` Flag 为 `disables`；3 个非 bool Flag 不登记该字段。未知有效值显示“无法与默认比较”，不会声称已偏离默认。
- 删除 `governance_gate` 类别和对应机制；`doc/engineer/implementation/flag-authoring-runbook.md` 明确保留规则：“治理性策略不做成 flag,写死在代码里,要改走 PR。”
- 修复 snapshot v2 的遗漏消费者 `publish-fable-template-alias`，它现在使用当前管理台 schema 常量；canonical batch 自己的 schema v1 守卫保持不变。
- QA 首轮发现 Flag 表头比数据行左偏 3px；`348e07872` 为 `.flag-head` 补上与 `.flag-row` 等宽的透明左边框，使四列 grid 内容盒重新对齐。
- 附带可复现的 localhost fixture、CDP capture 与九图度量脚本，供 browser-authorized QA host 执行。
