本单修的是与 FLY-2770 不同的病根：watcher 不再把陈旧
`cmux-node-registry` 里的无效标题当成待补镜像队列。节点轮次先从权威 live
roster 建 admission gate，`ensure_node_workspace` 对非 `node:*` 标题 fail
closed；仍存活但标题为 `-` 的节点只从 live authority 铸造标题，非 live 行不再
创建“已结束”摘要 tab。每轮先对账并剪掉超过 TTL 的非 live 行，现存 summary
仍按 TTL/cap 回收；账本对 conclusively absent 的 receipt 有持久 sidecar 计数，
而 title drift 只告警、不擅自改名或删 receipt。

运行中的 watcher 现在在每个 node row 的安全边界重读维护标记。命中标记时本轮
latch、停止 mutation、让出 lease；不再要求重启进程才能发现维护状态。所有
workspace 创建统一穿过 reservation chokepoint，受轮次预算、持久滚动 burst/rate
账本、总 workspace ceiling 与 runaway latch 约束；node/view 之间保留最小公平预算。
新增的生产 watchdog 独立采样 workspace 斜率、刷新心跳，并能在异常增长时写维护
标记、执行受控 watcher 退出和告警。
