模型解钉根治 — 设计方案

FLY-1496 · 2026-07-27 · 设计已过 Codex 评审 5 轮 APPROVED · engineering/doc/FLY-1496-model-unpinning/

一句话:让"模型用哪个"只有一个真相来源、改一处配置就生效,并且机器保证 Opus 4.8 在任何角落(包括兜底路径)都跑不起来。

背景:你一晚三次把模型拨回 Fable,它一直弹回 Opus 4.8。根因已抓实——不是玄学,是一个"抄了一份然后过期"的文件在每次重启时把旧值压回来。

那晚发生了什么(病根,已实锤)

projects.json

还写着 opus-4-8

启动日志铁证(7月26日晚,一晚 7 次重启,每次都压回):

20:43:41 model drift: env=claude-fable-5 manifest=claude-opus-4-8[1m] → using manifest 21:30:35 model drift: env=claude-fable-5 manifest=claude-opus-4-8[1m] → using manifest 22:03:15 … 23:27:32 … 23:57:52 (同样的行,共 7 次)

所以"session 中途漂移"的主体感 = 你没看见的后台重启 + 这份过期快照。调查阶段还会把其余零散来源逐一清点(见诚实边界)。

同时新增一个全局模型配置文件 ~/.flywheel/models.json:出新模型、改档位指向、改难度映射、改禁用名单——改这个文件就生效,不改代码、不发版。

配置长什么样(数据模型)

models.json 五段

段管什么
bindings"opus"这个档位当前指哪个版本(现指 Opus 5)

phases三段式 design / implement / QA 的 vendor+model+effort

文件缺失或写坏 = 自动回内建安全默认 + 响亮告警,绝不因配置问题让系统起不来。

禁 4.8 = 机器规则,分两种脾气

场景撞到 4.8 时为什么
派任务(runner)直接拒绝 400拒得起——失败响亮,立刻能改
Lead 开机替换成 Fable + 告警拒不起——不能让一台坏配置把整个团队 brick 在启动上

覆盖所有出口:派发接口、每一层解析、fleet 改配置、模板/定时任务写入、以及最后一道"起进程前"的守卫——守卫还会把裸别名统一换成精确版本号,版本决定权不再漏给 Claude 命令行自己猜。

关键取舍(和被否掉的方案)

决策点选了没选(为什么)
快照文件怎么办只写不读(降级为事后记录)彻底删掉——会破坏 fleet 的对账和回滚机制,改动大收益同
对账兼容快照里保持原拼写 + 新增"实际用了什么"字段改 fleet 全套比对逻辑——没必要,加两个字段就兼容
环境变量的地位彻底退出模型决策(评审抓的:它也是一份会过期的抄写)留作兜底——兜底时没法查禁用名单,可能把 4.8 漏回来
回滚撞禁用名单整体拒绝、零改动、说清原因回滚时悄悄替换——"精确还原"的合同不能掺假
定时任务旧档案可复用清扫脚本,残留不清零就报错每次执行前都加检查——要碰每个定时任务,复杂度不值

Codex 评审 5 轮共揪出 14 项(含 6 项 HIGH:fleet 回滚不还原真相文件、对账会被新写法卡死、禁用检查位置太靠后、启动器兜底会漏 4.8 等),全部并入方案。

诚实边界 — 这个设计不做什么

  • 已在跑的定时任务档案:改禁用名单不会穿透到它们已落盘的启动参数——靠"改完必跑清扫脚本"收口(脚本残留不清零就报错,是硬门不是口头约定)。
  • 配置上新模型 ≠ 全套元数据:新模型立刻可派发,但 token 计价表、单字母缩写等仍要后补一条,否则报表里按 $0 计价并告警。
  • Claude 命令行内部行为管不到:撞限额时它自己的提示/切换逻辑在我们代码之外——缓解 = 所有派发都显式指定模型 + 各账号默认设置统一(调查报告会逐账号核对)。
  • 不改工作流模板引擎:"模板钉死模型"的根治留给 v2 后续批次(现已用开关绕开);本单只保证模板写入也过禁用检查。
  • 漂移调查报告在实施阶段交付:7 个候选来源已列清单,主犯(过期快照×重启)已实锤,其余逐个给"修了"或"豁免+理由"。

验收(实施完成时你能看到)

  • 改 models.json 加一个新模型别名 → 不改代码直接能派(现场演示);
  • 删掉快照文件再重启 → 日志里永远不再出现 "using manifest" 压过配置;
  • 手动往配置里塞 4.8 → 派发被 400 拒 / Lead 开机被替换成 Fable 并告警;
  • 漂移来源调查报告 + 清扫前后对照;Codex 代码评审通过;ship 走 founder gate。
