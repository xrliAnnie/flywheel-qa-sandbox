# W1+W2 中间跑（**不是结论**，是管线在真数据上的第一次冻结-M 全跑）

日期: 2026-08-24 10:15 PT

## 它证明了什么

这是分析器**第一次**在**真数据**上以**冻结 M** 跑完整条链。此前所有冻结-M 的跑都在合成 fixture 上。

| 门 | 结果 |
|---|---|
| 三个对照 | ✅ 全过 —— 朴素 CP 的覆盖率**上界** 0.5709 < 0.95(**证明**它覆盖不足，不只是「没证明覆盖」)；oracle 过；种子稳定性过 |
| `b_lb @ A` | ✅ 16 个格点全过 |
| `range_lb @ N` | ✅ 16 个格点全过（⚠ 但 N 的拒绝域为空，见 `n_reachability`——这个「过」不代表 N 可达） |
| 参数集门 | ✅ 过，且**自报 `has_rejection_region: false`** —— 它没有拒绝域，不可引为拟合证据 |
| **适用域** | ✅ **过** —— **真数据的区块率均值与方差都落在冻结网格能产生的范围内** |
| 资格门 | ❌ **不过：只有 2 个窗，冻结设计要 3 个** |

## ⚠ 最值得单独说的一条

**适用域门在真数据上通过了。**

它问的是：「这批真数据的依赖结构，落在模拟器所描述的那个范围里吗？」
如果落在外面，那么所有覆盖率结论对这批数据**一句都不适用**，诚实的结局只能是 U。

它过了。这说明冻结模拟器的对抗网格**确实覆盖了生产机真实呈现的形状** —— 这不是自证，因为它完全可能不过。

## ⚠ 它**不是**什么

`authoritative_outcome = U`，唯一原因是**窗口数不足**（2/3）。
这**不是**阶段 0 的结论，只是「三窗没齐所以判据不结账」。真结论要等三窗齐。
