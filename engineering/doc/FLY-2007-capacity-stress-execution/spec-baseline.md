### 0.2.2 【裁决·可引用】每窗单元数 `J = 30`

⚠ **本节 v2 —— v1 的理由已被我自己的实测推翻并撤回，这里记的是真实理由。**

**v1 说过的（现已作废）**：「J=13 覆盖率不达标、J=30 是刚好过线的最小值、余量薄 0.9591」；随后又说「L2 才是绑定端点、要 J=44」。
**为什么作废**：两者都是**我模拟器里一个 bug 的产物** —— 两态过程用 50/50 开局，而判据比对的 `trueB` 是**平稳率**。最黏那档的平稳坏态概率只有 **9.1%**，我却给了 50%，把坏态放大 5.5 倍，再拿这个被污染的样本去比一个没被污染的真值。
**修正后的实测**（平稳开局，M=20000，全网格 8 档 × 两端点 = 16 个点）：**J=13 就已全过**，最差点 g08/L2 下界 **0.9606**。

⇒ **覆盖率不再是 `J` 的约束。** 一条被证伪的理由不能靠惯性留着当支撑。

**J = 30 的真实理由（Tadashi 2026-08-23 批准）—— 判别力，不是合规**：

> 更多单元 = 更紧的下界 = 更可能真的证出 A。全违约时 A 方向的下界在 J=13 是 **0.1159**，在 J=30 是 **0.1579**，判据线是 0.05。两个都过；但如果真实基线没那么极端（比如 `b` 在 0.1 附近），J=13 的下界会够不着而 J=30 够得着。我们花这 4 小时买的是**拿到决定性结论的概率**。

⇒ `J = 30` ⇒ 每窗 **2.5 小时**，三窗 7.5 小时。
⇒ ⚠ **它不是「覆盖率要求的最小值」，也不是「薄过线」** —— 这两种说法都属于已撤回的 v1，任何文档、注释或输出都不得再出现。

## 1. estimand（要估的到底是什么）

`b` = 产生该窗口观测序列的过程的**平稳每-tick 违约概率**，按**固定调度栅格**计。

- **保守计数口径**：`violations = missed + error + timer_late`。
  ⚠ `timer_late` **按违约计入**：调度器迟到正是被研究的负载造成的，把这些 tick 丢掉会**优先丢掉有害的那些观测**（FLY-1986 §2.2）。
- **不是**「这 3900 秒里恰好发生的比例」（有限窗实现值，不需要推断）；
- **不是**「未来任意窗口的风险」（要求跨窗平稳，而跨窗平稳恰是 §5 要检验的，不能预设）；
- ⇒ **每窗各估一个 `b_w`**。

## 2. 判据：阈值-计数精确二项界

单元违约率 `p_j ∈ [0,1]`，门槛 `c`，`K(c) = #{j : p_j > c}`，`π(c) = P(p_j > c)`：

```
b_ub(c) = c + (1−c)·π_ub(c)          b_lb(c) = c·π_lb(c)
```

`π_ub` / `π_lb` = Clopper–Pearson 精确二项，作用在 `K(c) ~ Binomial(J, π(c))`。

- **两条矩不等式无条件恒真**；
- ⚠ **Clopper–Pearson 那一步、以及「exact」这个词，都是在假设 A1 之下成立的**；
- **A1（单元 iid）被显式命名，不假装它成立**；其失效代价由 §7 的冻结模拟器量化。

### 2.1 单元定义（先验固定）

**单元 = 300 秒哨兵块。`J = 30`/窗（= 2.5 小时曝光；理由是判别力，见 §0.2.2）。先验固定，不做数据依赖合并。**

⚠ **`J` 是固定的 30，不是「幸存下来的那些」** —— `unreachable` / 意外重启 / `timer_late` 超限**不是随机缺失**，它们恰恰发生在机器最坏的时候；删掉之后剩余单元上的 `K` 不再是 Binomial(J, π)。
⇒ 处置是 §4 的资格门，**不是**换成幸存 `J` 重算。

滞后-1 自相关 `r₁` **计算并印出，但只作描述**，不改变任何单元定义或判决。

### 2.2 门槛网格（预注册，含非事后的选择理由）

`C = {0, 0.02, 0.05, 0.10, 0.20}`，`G = 5`。

| c | 为什么在网格里 |
|---|---|
| `0` | 「有没有任何违约」这个最自然的切分；全干净时它给出最紧的上界 |
| `0.02` | SLO 之下一档 |
| `0.05` | **就是 SLO 本身** —— 判据要在它上面有分辨力 |
| `0.10` | SLO 之上一档 |
| `0.20` | 之上第二档。⚠ **它在网格里是因为已排除的 pilot 数据显示 `b` 可能很大**（§8 第 6 条已披露），**不是**看了 W1–W3 才加的 |

⇒ 大致等比的阶梯，把 SLO 夹在中间。

### 2.3 比较算子

一律**严格 `>`**。⚠ **`p_j = c` 是可达的**（块级比率是 `k/150` / `k/100`：`3/150 = 0.02`、`15/150 = 0.10`）
⇒ **用整数交叉相乘判定** `violations · den(c) > num(c) · n`，**绝不用浮点比较**。

## 3. 错误率分配（全部数值在此冻结）

`SLO = 0.05`（founder 裁定）；`δ = 0.025`（Tadashi 裁定，**政策选择**，见 §5）。

| family | 总量 | 形状 | 每个 CP 的实际水平 |
|---|---|---|---|
| **达标（B）** | `α_B = 0.05` | **intersection–union test** —— 六个性能门 **且** 两个端点的等价门都要过 | 零假设是「至少一个 `b > SLO` 或不等价」；拒绝要求每个分量都在 `α_B` 拒绝 ⇒ 整体 ≤ `α_B`，**分量之间、性能门与等价门之间都不需要 Bonferroni**。性能：`α_B/G = 0.01`；等价（`range_ub`，3 窗 × 2 尾 × G）：`α_B/(6G) = 0.001667` |
| **不利（A + N）** | `α_adv = 0.05` = `α_A 0.025` + `α_N 0.025` | **并集** | **A**：6 分量 × G ⇒ `α_A/(6G) = 0.000833`（单侧下界）<br>**N**：2 端点 ⇒ 每端点 `α_N/2`；端点内 3 窗 × 2 尾 × G ⇒ `α_N/(2·6G) = 0.000417` |

⚠ `b_lb = max_c b_lb(c)` **对门槛取 max 就是一次选择**，这正是必须乘 `G` 的原因。
⚠ **`α_A + α_N = 0.05` 是主动选择**，让「唯一权威的不利结局」整体有 95% 保障；否则两个各 5% 的 family 并集最多可到 10%，而优先级消不掉这个并集。
⚠ **结论 schema 必须印出本表**，否则读者无法判断某个 95% 标签管的是哪一层。
⚠ **结论页不得把任何未校正的 marginal 95% 下界称为「已认证不达标」。**

## 5. 跨窗等价检验

- **区间算术，不重采样**：
  ```
  range_ub = max_w U_w − min_w L_w
  range_lb = max(0, max_w L_w − min_w U_w)
  ```
- ⚠ **跨窗 Bonferroni 对窗间依赖免疫** —— 这正是选它的理由：同机同日的三窗**不需要**假设独立，也不需要任何联合模型；
- ⚠ **`range_ub` 与 `range_lb` 水平不同（§3），必须分别算两套区间**，一套不得顶替另一套；
- **三态判定**：

| 判定 | 条件 | 结局 |
|---|---|---|
| `equivalent` | `range_ub < δ` | 不阻止 B |
| `non-equivalent` | `range_lb > δ` | **N（已证非平稳）** |
| `inconclusive` | 其余 | **不放行，但不叫 N** |

⚠ 「TOST 没过」**不等于** N —— 那是把低把握度当证据。

### 5.1 δ = 2.5 个百分点

**Tadashi 2026-08-23 批准**，出处：**Lead 在 FLY-1986 授权链下的仪器校准决策**。

**它是政策选择，不是推导结果**：「我们接受基线跨窗自发漂移 ≤ 2.5pp（= SLO 的一半）；超过即认为单窗阈值没有外部效度。」

⚠ **撤回的旧理由**：v1 曾写「小于 SLO 一半的漂移不足以把认证翻转」。**那在数学上是假的** —— 4.0% 与 6.0% 相差 2.0pp，却正好跨过 5% 的线。理由作废，结论没有靠惯性活着，而是换了新支撑（Lead 的政策决定）。

## 7. 模拟敏感性分析（**不叫 coverage validation**）

它是**在拟合出来的模拟器上做的敏感性检验** —— 从同一批数据 plug-in 依赖结构，验证不了未观测的长记忆、非平稳与参数不确定性。

**冻结**：模拟器代码、DGP 族（两态半马尔可夫）、依赖参数置信集、adversarial 网格（`K ≤ 20`）、真 `p` 网格、参数提取、拟合优度门、接受规则、种子。
**校准**：**只用已永久排除的 pilot 数据**；W1–W3 只做事后 sensitivity，**不得改判决规则**。

**错误预算**：`α_param = 0.025`、`α_MC = 0.025`（合计 ≤ 0.05）。
每个网格点的覆盖率用**精确二项下界**、水平 `1 − α_MC/K`；**要求所有 K 点同时 ≥ 0.95**。
`M = 20000`：在 `α_MC/K = 0.00125` 下，它支持把真覆盖率 ≥ 0.96 的点的精确下界推过 0.95。`M` 与 `K` 印在输出里。

| # | configuration | 每 CP 水平 | 消费者 | 本轮 |
|---|---|---|---|---|
| 1 | `b_ub @ B-performance` | 0.01 | B | 📄 文档层（§0.1 裁剪） |

## 9. attempt ledger

- **目录本身是分配权威**：原子 `mkdir attempt-NNN`（已存在即失败）即 reservation；durable 状态写在目录内（`state.json`，临时文件 + `fsync` + 原子 rename）；**顶层 JSONL 只是可重建 index，不构成第二个真相**；
- **确定性恢复**：任何**无 TERMINAL 状态**且**锁未被持有**的 attempt 目录，一律终结为 `aborted` + `reason=crash_before_terminal`，**并计入 ledger** ⇒ census 永远收敛；
- **三阶段**：`START`（锁内建目录）→ `PREFLIGHT`（逐字段只读采集，见 §9.1）→ `TERMINAL`（exit code / 状态 / 原因 / 产物哈希）；
- **双向 census**：ledger 每个 `attempt_id` 必有目录，每个 `attempt-*` 目录必有记录；
- **替换策略**：服务/宿主相关的作废（`unreachable`、意外重启 / identity 变更、`timer_late` 超限）**不得**被替换成 B 的证据 —— 它们使该窗乃至阶段 0 无法认证，并**本身作为可用性结论保留**。**只有**可独立证明的 operator 凭据故障或 harness / 存储故障可重跑，原 attempt 留档，上限 **2 次**。

### 9.1 wrapper 的逐字段只读 authority

| PREFLIGHT 字段 | 权威来源 | 读法 |
|---|---|---|
| `buildSha` / `bridge_started_at` / `ok` / `shuttingDown` | Bridge | `GET /health`（**唯一允许的网络调用**） |
| `pressure_hold` | StateStore | `sqlite3 -readonly <与采集器同一条 canonical path>`（**字面文件名，不拼 `file:` URI**） |
| worker identity（PID + start-time） | 进程表 | `lsof` + `ps`，**与采集器同一套解析** |
| `load1` | 宿主 | `uptime` |
| 当期班车时刻 | launchd | `plutil -p <updater plist>`（**现读，不用缓存的认识**） |

⇒ 表外的**任何网络 / 任何写方法 / 任何其它 DB 打开一律禁止**。

## 10. A/A 协议（FLY-1986 冻结点 ① 的强制项）

A/A 工具已按 FLY-1986 §16.1 移出采集器，但冻结点 ① 的合同**没有删除**「A/A 无害界与把握度必须在第一个阶段 0 窗口之前冻结」。

| 项 | 预注册值 |
|---|---|
| 疏/密节奏 | 疏 = 当前栅格（L1 2s / L2 3s）；密 = 各自的一半间隔 |
| 每种节奏最短曝光 | 各 ≥ 10 分钟，同窗内交替 |
| 估计量 | 两种节奏下 `b̂` 之差 |
| 无害 margin | **±1.0 个百分点**（= SLO 的五分之一；⚠ **政策选择**，理由：小于它的观察者效应不足以改变本单任何结论的方向） |
| 把握度 | 在无害界上 ≥ 0.80 |
| 失败规则 | 等价检验不通过 ⇒ **观察者效应未排除** ⇒ 所有延迟数字作废，先减探针成本 |

⚠⚠ **本轮没有跑 A/A ⇒ 观察者效应未被排除。** 已声明的自加负载是 FLY-1986 §16.2 的**约一个核的 2.0%**（perl 时钟，每 tick 两次 fork）。**这是限定，不是脚注**，必须出现在结论页。
