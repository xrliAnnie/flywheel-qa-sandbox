# FLY-2007 容量压测执行 — Design Review R1

VERDICT: CHANGES REQUESTED

## 中心审计结论

**research.md A.2 的中心 claim 正确，而且已由当前源码坐实。** collector 在 `scripts/qa-fly-1986-load-probe.sh:493-498` 计算并输出的是
`(missed + error + timer_late) / n`；脚本没有在这里做任何置信计算。`upper` 只是相对 `best_case` 而言把 `timer_late` 计作违约的保守**点估计口径**。FLY-1986 合同在 `engineering/doc/FLY-1986-load-stress-knee/plan.md:200-210` 要求的是单侧 95% 置信上界 `b_ub`。因此“collector 与判据之间缺分析层”不是误读，本节点补这层的方向没有 mis-scope。

问题在于：当前拟补的分析层本身尚不能兑现“序列相关下覆盖率有效”，并且有几处会绕过 collector 已有 fail-closed 语义的执行缺口。
