# 告警频道发言收紧 — Annie 操作卡(FLY-1071)

**要做什么**:把 #flywheel-alerts 频道改成「只有三个机器人能发言」,防止其他人/机器人误发消息把告警频道刷乱。你自己是服务器主人,不受任何限制,不用给自己加权限。

**在哪操作**:Discord 左侧频道列表 → 找到 **#flywheel-alerts** → 右键(或点频道名旁边的齿轮)→ **编辑频道** → 左侧选 **权限**。

## 第一步:关掉「所有人」的发言

1. 权限页里点 **@everyone**;
2. 找到 **发送消息(Send Messages)** → 点 **❌**(红叉,拒绝);
3. 找到 **在子区中发送消息(Send Messages in Threads)** → 点 **❌**;
4. 其他项(查看频道、阅读历史)**不要动**。

## 第二步:给三个机器人开发言白名单

在权限页左侧点 **添加成员或身份组**,逐个加下面三个机器人,每加一个,把它的 **发送消息** 和 **在子区中发送消息** 都点 **✓**(绿勾,允许):

| 机器人 | 说明 |
|---|---|
| **flywheel-alerts-dispatcher** | 发告警工单的调度员 |
| **claw-infra-bot** | Claude 侧自愈机器人(工单主力) |
| **Codex Infra Bot** | Codex 侧自愈机器人 |

## 第三步:保存

页面下方出现「注意 — 你有未保存的更改」时点 **保存更改**。

完成后跟 Tadashi 说一声即可,后续回归验证(机器人还能正常发帖)由 runner 自动做,不用你管。
