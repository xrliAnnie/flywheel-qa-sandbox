时区安全证明与生产锚点

tmux generation 不使用墙钟

capture: tmux new-window -P -F '#{window_id}|#{socket_path}|#{start_time}' persist: session_params.pane_loss_generation = { socket_path: string, server_start_time: "^[0-9]+$" } probe: tmux -S <socket> display-message -p '#{start_time}' compare: current.startTime === recorded.server_start_time

两边都是 tmux 原生 POSIX epoch 秒的十进制字符串；无 `Date`、ISO、locale、TZ 或 DST 转换。字段不可读即 `indeterminate`，不终态化。
