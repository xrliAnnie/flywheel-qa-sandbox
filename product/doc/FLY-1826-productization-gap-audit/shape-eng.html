1 · 交付物形态(已实现,FLY-1062)

  • 对外面:公开 npm scoped 包 @flywheel-ai/onboard(薄壳:bin + lib + README)。已发布 0.1.0(2026-07-18)。
  • 鉴权:客户粘 license key → 走 Authorization header 到 Cloudflare Worker。key 只存 sha256,可吊销、可轮换;明文只在签发瞬间打印一次,经 founder 手交。
  • 产物:R2 上的 payload tarball —— 零仓库访问、零源码暴露、零 TypeScript 运行时。根部一个 .flywheel-prebuilt 哨兵,所有 packaged 分支以它为键。
  • 打包边界:scripts/package-onboard-files.allow(125 行显式路径白名单)+ 发布安全门(secret 扫描 / 零 .ts / 零私仓 slug / 零 git clone)。新文件进包必须显式登记。
  • 发布链路:beta 每 6h 自动发 → promote 到 customer 通道要 founder 在 Discord 卡上点 ✅。两把对外发布 token 只在 Bridge 父进程内存(boot 时从 process.env 读入并抹除),永不落盘 / 永不进 CI / 永不进子进程。

2 · 客户机上的运行时(已实现)

  • 常驻:Bridge(受管服务)· 每个 Lead 一个 keepAlive 服务(flywheel-lead-wrapper-v2.sh <manifest> → lead-body.sh → claude-lead.sh)· daily-standup 定时器(每天 03:00)。
  • 按需:Runner 在 tmux 里起。
  • 状态根:~/.flywheel/ —— journal(v2,含 buddy 区)· .env(0600)· 日志 · 缓存,全部 0600。
  • 平台:darwin = launchd · linux/WSL2 = systemd-user,经统一 supervisor seam。container 是 fail-loud 的桩,零实现。
  • 密钥红线:所有 secret 只在步骤/连接器进程内经隐藏 TTY 读 → 0600 .env;journal / 日志 / 对话 / 转人工摘要全程 secret-scan。业务系统只申请只读;写/改走运行期 founder-gated。

来源:scripts/packaged/bootstrap-services.sh(packaged 路径的服务安装)· scripts/lib/supervisor.sh。 注意:packaged 路径明确禁用 restart-services.sh 与 flywheel-daemon.sh(它们 hardcode ~/Dev/flywheel),由 bootstrap-services 替代。

3 · 安装流程(12 步,已实现)

preflight · skeleton · model_key · bots · channels · linear · github · config · services · finish · captain_health · digest

  • 每步可单独 run / verify / 续传;journal 记 cursor + 非密证据。
  • 上层是 Buddy 对话状态机(b0–b8),它拥有全部用户面措辞(scripts/buddy/copy/ 21 份,有黑话 lint 测试);下层 step CLI 每次只吐一行 JSON —— 引擎原始输出到达用户面即视为黑话红线违规。
  • 业务连接器 seam 已有 4 个(Shopify / Veeqo / Ordoro / IMAP),全部只读 probe/pull。第一个真产出的 vertical 只做了 dropship 订单一个。
  • Discord 那 4 步是平台边界(bot 不能建归用户所有的 server、不能建自己、intent 只能在 Portal 开),其余频道结构 bot 自动建。

5 · 一个结构性问题,需要产品侧先答

容器化 = 零实现(全仓零 Dockerfile / compose / devcontainer),而 npm 路线已经在零容器的前提下做到了「客户零仓库访问安装」。

所以 FLY-654 里写的「容器化 + 配置驱动项目 = 前置」已经不成立。FLY-652 / 559 / 653 三张单现在悬着 —— 要不要做、什么时候做,取决于产品侧对托管版(V2)的决定,不是工程能自己拍的。
