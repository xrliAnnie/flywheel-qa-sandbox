### 3.0 这份 DR 最反直觉的一条:时机问题不是靠给领导更多权力解决的

**【事实 · DR 执行摘要开篇第一句】** DR 扫了战略管理、应急管理、航空航天、医疗、制造、金融市场、软件开发、风险投资、临床试验、职业安全九个领域后,给出的第一条结论是:

> 机构**很少**靠「给一个领导更多权威」来解决转向的时机问题。这些机制作用的位置,全都在**领导行使权威之前**的某一环:察觉变化 / 认出它的重要性 / 判定阈值被跨过 / 把信息路由给对的人 / 打断当前工作 / 挑战当前的解读 / 约束领导接下来能做什么。

**【事实】** DR 把这条提炼成一个明确的二分,并说这是「本综述里实证后果最重大的区分」:

| | **权威机制**(authority mechanisms) | **时机机制**(timing mechanisms) |
|---|---|---|
| 回答的问题 | **谁**可以下令转向 | 信息**什么时候**到达那个人、当前动作**什么时候**能被打断 |
| 具体形态 | 决策权分配、正式指挥结构、授权 | 触发阈值、持续监测、评审节奏、升级路径、停工权、对抗性评审、speak-up 文化 |

**【事实】** DR 在跨机制对比表里给了这条二分一个可验证的落点:**decision-rights matrix(决策权矩阵)在「假阴性/行动过晚」一栏被标为 High**,理由原文是 —— 「**High if unpaired with a trigger, because ownership alone does not reveal change**」(单有归属权不会让变化自己显形)。

**【推断 · 我的,非 DR 原文】** Annie 问的是「director 凭什么有这个能动性」。这份 DR 的答案是:**她问的那半可能不是卡住的那半。** 一个 director 有权说「A 先停一停」是相对容易安排的;难的是他**怎么知道现在该说**。DR 的九个领域里,机构投入的绝大部分工程量都花在后半截。

**【事实】** DR 给了一个把「时机」拆开的分解式(它明说这是**跨文献的综合,不是任何一个文献统一使用的术语**):

```
T_redirect = T_sense + T_recognize + T_route + T_decide + T_execute
          察觉      认出重要性     路由到人    做决定    执行
```

并据此指出文献里存在**三种不同的时机错误**:
1. 真实变化**察觉得太晚**
2. **过早或不必要地**对一个信号动手
3. **察觉对了,但在等升级/审批/执行的过程中把干预窗口耗掉了**

**【事实】** 医疗急救响应文献同时给了第 1 种和第 3 种的例子;告警疲劳和市场熔断研究让第 2 种「异常清晰可见」。

### 3.1 M1 纯日历节奏(time-boxing / recurring review cadence)

**它解决什么** —— **【事实】** DR 的定性:这一族机制**避免依赖「自发地认出异常」**,靠的是**制造出「必须重新考虑是否继续当前路线」的时刻**。DR 给这类机制下的「正确时刻」定义是:**「一个有上界的最大等待时间,到了就必须重新审视」**(a bounded maximum waiting time until mandatory reconsideration)。

**真实形态(≥2 个独立来源)** ——
- **【事实】Scrum**:Daily Scrum 是每个工作日 **15 分钟**的检视/调整事件;Sprint Review 检视产出**以及环境变化**以决定后续调整,一个月的 sprint 上限 **4 小时**;retrospective 上限 **3 小时**。
- **【事实】FEMA 事件指挥系统(ICS)**:把行动划成明确的 **operational periods**,每个周期一份 Incident Action Plan(IAP),规定该周期的目标、任务分配与通信。

**代价** —— **【事实】** 周期性会议与准备时间、上下文切换、协调开销。DR 特别点出 **Scrum 把这部分直接成本做成了可测量的**(因为时间盒是写死的)。

**什么时候失效 —— 这一格是 M1 最要紧的一条** ——
**【事实】** DR 原话:「**最大检测延迟被 cadence 界住了,但没有被消除**:一个刚好发生在评审之后的突变,可能要等将近一整个周期。」
**【事实】** 周期太短造成 churn(反复搅动);太长则推迟重新考虑。
**【事实 · 证据局限】** DR 明说:**把某个特定 cadence 和「最优转向时机」联系起来的强因果证据是有限的。**

**「到点了真有话说吗」** —— **【事实】** DR 没有直接研究「到点但没话说」这个现象。它给的相关设计是 Sprint Review 的对象定义(检视 increment **和环境变化**)和 FEMA 的 IAP(每周期强制产出目标与分配)。**【推断 · 我的】** 这两者的共同点是**评审有一个规定的检视对象**,不是「大家来聊聊」—— 这与 FLY-1045 那句 WBR 结论(「if every team has a **standard review object** and exception thresholds」)是同一件事的两次出现。

**它假设了人有什么** —— **【推断 · 我的】** 这一类对人的假设最轻:不要求人主动察觉异常,只要求人**到点会来**。这也是它在 DR 的跨机制表里被标为**「standing cost 低—中、evidence strength 描述性强」**的原因。

### 3.2 M2 节奏 + 例外过滤(monitoring / metrics / dashboards)

**它解决什么** —— **【事实】** 这一族「主要缩短的是**底层条件发生变化**到**机构认出这个变化**之间的时间」。DR 把监测/指标与仪表盘归在「信号与触发机制」里,并强调它**提供信号但不必然规定动作**。

**真实形态(≥2 个独立来源)** ——
- **【事实】医疗早期预警**:生命体征与 early-warning score 作为 rapid-response system 的「afferent limb(传入支)」,利用的事实是**恶化往往在心跳骤停前数小时就出现**。
- **【事实】实时仪表盘**:一个 **2024 年、524 名参与者**的实验发现,仪表盘的**信息格式、时效性、完整性**通过**降低感知任务复杂度、提高信息满意度**来**间接**影响决策质量。DR 特别标注:这支持的是**感知/信息质量这条路径**,**不是**「仪表盘必然改善硬性组织结果」这个断言。

**阈值谁定、怎么定、多久重定 —— 这是 Annie 卡住的那一点** ——
**【事实】** DR **没有**给出「阈值由谁定、怎么定」的通用答案。它给的是**阈值被调整后发生了什么**的量化证据:
- **【事实】** AHRQ 的告警安全综述描述了一次标准化监测流程改造:**每监护患者日的心脏告警中位数从 180 降到 40**,**误报率中位数从 95% 降到 50%**;另一次干预把误报从 **18.8% 降到 9.6%**。
- **【事实】** DR 由此得出:这类机制有一个**经验上可见的「注意力预算」**(an empirically visible attention budget)。

**【事实 · 一个可直接类比的精细阈值设计】** 美国市场熔断:当前阈值是标普 500 下跌 **7% / 13% / 20%**。**Level 1 或 2 在下午 3:25 之前**触发 → 停 15 分钟;**同样的跌幅在 3:25 之后**触发 → **不停**;Level 3 → 当日收市。DR 的评语很关键:

> **监管并没有把「正确时刻」定义成「7% 一发生就是」;触发条件同时挂在「幅度」和「剩余交易时间」上。**

**代价 / 失效** ——
- **【事实】** 滞后指标在有用的选项已经收窄之后才发现变化;噪声指标造成信号过载;**反复出现的不可行动信号造成脱敏**。
- **【事实】** 医疗告警数据显示某些研究里误报率高达 **72%–99%**;某学术中心 **12 天内超过 59,000 次告警**。
- **【事实 · 高可见阈值的一个通用失效模式】** 熔断研究发现显著的 **"magnet effect"(磁吸效应)**:参与者一旦知道干预边界在哪,行为会**在到达阈值之前**就发生改变。

**它假设了人有什么** —— **【推断 · 我的】** 假设**有一个可测量的量**存在,且这个量与「该不该转向」相关。这正是 §2.1 那条筛子要挡的地方。

### 3.3 M3 预设触发器 / tripwire(trigger-based protocols)+ 停工权

**它解决什么** —— **【事实】** 事先规定一个**可测量的状态**和**与之绑定的动作**:呼叫响应团队、停止倒计时、暂停交易、进入应急模式。

**真实形态(≥2 个独立来源)** ——
- **【事实】NASA 的 launch-commit criteria(LCC)**:明确规定运行限值,**以及限值被突破后必须发生什么**。
- **【事实】医疗 rapid response team**:近 **130 万**入院人次的 meta 分析 —— 成人非 ICU 心跳骤停下降 **33.8%**(RR 0.66, 95% CI 0.54–0.80),但**成人住院死亡率无显著下降**(RR 0.96, 95% CI 0.84–1.09);儿科非 ICU 骤停下降 **37.7%**、死亡率下降 **21.4%**,但**后者对敏感性分析不稳健**。
- **【事实】OSHA 起重机规则**:操作员在安全存疑时**有权停止/拒绝吊装**,直到合格人员判定安全为止 —— 这是**把第一个合法打断者放在离异常最近的人身上**,而不是远处的管理者。

**DR 里对本单最关键的一条结构性发现 —— 测量与响应必须分开看** ——
**【事实】** rapid-response system 有一个**传入支(afferent,检测并激活)**和一个**传出支(efferent,行动)**。DR 原话:**「一个完美的触发器,如果激活被社会性地抑制、或响应团队不可用,就是无效的。」** AHRQ 报告有大量证据表明:**阈值被满足了但激活没有发生**,而这种延迟与更差的结局相关。

**【事实 · 两条容易被忽略的量化结论】**
1. **光是「触发次数变多」不等于结果变好。** 早期的 MERIT 集群随机试验发现:实施后急救团队呼叫次数大幅上升,但主要复合临床结局**没有明显改善**。DR 的评语:这把「机构反应得更频繁」和「机构在有益的时刻反应」**分开了**。
2. **存在一个「最小机制剂量」。** AHRQ 综述指出,早前证据显示 rapid-response system 需要达到**每 1000 入院人次一定的激活次数门槛**之后,才出现可测量的结果效应。DR 的评语:**一个几乎从不被行使的名义权利,不构成一个有效的时机机制。**

**代价** —— **【事实】** 规则开发与验证、训练、响应能力、误激活、打断。一份儿科 MET 的成本分析估算**年运营成本约 28.7 万–230 万美元**(取决于人员配置模型)。

**什么时候失效** —— **【事实】** 阈值可能过敏或过钝;**人在阈值达到后可能不激活**;响应能力可能不可用;**刚性阈值不理解上下文**。AHRQ 认为延迟/遗漏激活**仍然常见**。

**它假设了人有什么** —— **【事实】** DR 明确指出停工权这类机制的**假阴性风险从「领导没及时听到」转移到了「一线的人没有行使这个权利」**;OSHA 因此专门包含**反报复条款** —— DR 的评语:**正式权威本身不能消除打断的社会维度。**

### 3.4 M4 阶段闸门 / stage-gate(progressive commitment)

**它解决什么** —— **【事实】** 重大的不可逆步骤要求**逐级更具体的就绪检查**。

**真实形态(NASA 是 DR 里最详细的一个)** ——
**【事实】** NASA 发射治理的时间结构:**LVRR** 约发射前 30–60 天 → **FRR** 前 3–12 天 → **LRR** 不晚于前 1 天 → 发射前**约 5 分钟**的最终 commit-to-launch 点名表决(**所有被点名方都必须 Go**)。

**【事实 · 这一条直接回答了「它和日历节奏的区别」】** 打断的代价**随时机急剧变化**:Artemis I 的终端倒计时中,**T−6 到 T−1:30 之间**的停止可以 hold 最多 3 分钟然后恢复;更长的停止需要**回退到 T−10**;**移交给自动发射序列器之后**,任何足以停止计数的问题**直接结束当天的发射尝试**。

**【事实 · DR 从中提炼的通用模式】**
> 机构**并不在所有时刻使用同一种转向机制**。离不可逆事件远时,用**审议式评审**;靠近时,**明确判据 + 一致/规定的表决权**变得更重要;到最后阶段,**自动约束替代了一部分实时的自由裁量**。

**【事实】** DR 在「什么叫正确时刻」一节把这个叫作 **option-preserving decision point**,并说相关的量往往是「**距离可逆性崩塌还剩多少时间**」(time remaining before reversibility collapses)。

**代价 / 失效** —— **【事实】** 评审人力、文档、等待关闭、进度储备与潜在延误;**闸门失败得越晚代价越陡**,因为承诺已经累积。失效模式:**闸门合规可能变成仪式化**;晚到的信息可能绕过早先的假设;闸门太多增加延迟、太少让隐藏问题存续。**【事实 · 证据局限】** 直接的对照因果估计**稀缺**。

### 3.5 M5 资源闸 / 预承诺(precommitment & staged rights)+ 独立停止委员会

**它解决什么** —— **【事实】** DR 给了一个精确的心理学定位:预承诺针对的是另一种时间性病理 —— **「做『要不要继续』这个决定的人,在资源已经沉没之后,实际上已经不是当初评估同一个前景的那个人了。」**

**真实形态(≥2 个独立来源)** ——
- **【事实】风险投资合同**(Kaplan & Strömberg 对真实 VC 合同的研究):现金流权、董事会席位、投票权、清算权等控制权是**分开分配**的,使控制权可以随融资推进而转移。
- **【事实 · VC 时机的量化】** 一项针对 2000–2017 年间获投印度公司的研究:**市场不确定性每上升 1%,到下一轮融资的延迟增加超过 6%**;而**代理问题更严重时,这个间隔缩短 55%**。
- **【事实】临床试验的独立数据监查委员会(DMC)**:FDA 指南承认 DMC 承担重要的试验监查职能,发起方可以把设计/实施的决定权委托出去。DR 给这类机制的时机定义比阈值型更细一层:**不只是「证据什么时候越线」,还有「证据什么时候成熟到一个独立机构能把真实信号和统计涨落分开」**。

**【事实 · 「太早行动」的代价在这一族里最可测】** 统计学文献记载:**过早停止试验会牺牲精度、并放大表观效应** —— 这使得「早停」的假阳性代价**异常可测量**。

**代价 / 失效** —— **【事实】** 谈判/法务成本、监控、管理自由裁量权的丧失、围绕里程碑的博弈,以及**事先条件在条件变化后变得过时**的风险。**里程碑可能被 gaming**;刚性权利可能诱发过早终止或过度延续。**【事实 · 证据局限】** 对实际权利条款的**描述性证据很强**,但「某个具体权利产生了最优时机」的**因果证据弱得多**。

**【事实 · 对我们最直接相关的一条 rigidity 成本】** DR 在成本分类表里单列了 **Rigidity/option cost**:「预设阈值与合同在条件变化后变得不合适」,并诚实标注 —— **这种组织刚性成本的直接因果估计仍然稀少。**

### 3.6 附:M-x 对抗性机制(red team / devil's advocate)—— 不属于我原来的五格,但 DR 把它当独立一族

**【事实】** 这一族不解决「察觉」,解决的是**偏见与社会抑制**。

- **【事实】** Schweiger, Sandberg & Ragan:辩证探询与魔鬼代言人产生的**建议与假设质量高于共识法**。
- **【事实】** 后续 meta 分析:魔鬼代言人总体上比「只用专家」更有效,但**结果随任务结构变化**。
- **【事实 · 2025 年的一个实验,对本单特别相关】** 指派一名魔鬼代言人,**在收到负面项目反馈后减少了承诺升级(escalation of commitment)**,且在「开放型」和「归咎型」两种错误管理氛围下**都成立**。机制是:让负面信息更显著,并对抗「从项目原本的经济目标漂移到『把它做完』」这种转移。
- **【事实 · 代价,而且是可测量的社会代价】** 魔鬼代言人实验发现**参与者此后与彼此合作的意愿下降**。DR 的评语:这个机制的时机成本**不只是多花的会议时间** —— 制度化的反复异议会改变关系和未来的协调。

**【事实 · 一条打破「心理安全 = 更早叫停」这个口号的直接证据】** 同一个 2025 实验发现:开放的错误管理氛围**既**让人更容易承认失败,**也**增加了冒险意愿,两个效应在总体上**互相抵消**。DR 的评语:这是**不寻常地直接**的证据 —— 一个降低**社会性假阴性**(坏消息说不出口)的机制,可能同时增加**决策性假阴性**(管理者更愿意继续高风险项目)。

### 3.7 一张跨机制对比(DR 原表的关键列,as-of 2026-08-17)

**【事实 · 全部来自 DR 的跨机制对比表】** DR 明确标注:「成本量级」是**跨情境的序数评估**,不是汇总的货币估计,因为**只有少数机制存在可比的成本效果研究**。

| 机制 | 时机效果的证据强度 | 介入延迟 | 假阳性风险 | 假阴性/过晚风险 |
|---|---|---|---|---|
| 触发协议(trigger protocol) | **强—中**(医疗有 RCT/meta) | 认出后数秒—数分 | 阈值敏感则中—高 | 阈值钝或激活被忽略则中 |
| 监测/指标 | 检测**中**;最终结果因果**较弱** | 近实时—报告周期 | 指标有噪声则**高** | 指标滞后/采样差则**高** |
| 升级规则 | 描述性**中**;因果**有限** | 数分—数小时,**随 hop 增加** | 中 | 路由延迟或不升级则中—高 |
| 委派否决/停工权 | 法律与操作文档**强**;孤立因果证据**有限** | **即刻—数分** | 中(打断可能是预防性的) | 社会抑制压制使用则中—高 |
| 时间盒评审 | 描述性**强**;因果时机证据**有限** | **被 cadence 界住** | 低(评审是预期内的) | 中:刚过评审的变化要等下一次 |
| **决策权矩阵/授权** | 决策速度上有**中等**的旁证 | 可显著减少路由延迟 | 低(**它本身不会触发**) | **高 —— 若不与触发器配对** |
| 实时仪表盘 | 信息处理上**中等实验证据**;硬性现场结果有限 | 技术上数秒—数分 | 中—高(显示/告警过载) | 中—高(告警被忽略或数据过时) |
| 阶段闸门 | 操作性**中**;项目证据**混杂** | 闸门间数天—数月;**临近最终承诺时极快** | 中 | **闸门间隔宽则高** |
| 红队/魔鬼代言人 | 实验室/meta **中**;现场硬结果**有限** | 数小时—数周 | 中(过度挑战会拖垮可行方案) | 中(仪式化或社会性弱的挑战会漏掉真问题) |
| 预承诺/分期合同 | 描述与观察**中** | 在里程碑/轮次/合约事件 | 里程碑过时则中—高 | 里程碑抓不到新风险则中 |
| 独立停止委员会 | 统计学理据**强**;组织实证**参差** | 中期分析节奏,数天—数月 | **显式重大**:早停损失精度 | **显式重大**:晚停延长暴露/浪费 |
| 文化 speak-up / CRM | 行为上**中—强**;硬结果**弱—中** | 潜在即刻 | 可变:更多发声也意味着更多低价值信号 | 层级/恐惧下**高** |

### 3.8 按「攻击哪一段延迟」重排(DR 原表,对设计最有用的一张)

**【事实 · DR 原表】**

| 时机瓶颈 | 主要针对它的机制 | 仍未解决的 |
|---|---|---|
| 机构**看不见**变化 | 监测、指标、仪表盘 | 传感器/模型有效性与**注意力容量** |
| 看见了但**分不清信号与噪声** | 阈值、预测、红队、独立监查 | 敏感性/特异性与模型误差 |
| 有人看见了但**没说出来** | speak-up 规范、委派否决、法律保护、CRM | 地位、报复恐惧、激励 |
| 说了但**送错了地方** | 升级规则、决策权分配、ICS | 交接与排队延迟 |
| 决策者**偏向继续** | 魔鬼代言人、独立评审者、分期出资、停止规则 | 评审者偏见、过早停止、新信息 |
| 机构**从不停下来重新考虑** | 时间盒、闸门、operational period | **发生在两次评审之间的事件** |
| 决定了但**执行太慢** | 预写好的响应、委派本地权限、自动化 | 容量约束与实施摩擦 |
| **干预本身是有代价的** | 阈值校准、条件性 hold、重启前评审 | **根本性的假阳/假阴权衡无法被消除** |

### 🔴 A. 「装上去」和「有用」是两回事 —— 本单最该被记住的一条

**【事实】** 2021 年 **Cochrane 系统综述**:装了 rapid-response 系统本身,在若干结局上**几乎没有差别**(low-to-moderate certainty)。而其它 meta 分析确实发现骤停/死亡率下降 —— **系统性证据是不一致的**。

**【事实】** 但 **Kaiser Permanente 的 Advance Alert Monitor**(**预测模型 + 集中监控 + 受训响应者 + 明确工作流**,19 家医院分批部署、人群极大)在被预警的干预组中关联到 **死亡率低 16%**,估算**每年少死约 520 人**。DR 给它的证据等级是「moderate-to-higher 准实验」。

**⇒ 判据(直接对上我们)**:**机制只在「与响应者 + 工作流整合」时才有效,光装上去没用。**
**【推断 · 我的】** 翻译成本单的话:**「总管建起来」不等于「总管有用」。** 真正决定有没有用的,是它旁边有没有一条「谁接、接了做什么」的路 —— 这与 §3.3 那条「阈值被满足了但没人激活」是同一件事的两次出现。

### 🟡 B. 直接回答 Annie 那句「每周一次可能有点频繁」

**【事实】** 关于每日站会的实证:定性田野证据支持它能**快速交换阻塞与信息**,但同时发现**在实现得不好时有大量不满** —— 具体的三个致病条件是:
1. 变成**向管理层汇报状态**(status-report theater)
2. **过于频繁**
3. **时间过长**

**【事实 · 成本量化】** 常见的 15 分钟节奏 = 每位参与者每天 **0.25 人时**;10 人 × 220 工作日 = **每年 550 人时**(还不含后续跟进)。

**【推断 · 我的】** 她担心的「频繁」在证据里**确实是一个已被识别的致病条件**,但它**不是单独起作用的** —— 和它并列的另外两条是「变成汇报状态」和「时间过长」。所以「多久一次」这个问题,在人类那边**从来不是单独可调的旋钮**。我只把这三条摆出来,**不替她选频率**。

### 🟡 C. 阶段闸门:形式化没用,严格的 Go/Kill 才有用

**【事实】** 跨 **161 个业务单元**的对标研究:**严谨的新产品开发流程质量 + 强硬的 Go/Kill 纪律**与更强的绩效相关联;而**仅仅把流程形式化并没有**。
**【事实 · 失效模式】** 橡皮图章式闸门 · 沉没成本升级 · **粉饰预测** · 太晚才取消。

### 🟢 E. 一个「不直接干活的人」到底做什么才有用 —— 部分回答了 A3

**【事实】** 2023 年一项针对 **62 个应用开发项目团队**的研究(Siddiquei, Fisher & Hrivnak)把 temporal leadership 拆成两半:**项目启动时的时间规划** + **执行过程中的时间提醒**。
- 这两项合起来占了被分配的可预测方差的 **91.7%**
- 含全部四个预测变量的模型解释了**按时完成**方差的 **39%**
- **temporal planning 的回归系数 β=.52 显著**,而**传统的 initiating structure(常规的布置任务式领导)不显著**

**【推断 · 我的】** 这条是本单唯一一处**正面**回答「一个不亲自干活的角色做什么才产生效果」的证据 —— 答案不是「有权叫停」,而是**「在启动时规划时间 + 在执行中提醒时间」**。
⚠️ 边界:相关性研究、单项、62 个团队,**不是因果实验**;而且它测的是**按时完成**,不是「转向得对不对」。所以它**不能**被读成「所以总管只要做提醒就行」。
⇒ §1 的 **A3 由「完全未答」上调为「有一条侧面证据」**,但 A1 / A2(权力从哪来、有什么约束)仍然未答。

### 🔴 D. 一条横切所有机制的结构性失效(DR 单独点出)

**【事实 · DR 原文】**
> **权威可以是集中的,而信息是分散的。**
> 守门人无法叫停一个预测已被粉饰过的失败项目;急救团队无法介入一个没人上报的病人;高级运营经理无法在相关可靠性遥测到达之前重新调配工程力量。
> andon、心理安全、自动告警、近实时 SLO 指标这类机制,**主要改变的是信息到达的时间与可信度,而不是最终决策者的法定权限。**

**【推断 · 我的】** 这条和 §3.0 是同一个结论的第二次独立出现 —— 两份不同的 DR、不同的检索,都撞到「**权限不是瓶颈,信息到达才是**」。⚠️ 但注意它**不能**被读成「所以不用管权限」:它说的是权限**不够**,没说权限**不必要**。

## 4. 副轴 · 打断的代价(1045 完全没有的一维)

> 这一维在 FLY-1045 里完全没有,而它决定了任何提醒机制的**上限**。

### 4.1 DR 给出的成本分类(【事实 · DR 原表】)

| 成本类别 | 什么造成的 | 举证 |
|---|---|---|
| **直接运营成本** | 传感器、数据系统、专职响应者、评审人力、训练、独立挑战者 | 一份儿科 MET 分析:**年运营 28.7 万–230 万美元**,取决于人员配置 |
| **注意力/认知成本** | 告警负荷、指标、升级消息、角色复杂度 | 医疗告警研究:某些场景**误报率 72%–99%** |
| **打断/机会成本** | 停产、交易暂停、取消发射、响应者被抽调 | SEC 熔断在特定阈值下**停 15 分钟**;NASA 可能回退到 T−10 或**直接结束当天尝试** |
| **审议/延迟成本** | 闸门、审批、升级 hop、红队评审、委员会 | Scrum 保留固定检视窗口:**每日 15 分钟** + 有时间盒的 review/retro |
| **关系成本** | 结构化冲突、挑战上级、被归咎的风险 | 魔鬼代言人实验:**批判性评估提高,但未来合作意愿下降** |
| **错误成本** | 假阳性干预 或 假阴性不干预 | 熔断可能打断正当流动性;早期预警可能过度告警或漏/延迟 |
| **刚性/期权成本** | 预设阈值与合同在条件变化后变得不合适 | VC 与临床试验治理**显式地**用自由裁量权换取分期或独立决策权;⚠️ **这种组织刚性成本的直接因果估计仍然稀少** |

### 4.2 告警疲劳:量化证据(【事实】)

- 医疗告警研究报告某些场景**误报比例 72%–99%**
- 某学术中心**12 天内超过 59,000 次告警**
- **可改善的证据**:标准化监测流程使**每监护患者日心脏告警中位数 180 → 40**,**误报率中位数 95% → 50%**;另一次干预把误报从 **18.8% → 9.6%**
- DR 的定性:这类机制存在一个**经验上可见的「注意力预算」**

**【事实 · DR 的一句总结,直接对应「实时」这个词】**
> **「Real time」描述的是数据可得性,不必然是人的认知或机构的实际动作延迟。**

**【事实 · 第二份 DR 补的两条成本量化】**
- **常备产能成本**:儿科 medical-emergency-team 年运营 **$287,145 – $2,358,112**(取决于配置)。同一分析还估算:**发生危重恶化的病人比其它 ICU 转入多约 $100,000 的事后成本** —— 这把「准备好的成本」与「反应晚的成本」的取舍**显式量化**了。
- **协调税**:闸门吃高管与项目组时间;站会吃固定团队时间(15 分钟 × 10 人 × 220 天 = **550 人时/年**);告警吃响应者注意力;SLO 执行可能冻结功能吞吐;停线机制**故意牺牲当期产出**。⚠️ DR 提醒:**这些成本随假阳性频率增长**,而组织文献**测收益比测完整时间成本容易得多** —— 所以跨机制的成本效果比较,**光靠已发表研究做不出来**。

### 4.3 注意力残留 / 打断恢复成本

**⚠️【缺席证据 —— 必须如实写】** 这份 DR **没有**覆盖 Gloria Mark 一系的「打断后恢复时间 / 注意力残留」个体认知文献。DR 的注意力成本证据**全部来自机构层面的告警负荷**(医疗告警、仪表盘复杂度),不是个体的任务切换成本。

**【推断 · 我的】** 所以「一次打断实际花掉 Annie 多少」这个问题,**本单目前没有证据回答**。§1 的 I2 保持未答。要答需要单独一次检索,**不在本轮范围**。

### 4.4 一条对「误报 vs 漏报」的关键提醒(【事实 · DR 证据局限一节】)

> **在自动系统之外,假阳性经常被少算。** 一次「预防了事故」的安全干预留下的是一个**模糊的反事实** —— 也许本来就不会出事。自动告警、统计停止边界、交易暂停让「误干预率」比较容易研究;**非正式的领导层转向通常做不到。**

**【推断 · 我的】** 这条对本单尤其锋利:「总管提醒了一次,她照做了,结果还不错」—— 这个观察**无法证明**那次提醒是对的,因为不提醒的那个世界看不到。**这不是可以靠更好的实现绕过去的,是这类机制的固有属性。**

**【事实 · 一条正面回答「反拉伸」的实证】** DR 单独警告:**"多项目" 在厂商材料里经常是含糊的** —— 一个 agent 平台可以连很多代码仓、SaaS 系统、部门、云 project,**同时仍然只是在执行一个更高层的请求**。这与本单开头写死的反拉伸纪律完全一致,而且是外部独立说的。

**【事实 · 一条对我们有利的】** **持久化已经是真的了** —— Google 有长运行时 + session 状态 + 持久 Memory Bank;Devin 能排周期性 session 并保留状态;AWS AgentCore 支持 memory。DR 的结论:
> **一个持续存在的 meta-agent 的技术前提已经具备,与「组织有没有把组合级的转向权交给它」无关。**

**【推断 · 我的】** ⇒ 卡住第四层的**不是技术**。这与 §3.0 那条(时机问题不是权力问题)恰好构成一对:**外面的世界卡在「敢不敢授权」,而人类机构那半的证据说「授权不是关键,信息到达才是」。** 这两条摆在一起是有张力的,我不替她消解。

### 6.4 多 agent 本身的量化证据(这一段对「要不要加层」很硬)

**【事实】** 2026-04 版《Towards a Science of Scaling Agent Systems》:评了 **260 种配置**、5 种架构、6 个基准、3 个 LLM 家族。相对单 agent 基线:
- 在可分解的金融推理任务上 **+80.8%**
- 在**顺序性规划**任务上 **−70.0%**
- **协调收益随底层单 agent 能力上升而递减**;工具密集任务承担多 agent 开销;**没有中心化验证的系统更容易传播错误**

**【事实 · 直接打在本单主轴上】** DR 指出这个实验与「正确时刻」直接相关 —— 一个 supervisor 至少有**三个时机决策**:
1. **什么时候拆解**
2. **什么时候介入下级的轨迹**
3. **什么时候停止协调、开始汇总**

那个 **−70%** 说明:**在错误的结构性时刻发起跨 agent 协调,可能比让一个 agent 自己做糟糕得多。**

**【事实】** MAST 研究:分析 **7 个多 agent 框架的 1,600+ 条标注轨迹**,归纳出 **14 种失效模式**(系统设计问题 / agent 间错位 / 任务验证失败),标注一致性 κ=.88。它的**出发观察**是:**多 agent 的性能收益往往很小,尽管系统复杂度显著上升。**

**【事实 · 运营证据】** Cognition 2026-04 的复盘说其线上设计是「管理者拆活 → 子代理执行 → 管理者汇总」,**不是无结构的蜂群**;并报告了三类问题:**管理者过度指令化**、**下级错误地假定共享状态**、**连贯委派所需的上下文没有被显式传递**。

### 6.5 成本:AI 侧的「协调税」

**【事实】**
- Anthropic 16-agent 编译器实验:近 **2,000 个 Claude Code session**、约 **10 万行**、约 **$20,000 API 花费**;而其企业遥测显示普通单开发者约 **$13/活跃日**、**$150–250/月** ⇒ **密集并行 agent 工作进入了另一个成本区间**
- Devin:**每个下级都是一个完整的 Devin**(自带 VM / 终端 / 浏览器 / 开发环境),管理界面显式暴露每个子代理的 ACU 消耗 ⇒ **委派的边际成本不是多一次函数调用,而是多一条有状态的 agent 轨迹 + supervisor 自己的协调工作**
- AWS 自己的成本指南**明确警告不要用 AI supervisor 做确定性路由**(基于模型的路由制造不必要的推理成本),并建议**把编排成本与工作成本分开计**

**【事实 · DR 的收束】** 这是人类协调税的 AI 版本:人类花会议、评审时间、备用人力、打断容量;agent 花 token、运行时、记忆/状态操作、遥测、工具调用、验证、有时还有重复劳动。**两者在任务高度顺序化、或介入信号很差时,都可能协调所失大于所得。**
