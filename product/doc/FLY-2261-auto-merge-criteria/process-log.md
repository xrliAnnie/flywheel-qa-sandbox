## 1. 收敛结果:判据的现状(她已过卡)

### 1.1 三道闸,全过才进自动道

| 闸 | 内容 |
| -- | -- |
| ① | 改动属于一个**事先画好的类** |
| ② | 有一条**在真环境跑过一次**的证据 |
| ③ | 这一单的**方向**她已经拍过(没过方向门的不进自动道) |

### 1.2 闸① —— 「类」的定义与资格门槛

**定义**:「类」= 一台机器**光看这次改了哪些文件**就能直接判出来的**改动种类**;
不是「这一单稳不稳」的分数,里面**没有任何模型判断**。

🔴 **资格门槛(本轮最重要的产出,由她的质疑逼出)**:

> **一个类别,只有在「不需要任何判断、光看 diff 就能判定」的时候,才有资格进自动道。
> 只要它需要 Lead 读一眼才能定,它按定义就不够格 —— 不是「以后做准一点就能进」,是永远不进。**

| 类 | 机器怎么判 | 状态 |
| -- | -- | -- |
| **纯文档类** | 改动文件**全部**落在 6 个文档前缀下(`doc/` `docs/` `engineering/doc/` `product/doc/` `content/doc/` `marketing/doc/`)**且** ≤ 50 个文件;碰到任何别的文件立刻不算 | **今天就有**(`bridge/ship-relevant-diff.ts`,8 月实测 202 次,docs-only 占 14.4%) |
| 配置 / 开关类 | 只动配置或开关默认值 | 未建;**且只判得了半个**(「这个开关重不重要」看不出) |
| 单点修改类 | 只碰一个模块 + 测试同改 | 未建;**判不了**(要理解模块边界) |
| 新机制类 | 新增别人会依赖的机制 / 改对外行为 | **永不自动** |

⇒ **从纯文档类 14% 起步不是保守,是目前只有它过得了这道门槛。**
   其余三类**不是候选名单**,不会「慢慢放开」—— 要进来得先有人想出一个不需要判断的判定法。

**错判不对称(门槛之所以守得住)**:

| 错判方向 | 后果 |
| -- | -- |
| 本该人看的被判进自动道 | **真代价** —— 只能事后 revert |
| 本可自动的被判出去 | **零代价** —— 落回她手上,与今天相同 |

⇒ 规则只能往一边偏:**有一丝拿不准就不进**。这也是纯文档规则写成「碰到任何一个别的文件立刻不算」而非「大部分是文档就算」的原因。

**不走置信度分数**:分数把一个**可以争论的判断伪装成一个数**。
「0.87」无法反驳 ⇒ 永远不敢放手;「这单算不算纯文档」可以反驳(「不算,它碰了 CI 配置」)⇒ 判据必须是**能吵架的**。

### 1.3 闸② —— 「真环境跑过一次」的强度(她定:强度二)

**强度二 = 两半,缺一半就不算**:

1. **场地**:在 529 房把这条链路**从头到尾真跑一次**(不是单元测试)
2. **证据**:留下一条**外部可查、能被重跑**的记录

⚠️ 她第一次读只读到第 1 半。**第 2 半才是挡住「模型自称跑过」的那道墙** —— 少了它,强度二退化成强度一,而强度一对那 8 条**一条都拦不住**。

**她的授权(已落成规矩)**:

- 默认强度二,不必问她。
- **开机 / 常驻 / 部署**那一类(FLY-2029 型)由 Lead 判定;**强度二证明不了它 ⇒ 不自动,回她手上**。
- 🔴 **自律条款**:「我拿不准」**不等于**退回给她。只有当**那一类改动的性质本身**决定了强度二证不了(例如要证的就是「重启之后会怎样」,而强度二根本不重启),才退回,**并必须写明是哪一条性质**。
  否则「退回给你」会变成免责按钮,她的桌子又满了,这一单白做。

**已知最弱的一环(未解,已对她明说)**:强度二挡不住 FLY-1833 那种 flaky —— 一个 flaky 的端到端测试照样会偶然全绿。目前没有干净的补法。

### 1.4 落地顺序(她定:补法 C)

**先影子跑,再放手**,且从最窄一档起步:

- 影子跑期间**只算纯文档类**,**一次都不真的自动合并**;她的动作零变化、省下的时间为零、出事风险为零。
- 同时记**机器判的类**与**人判的类** ⇒ 两周后产出**错判率表**。
- 放手判据事先定死:**纯文档类错判率为 0 才开;不为 0 连它也不开。**

⇒ 顺序不能反。她的阻塞点**不是**判据准不准,是**「我不太放心」** —— 判据可以论证,放不放心只能拿真数据换;先放手再补数据的话,不放心永远没有东西可以消解。
