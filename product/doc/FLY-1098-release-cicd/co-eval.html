⭐ round-8 核心 · 让它自己发（你只在想拦时出手）

从「你点才发」翻成「默认发，除非你说别发」

关键反转（你要的减负）：上一版第 2 步是你点「发」才发（opt-in，绑住你）。这一版翻成 —— 到点系统默认就把这版发对外，你什么都不用做；只有你想拦时，点一下「别发」。 你从「每天要点」变成「只在不放心时才出手」。

但不是闭眼发 —— 有安全闸

系统只在确认这版稳时才敢默认自动发。稳不稳就看已定的判据 c（看门狗没崩没报警 + bug 数低 + 你没标坏）：

到对外发布的点（每周·可配）→ 系统挑候选 beta
↓ 看判据 c 什么颜色
这版判据 c 是绿 / 黄红？
🟢 绿（没崩、bug 少、你没标坏） → 日报说「今天默认发对外 beta X，想拦在 [窗口] 内点『别发』」
· 窗口内你没动 → 自动发对外（记账：沉默默认发）
· 你点了『别发』 → 停住、这周不发，等下个点或你手动 go
🟡🟠 黄 / 红（崩了 / bug 多 / 你标了坏） → 不自动发，停着
日报说「这版有问题（N 个 bug / 崩过），没自动发。你要坚持发就点『发』，否则等下一版」= 回到你明确 go

一句话：稳 → 默认发、你可拦；不稳 → 停下等你。 加上兜底：发了客户发现坏 → flywheel rollback 秒回上一版。所以「自动」不等于「冒险」。
