🆕 这轮最大的发现

「AI 公司」这个位不但有人占,还免费开源了 —— Paperclip

Paperclip(作者 @dotta,2026-03 发布):一个开源免费的「把你的 agent 组织成一个公司」的控制平面 —— org chart、角色、预算、治理、ticket + 全程记录。「你是 CEO,agent 是员工」。3 周 30K GitHub star、4 月破 43K,史上最快的开源 agent 项目之一。

有意思的是:作者是因为「同时开着 20–30 个 Claude Code 窗口、没人管得过来」才做的它 —— 跟我们的起源痛点一模一样。

对我们意味着什么:加上 Matrix,「把 agent 组织成一整个公司」现在 = 免费 + 开源 + 人人可下。这个壳当差异,已经没有护城河了。

但它有个致命门槛(= 我们的机会)

  • 要你会自托管:自己跑 Node server / Docker / VPS,还得自带 agent —— 一个完全非技术的老板根本装不起来。
  • 它是 generic 框架:给你「搭任意 AI 公司」的能力,但建什么、质量好不好、有没有人买,都是你的事。
由此收窄的真差异(写死):Paperclip / Matrix 给你一个 generic 框架自己拼;Flywheel concrete —— 一支已经组装好、替你建你那个具体产品的团队。通用那层已被免费开源商品化,价值在「具体 + 替你做完 + 一试真能跑」。
你上轮 flag 的硬问题 · 这轮正面答

一个完全非技术的老板,不读代码,凭什么信我们?

别人的「信任」机制(Paperclip 的记录面板、Matrix 的「return proof」、Hermes 的记忆图)—— 对纯非技术都是「一堆看不太懂的日志」。行业数据:只有 6% 的公司完全信任 AI agent 自主干活。所以「信任」得换成他能亲身感知的东西:

⚓ 锚点 · 结果证明:东西你一试真能跑,而且下周还能跑(不崩、持续维护不烂)。这是非技术老板唯一能自己验证的信任 —— 而且恰恰是 Matrix(coding 弱、跑营销生意)和 Paperclip(generic、质量看你自带的 agent)做不到的。信任往这上面压。

另外三件他能感知的事

  • 能对话的 named Lead:你在 Discord 里能直接问它「为什么这么做」「改一下」,像信一个员工 / 承包商,不是信一个黑箱。
  • 批决定,不批 diff:Lead 用大白话说「我打算做 X,行吗?」,你批的是你听得懂的一个决定,不是一屏代码。
  • 能感知的护栏:不 surprise 账单(跑订阅、花费可预测)+ 随时能喊停。

那 PR / CI / code review / QA 呢? → 沉在引擎盖下当质量保证,是上面「一试真能跑、下周还能跑」的底气,不是拿去跟你(非技术)讲的卖点。别人给你看证据;我们给你一个真能用、且有人替你养着的东西。
