## 2. 三块 GTM 情报详情

### ① 定价模型(Annie:套餐 / 档位 / 免费额度 / 计费单位)

- **全行业几乎都是 credit / 用量计费,不是按座位**。计费单位五花八门:Lovable/Base44/Replit 按 credit(建改动作 + app 内用量),Devin 按 **ACU(算力单位)**,Matrix 公测免费、母平台 flowith 按 credit。
- **共同痛点 = 账单不可预测**(Replit「bill shock」、Lovable「隐藏 Cloud+AI 用量」)。非技术用户最恨 surprise bill。
- **免费额度是标配获客钩子**:Matrix 邀请码送额度、Lovable 每日 5 credits、Base44 forever free 25 credits。
- **对我们的启发**:① 定价上我们可以主打「**可预测,不 surprise**」(跑 Claude 订阅);② 但 ⚠️ Matrix 也订阅驱动,别当独有;③ 计费单位选择本身是定位信号——「按结果/按验收」比「按 credit 烧」更贴非技术心智,值得想。

### ② 怎么推广(Annie:渠道 / messaging / 爆款内容 / KOL / demo 病毒)

- **build-in-public 是这波 AI builder 的共同引擎**:Lovable 全员在 X+LinkedIn 发、内部频道 2 小时内互相转发;Base44 创始人 LinkedIn 第一人称连载(产品/反馈/局限都发)。
- **用「产品自己干活的 demo」当病毒素材**:Matrix 在 X 上演示 agent 端到端写爆款 X 内容(用产品证明产品);Lovable 全员用 Lovable 建 side project 再晒。
- **KOL / 多渠道飞轮**:Lovable 识别 249 个 X influencer、跑 12+ 渠道让每个渠道给下一个引流(PH→GitHub star→播客→X→再回 PH)。**几乎零付费广告**。
- **中文圈**:Matrix 走**小红书**(Annie 就在 XHS 刷到)——对我们如果要打中文非技术小企业,这是可复制的渠道洞察。
- **对我们的启发**:最强的病毒素材是「**让 AI 团队当着人面把一个真东西建出来**」的 demo;build-in-public + 产品自传播比投广告更适合我们这种叙事强的产品。

### ③ 怎么获客(Annie:试用 / waitlist / PLG / 销售驱动)

- **PLG(产品驱动增长)+ 病毒环是主路**:Base44 的 onboarding「**招募布道者而非转化用户**」——用户一旦几分钟内看到 idea 变成能跑的东西,就自发去晒。Lovable $100M ARR **零付费获客**。
- **邀请码稀缺 + 推荐环**:Matrix invite-only + 每人 2 个邀请 → 组织式病毒扩散 + 稀缺感。
- **只有 Devin 偏销售驱动**(企业自上而下),但也用降价($500→$20)打开个人自助档。
- **对我们的启发**:我们「一整个 AI 团队替你建软件」的**首次体验**必须像 Base44 那样「几分钟看到真东西」才能触发自传播;邀请环 + 免费额度是低成本获客范式。

## 3. 产品洞察:桌面 App vs 手机验收(Annie 明确要记)

**Annie 的洞察(成立)**:Matrix 绑 **macOS 桌面 app** = 她**只带手机时无法验收**;Flywheel 长在 **Discord(手机端一流)** = **随时随地可给方向 + 验收** = 真差异点。

各家「手机能不能用/验收」实况:

| 竞品 | 可达面 | 手机能验收吗 | 备注 |
|---|---|---|---|
| **Matrix** | **macOS 桌面 app ONLY** | **❌ 不能** | Apple Silicon 限定;评论区有人抱怨「要开盖才能工作」。**这就是 Annie 抓到的弱点** |
| Lovable / Base44 / v0 / Bolt | web | ⚠️ 勉强 | 浏览器手机能开,但在手机上 prompt/改 app 体验差 |
| Replit | web(+历史 mobile) | ⚠️ 一般 | 云 IDE 手机端受限 |
| Devin | web + **Slack** | ✅ 可(Slack 手机) | Slack 派任务/看进度手机可达 |
| Hermes Agent | 自托管 daemon + 接 16+ 消息平台 | ✅ 可(但要先会自托管) | 面向技术人 |
| **🎯 Flywheel** | **Discord(桌面 + 手机原生)** | ✅✅ **一流** | founder 只管两头,**手机上就能给方向 + 验收 PR** |

**结论(喂定位)**:「**在手机上、在你已经在用的 IM 里,随时给方向 + 验收**」是我们相对 Matrix(桌面绑定)的**具体、可感的差异点**,建议写进 FLY-908 产品形态。⚠️ 注意:Devin/Hermes 靠 Slack/消息平台也部分解了这个痛,所以「手机可达」本身不独有;**真正独有的是「非技术 + 手机 IM + 一整个团队 + 工程级验收」的组合**。

## 4. Annie 能直接学的 GTM playbook(提炼)

1. **build-in-public**:创始人/团队在 X(或中文圈用小红书)第一人称连载做产品的过程,比投广告更适合叙事强的产品。
2. **产品自传播 onboarding**:让用户几分钟内看到「真东西被建出来」→ 他自发去晒 → onboarding 招募布道者。这是 Base44/Lovable 病毒的核心。
3. **最好的 demo = 产品当众干活**:Matrix 演示 agent 写爆款 X;我们可演示「AI 团队当众建/修一个真功能」。
4. **邀请码稀缺 + 推荐环 + 免费额度**:低成本获客三件套(Matrix)。
5. **几乎零付费广告**:头部都靠 PLG + 内容 + 社区,不烧广告($100M-$400M ARR 级别都这么起来的)。
6. **中文圈用小红书**:如果打中文非技术小企业,XHS 是被验证的渠道。
