你的问题 ③ · 节点三 —— 这一格结论最硬

语音线 —— 前台那半 Astra 直接用不了

先看清楚它是两层,不是一个东西。这是我们自己 FLY-1911 实测出来的结构:

你说话 │ ▼ [ 前台:耳朵 + 嘴巴 ] ← 负责听清、马上应声 │ 它把任务交办给下面这层 ▼ [ 后台:真正干活的那个 ] ← 跑命令、查东西 │ ▼ 把结果念给你听
  • 前台那层:Astra 用不了。OpenAI 官方 API 文档把「实时语音」「实时转写」「音频进出」全部列为不支持。它只吃文字和图片,只吐文字。
    而且我们这边还有一层:Codex 的前台语音层有它自己独立的模型设置,跟我们平时改的那个「模型」根本不是同一个键 —— 就算改了也改不到耳朵嘴巴。
  • 后台那层:理论上可以换成 Astra,但大概率帮倒忙。语音的体验瓶颈是快不快,不是聪不聪明。我们实测过:它张嘴要 610 毫秒,真去干一圈活要 19.2 秒。Astra 没有「不思考」这档,后台换它只会让那 19.2 秒更长。
  • 最大的痛点根本不在模型上。你体验过的那个「问完 19 秒没动静」,原因是「先应一声」这个功能只在 v3 通道生效,而 v3 通道现在被上游堵着(我们实测两次都是 401,同账号 v2 却正常)。换 Astra 不解这个。
  • 🔎 一条新信号,可能比换模型更相关:Codex 命令行工具 0.153.0 的更新日志里出现了一串「原生语音」相关的改动(语音宿主生命周期、原生语音依赖构建)。这可能是我们语音线真正该跟的东西 —— 建议单开一单看,不在这一单里做。
