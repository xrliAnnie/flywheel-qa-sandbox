## 抓取层:三条实测发现(设计里编不出来的)

### 1. 程序化滚动无效,必须用真实滚动事件

`window.scrollTo(0, scrollHeight)` 打不动 X 的懒加载 —— `scrollY` 卡在 8357 不动、页高维持 10027。
换成扩展的真实滚动事件后:页高 **10027 → 15343**,条目 **10 → 21**。

⇒ **这条要写进实现约束。** 谁按「用 JS 滚到底」去实现,会拿到一个静默只出 10 条的采集器 —— 而且它看起来是成功的。

### 2. 单次工具输出上限约 1200 字符,是真实的传输瓶颈

20 条(5.3 KB)一次取不回来,得分块。剪贴板桥接两条路都失败:
`execCommand('copy')` 无用户手势返回 false;`navigator.clipboard.writeText` 报 `NotAllowedError: Document is not focused`。

⇒ 将来做成 skill 时,采集端应当**直接落盘**,不要经过对话通道往回搬数据。

### 3. 两个账号高度重叠

`@sunyuchentron` 基本是 `@justinsuntron` 的中文镜像 —— 「91B」「Messari Q2」「Clarity Act」三条两边都有。
**加第二个账号带来的独立条目远少于翻倍。** 去重要在配置层就当成一等公民,不是事后补丁。

## 🔴 Chrome 断连,反而抓到一个会让整页失效的 bug

`list_connected_browsers` 返回 `[]`,扩展完全断连。**没重试、没绕路**(这是既定规矩),
但**没有因此跳过验证** —— 改用浏览器之外能做的:把内联脚本抠出来解析。

**结果:生成的脚本里 `lines.join(` 后面是一个真换行 → 页面 JS 整体解析失败 → 所有按钮全死。**

根因:这一轮用 shell heredoc 重写生成器,**模板字面量里的 `\n` 被 JS 当成真换行输出**
(上一版写的是 `\\n`)。

> ### ⚠️ 这条是本轮最该记住的
> **出事时所有静态门全是绿的** —— 0 inline handler、nonce 在、文档完整、三态 CSS 在、计数一致。
> **只有真去解析那段脚本才发现。**
> 这就是这个 issue 一整天在数的那个形状:**系统给一个坏掉的东西套了一身绿灯。**

**修法不是只改那一处**,而是给生成器加了**生成期自检**:
写文件前先 `new Function()` 解析自己产出的脚本,不过就**拒绝写**。

**而且拿阴性场景验了这个自检**(阳性对照):故意打回坏写法 →
自检抛出「内联脚本语法错误,页面 JS 会全死」并拒绝生成;恢复后正常。

> **一个没被阴性验证过的检查,本身就是下一个假绿。** 加检查和验检查是两件事,两件都要做。

### 第六轮 — Annie 读完真早报提的两条(2026-08-12)

原话:「让我留comments的部分,你不用给我收起来了,全部都自动打开就行」
「每个tab都是从一开始重新标就行了」

**① 备注框默认展开。** 用 `<details open>` 而不是干脆去掉 `<details>`,两个理由:
summary 那行「+ 备注」同时是这个框的标签,去掉就剩一个没标签的秃 textarea;
而且复制失败那条兜底靠 `closest('details')`,details 没了它会空跑。
她要的是「默认打开」,不是「不许合上」。

**② 编号按 tab 各自从 1 数。** GitHub 面 1..18(两节连着数),X 面 1..6。
**在建模型时按 tab 定死,不在渲染时按数组下标算** —— 切 tab 只是 hidden 的显隐,
DOM 一直都在,按下标算出来的号跟「它在自己 tab 里排第几」是两回事。

**一个差点被忽略的连带风险:改编号会不会把她已经写的备注冲掉?**
不会,而且不是运气 —— 备注的 localStorage 键是 `gh:<repo>` / `x:<推文id>`,
是**内容派生**的,不是位置派生的。实测刷新后键仍是 `x:2086548276053180892`,
跟它现在显示成 1 还是 19 无关。如果当初图省事把键写成编号,这一轮的改动会**静默
清空她写过的所有备注** —— 而且页面看上去完全正常。

### 两条新的生成期硬门(都跑了阳性对照)

- **备注框必须是展开的**:只数个数不够 —— 折叠着的也是 24 个。所以数的是带 `open` 的。
  对照:把 `open` 拿掉 → 拦住,报「展开 0 个,应为 24 个」。
- **每个 tab 的编号必须恰好是 1..N,N = 该 tab 的真实条数**(算出来的,不写死)。
  对照:改回全局连号 → 拦住,报「x 面编号不是 1..6,实际是 19,20,21…23,24」——
