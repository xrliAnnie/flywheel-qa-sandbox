# FLY-1704 早报 feed 的 UI 方向 — 探索

Issue: FLY-1704 (https://linear.app/geoforge3d/issue/FLY-1704/design-早报-feed-的-ui-方向-先-research-再出几版-mockup-让-annie-挑不动内容采集)
日期: 2026-08-11
基于: 无（本单是 FLY-1410 的刹车单，不是它的下一轮）

---

## 1. 这一单在解决什么

Annie 原话：「我觉得这个早报的格式我还是不太喜欢……**我们先把这个 feed 的 UI 大概定一下**」。

FLY-1410 从 v4 迭到 v8 一共五版，**每一版改的都是内容和细节**（编号、备注框、中文总结、去图、去社交卡），
**版式本身从来没有被单独拿出来定过**。所以这不是「再改一版」，是**先定壳**。

一句话：**这单只解决「一条 feed 长什么样」，不解决「一条 feed 里写什么」。**

---

## 2. 明确的边界（照抄派单，不扩不缩）

| 做 | 不做 |
|---|---|
| research：这类 feed 好看的做对了什么（带真实截图/链接） | ❌ 改内容口径 |
| 3-4 个**明显不同方向**的 mockup，用**真实 v8 数据**渲染 | ❌ 改采集 / 碰 `build-brief.mjs` 的数据逻辑 |
| 让她能并排看、直接指「要这个」 | ❌ 出「一版完美稿」 |
| | ❌ 上线 / 替代 v8 |

**内容口径已经过她认可，本单不推翻**：底数诚实、每条四段讲解、X 卡中文总结在上、无图。
四段（这是什么 / 为什么值得你看 / 跟我们什么关系 / 哪里能借鉴）**信息一条不能丢**，
但**「怎么把这四段摆在纸上」是本单的自由度**。这条区分是整单的地基。

---

## 3. 我把「不喜欢」翻译成了什么（假设，要她证伪）

她说的是「格式」，没说哪里坏。我不猜她的用词，我去**量**了 v8 的版式本身
（在 v8 线上页跑 DOM 测量，数字见 `research.md §1`，可复跑）。以下是**实测**，不是我的审美意见：

1. **一张卡有 10 个带边框或底色的容器**（实测 `boxedPerItemMax = 10`，含卡片自己）——
   卡片投影、左侧色条、编号块、灰底代码框、4 行标签行、绿底核验条、备注框……
   眼睛必须先解析结构，才能开始读内容。**24 条全部被围成卡片**（`fullyBoxedItems = 24/24`）。
2. **框中框嵌套 4 层**（卡 → 代码框 / 标签行 / 核验条 / 备注框）。这是「看起来像后台管理系统」的头号来源。
3. **四段等权重**：同字号（14.5px）、同颜色、同间距。**没有任何一处告诉眼睛「从这里开始读」**。
4. **整页有 74 个字段名单元格**（实测）：「这是什么」×18、「跟我们什么关系」×19、
   「哪里能借鉴」×19、「为什么值得你看」×13、「为什么没深入」×5。
   每个占掉固定 104px（卡宽的 12.7%）。**它们是表单标签，不是内容。**
5. **25 个空备注框常驻**（实测）：占了真实视觉重量，但绝大多数时间是空的。
6. **蓝 / 绿 / 灰三种底色块**混在一页里，彼此没有语义顺序 —— 读者不知道哪个更重要。
7. **正文行宽 665px = 每行 46 个汉字**（实测），高于中文舒适区（约 30–40 字/行）。
   **整页 9,790px 高 ≈ 11 屏**（900px 视口）。
8. **没有排序**：24 张卡平铺，第 1 条和第 18 条视觉上一样重。她想「只花 3 分钟」时，页面帮不上忙。

**假设（她可以直接否）**：她不喜欢的不是"哪个颜色不好看"，
而是**这一页把「读物」做成了「表单」**。四段内容是好的，装它的那个壳是行政表格的壳。

> ⚠️ 这是我的诊断，不是她说的。如果她的真实不适在别处（比如太长、太密、字太小），
> 那 4 个方向里应该有一个能命中；如果一个都不命中，**她说「都不对，因为 X」也是有效结果**，X 就是下一轮输入。

---

## 4. 为什么用「几个不同方向」而不是「改一版」

改一版只能沿着当前这个壳做局部优化 —— 那正是 v4→v8 五轮做过的事，且已经证明收敛不了。
**几个方向的价值在于它们赌的东西不同**，她挑的其实不是好看，是**赌哪一件事最重要**：

- 赌**扫得快** → 极简电报
- 赌**读的时候不被打断** → 左栏元数据 + 右栏散文
- 赌**替她做减法** → 杂志式头条制
- 赌**先看全局再钻细节** → 密集工作台

四个方向都能装下同样的四段内容，区别只在**摆法**。她指哪个，我们就知道她真正要的是哪种阅读方式。

---

## 5. 待她拍的（不在本单自行决定）

1. **方向**：A / B / C / D 选一，或者「都不对，因为 X」。
2. **备注框怎么活**：v7 她要求「每条一个、能 copy paste」。四个方向对它的处理不同
   （常驻 / 收起 / 移到侧栏 / 变行尾图标）。这条是她的既有要求，**我不擅自砍**，只在方向里给不同摆法。
3. **要不要排序**（只有方向 C 需要）：C 假设 18 条不是平的、有头条。如果她认为「都一样重，我自己挑」，C 就出局。
