路线:三小块,每块独立能上线、能验证

原则:先用一类高频小决策跑通闭环(你能亲眼看到它真的替你拍对了),再一类一类加宽。不一上来铺全套阶梯。

1

影子跑:让它先「偷偷预测」一类小决策 产出:学习曲线

选一类高频、纯可逆的小决策(建议:issue 归类/排优先级)。Lead 照常做,系统在背后记「CIPHER 会怎么拍 + 拍得像不像你」,不改变任何行为、零风险。

验证 拿历史决策回放对比预测准确率;把握度随样本上升。你会看到一张「它学到几成像你」的曲线。

2

接通:高把握 + 你解锁的,真自治 产出:第一类真自治决策

给这类决策加一道闸(业界同款):动作可逆(不碰 4 类地板)+ 成熟度到「可信」+ 把握 ≥0.80 + 你点头解锁了这个 pattern → 自动做 + 告诉你;差任何一条 → 还是建议等你点头。

验证 解锁一个 pattern 看它真自治;故意塞一个碰地板的 case 确认被闸挡回;你一键收回立即生效。

3

面板:等级卡 + 一键收放 + 每日抽检单 产出:你的控制台

每个 Lead 一张卡:哪些 pattern 学到几成、哪些已解锁;你在这里一键解锁/收回。自治动作进每日 digest,你标「对/错/特例」——标错的自动降回建议档。

验证 面板解锁 → 块 2 生效;digest 标错 → 该 pattern 掉档。

之后:同一套模子(影子→闸→解锁→抽检),一次加一类可逆决策,每次都独立可上线。

🔒 贯穿全程不动的地板:花钱 / 真不可逆销毁(含 retry) / 安全权限 / ship·merge·runner 生命周期 —— 4 类永远先被闸住、永远问你。PR 合并那条「永远问你」的现状保持不动。
