# FLY-922 方法对比 — 从 DR 里挑真能落地的(不锚 CIPHER)

Issue: FLY-922 · 日期: 2026-07-06 · 基于: research.md §8(ChatGPT DR)+ Annie「CIPHER 不是对的打法」反馈

---

## 0. 为什么 Annie 的直觉是对的(先自我纠错)

CIPHER 本质是 **approve/reject 计数器**:按粗粒度维度 key 数「这类 PR 她批了几次」,**完全不记「她为什么这么拍」**。而 Annie 给系统的真实信号恰恰是**带理由的语言纠正**(「不对,因为 X;以后这类要 Y」)——120 条 feedback memory 每条都有 Why。计数器吃不下这种信号,理由才是能迁移到新决策的东西。且 CIPHER 绑在 PR 审批(地板动作)上。**「现成」不等于「对」,方法要跟着信号形态走。**

## 1. 候选 A:Ripple-Down Rules(RDR)——「破例先记,同类反复才升成规则」

**是什么**:1980s 起于医疗专家系统、在病理实验室**生产环境验证过多年**(PEIRS 系统)的增量规则维护法。机制:系统按规则树给结论;专家不同意时,**就在触发的那条规则下面挂一条例外规则**,条件 = 本 case 与该规则「奠基案例」的差异;每条规则永远绑着造出它的那个真实案例。知识获取 = 日常使用中的维护,**不需要一次性写全规则**。

**怎么实现(我们,零新基建)**:
- 规则 = markdown 决策规则文件 —— **现有 120 条 feedback 的 How-to-apply 就是雏形**;奠基案例 = 已有的 originSessionId。
- Lead 做决策时,LLM 沿规则树走出结论 + 引用是哪条规则;
- Annie 纠正一次 → 系统**自动起草一条例外规则**(带本 case、标差异条件)→ 她一键确认收进树。
- 置信 = 每条规则自己的战绩(命中多少次、被纠正几次)。

**适合度:极高。** 她的纠正天然就是「例外先记」;规则可读可改可撤(她能打开看「你学到了我什么」);十几条数据就能跑,不存在过拟合问题。

**第一片怎么建**:把 120 条 feedback 蒸馏成**一棵 triage 决策规则树**(默认规则 + 已知例外,1 个文件)→ **shadow 跑**:每次 triage 规则树也出答案,对比实际,不一致就起草例外 → 一致率够 + 她抽查 OK → 对她解锁的类别走「做+告知」。

## 2. 候选 B:Case-Based Reasoning(CBR)—— 先例检索

**是什么**:新决策 → 检索最像的过往案例 → 沿用其结论(必要时修订)→ 本决策存回案例库。DR 点名它「对 founder 委托异常贴合」:founder 决策本来就是类比式(「这像 3 月批的 Acme,差别是有法务风险」),解释性最好。

**怎么实现**:决策 episode 结构化存(context/选择/**理由**/结果)→ 新决策检索 top-k 先例喂 LLM 出建议 + 引用先例 → **无近似先例 = 自动弃权问 Annie**(天然的 conformal 弃权)。LLM 时代 = 检索增强 few-shot,实现极自然。

**适合度:高。** 解释性最好、弃权行为天然;短板是「规则」不显式(泛化藏在 LLM 里),Annie 想审「你学到了什么」时不如一棵规则树直观。

**第一片怎么建**:把 56 个 decision snapshot + 120 feedback 变成可检索案例库,同样 shadow 对比。

## 3. 不推荐单独用的(诚实淘汰)

- **CIRL**:理论框架(人知道 reward、agent 不知道、含教学行为的合作博弈)——心智模型有价值,**没有我们规模可落地的工程形态**。pass。
- **CIPHER 单干**:计数器不吃理由;绑地板动作;她的直觉对。**但它的 snapshot/outcome 记录管道可以留着当数据源之一**,不当骨架。
- **conformal 弃权 + graduated autonomy(shadow→建议→自治)**:不是独立方法,是**安全壳** —— A/B 谁当骨架都要套这两层。

## 4. 推荐:RDR 为骨架 + CBR 当证据层(套 弃权+渐进 安全壳)

- **RDR 规则树 = 「Annie 决策宪法」的活版本**:显式、可读、她可直接改;每条规则绑真实奠基案例。
- **CBR 案例库 = 规则的证据层**:每条规则的例外来自具体案例;规则树没覆盖的新情况 → 先例检索给参考、没先例就弃权问她。
- **拿不准 → 弃权问她**(conformal 思想);**shadow → 建议 → 做+告知** 渐进(graduated autonomy);reserved 4 类地板照旧永不进。

**为什么比 CIPHER 对(一句话)**:CIPHER 数她「批了没」,RDR/CBR 记她「为什么」—— 她的决策力值钱在理由,理由才能替她拍新决策。且全程可读可改可撤,10-100 条数据刚好够用。

**第一片(具体)**:① 从 120 条 feedback 蒸馏 triage 规则树(1 文件、1-2 天);② shadow 跑 2-4 周记一致率(零风险零行为改变);③ 一致率达标 + Annie 抽查认可 → 她解锁的类别进「做+告知」。每步可验证、可叫停。
