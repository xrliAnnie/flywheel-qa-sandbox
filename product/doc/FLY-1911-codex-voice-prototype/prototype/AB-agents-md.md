# A/B:同一份载荷,两条投递路径(FLY-1911)

**问题**(Lead 定的形状):她要的是**让文件夹本身携带身份**;我们现在的做法是**会话创建时注入**。
⇒ 先不设计「转换」,**把同一份内容写进 `~/.codex-honeylemon/AGENTS.md`**,再和注入那条路比。

```
A  会话创建时注入 baseInstructions(现状,已在用)
B  只靠 CODEX_HOME 里的 AGENTS.md(⛔ 完全不注入)
```

## 载荷
`make-agents-md.mjs` 生成,来源四个:identity + 记忆索引 + 数据地图 + founder-only-authority 合同。
**实际大小 73,354 字符**(⚠️ **不是先前说的 99,236** —— 记忆索引 8/21 23:43Z 被压过,42KB→14KB;
所以生成脚本每次都打印实际字符数,⛔ 别引用旧数字)。

## 🔴 A/B 顺带抓出一个我自己留下的缺陷
A、B **两场都教了一个早就不生效的用法**(`<命令> | hl-tell-lead.sh '…'` 这种管道写法)——
因为数据地图里**旧那一行还在**(我改写那一节时只换了文末,漏了正文里的指针)。
⇒ 已改成 `hl-tell-lead.sh [--check <名字>] '要说的话'`,重新生成 AGENTS.md 并复跑 B:**它现在教的是新写法**。
📌 **一份文档里同时存在新旧两种写法时,它会读到先出现的那一个。**
