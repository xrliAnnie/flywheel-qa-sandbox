# 判别实验:空转之后,第一问就问【必须用工具才能答】的题(⛔ 跑前写死)

## 条件
· 桥 `HL_WAIT_HUMAN=0`(**回到旧行为:桥起时就建会话**)—— 因为要的是「一个已经放凉的会话」
· 空转 **660 秒**(11 分钟,落在会失败那一档)
· 然后探针进房,**第一问**就是记忆题:「在你的记忆目录里找一下 FLY-1038 那一条,告诉我它说的是什么」
  ⚠️ 故意**不报文件名** —— 上一次语音把文件名听坏了,污染了那一格

## 判据(二选一,跑完不许改)
```
A  它跑了命令(RUN ≥ 1)并答出 FLY-1038 的内容
   ⇒ 病在【议题那一问】本身:空转之后它照样会用工具,只是【议题那一问】它认为不需要查
   ⇒ 方向整个变(不是「冷开场不查」,是「它不知道议题需要查」)
B  它 0 条命令、答不出/说不知道
   ⇒ 病在【第一轮】,与议题无关 ⇒ 「空转后第一轮不伸手拿工具」成立
```
## 边界(写在前面,免得跑完自我加码)
· **n=1**。⛔ 不拿一场当定论,只当把两条路分开的第一刀。
· 若出现第三种(跑了命令但答错 / 转写又坏了)⇒ **照实报第三种**,⛔ 不硬塞进 A 或 B。
