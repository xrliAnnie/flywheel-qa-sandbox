# 把「它打算干什么」念出来 —— 两段真跑的录音

**这不是模拟,是房间里录下来的。** 两段都来自真实会话,从她问完开始。

| 文件 | 条件 | 里面有什么 |
|---|---|---|
| **A** 等待音开着 | **和她真正会用的一样** | 她问 → 4 秒后另一个嗓子念出它的打算 → 等待音 → 它说答案 |
| **B** 等待音关着 | ⚠️ 和她真正会用的**不一样** | 同上,但**中途换了一句预告**(它改主意了)⇒ 能听到**切换那一处** |

⚠️ **B 之所以关掉等待音**:要听的是**两句预告之间的接缝**,等待音会盖住它。
⇒ **B 不代表她实际会听到的样子;A 才是。**

## ⚠️ 一件必须先说的事实(⛔ 只讲事实,不讲我们的预期)

**念这句话的是【另一个嗓子】,是故意的。**
> **它自己的嗓子念不了这句** —— 实测过两次:
> **对话里让它照念,它可能拒绝;写进建会话的指令,压不住它的开场白。**

## 这一档的账:**跑通了 ≠ 量到了**

```
✅ 已量到  不推迟答案(她问完 → 答案 25.8s / 26.2s,和没有预告时同一区间)
✅ 已量到  答案到达时预告已经停了
✅ 已量到  不产生虚假的「她说话了」
⚠️ 未量到  预告出声的及时性 —— 阈值待定:环境常数(传输 480ms)刚量到,新形状还没跑过
⚠️ 未量到  切换处有没有断口 —— 读代码是结构上不可能;实测的尺子不合用,没能证实
```
> 🔴 **四场真跑没出过异常,是一句关于【功能】的话,不是一句关于【质量】的话。**
