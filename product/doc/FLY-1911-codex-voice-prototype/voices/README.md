## 一致性(照实,不修饰)

- **10 / 10 都保留了英文 `code review`** —— 加那句约束之后没有一个翻成中文
- 大小写有差异:`code review` / `Code Review`;`Flywheel` / `flywheel`(**听觉上无差别**)
- 动词有差异:**看 / 处理 / 查看** —— 三种说法,长度接近
- 时长 4.3s ~ 7.6s ⇒ **coral 最长(7.6s)、cedar 最短(4.3s)**,那是它话多话少,不是语速
- **十段音量归一到同一峰值** ⇒ 她比的是音色,不是录音电平
