## Spike β detail

Smoke test script: `scripts/spike-mailbox-wake.sh`.

Steps:
1. Create real-`$HOME` team file at `~/.claude/teams/fly142-spike-<pid>/`
2. Spawn Runner inside tmux pane with team flags + `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`
3. Wait 12s for REPL initialization
4. Append sentinel message to `inboxes/spike-runner.json` (raw JSON write, not via SendMessage)
5. Poll tmux pane every 2s for `ALPHA-OK` token

**Result**: Runner echoed `ALPHA-OK` within ~6s. Mailbox file showed `"read": true` post-delivery.

Pane snapshot (relevant lines):
```
@spike-lead❯ spike test sentinel

⏺ ALPHA-OK
```

Exactly matches `useInboxPoller.ts:843` idle-submit behavior — message delivered as user turn.

## Spike γ argument

Spike β proved the mailbox file write → useInboxPoller delivery wire. The Lead's `SendMessageTool` (when LLM-invoked) calls the same `writeToMailbox` function (`teammateMailbox.ts:134`). So:
- If Lead runs with team flags + env var → SendMessageTool is enabled
- Lead LLM invokes SendMessage → calls writeToMailbox → writes target inbox JSON
- Target Runner already proved to wake (spike β)
