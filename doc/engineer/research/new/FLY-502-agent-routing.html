● 市面其它 coding agent，谁能当 Flywheel backend？

过滤器 = ① headless/CLI agentic（非纯 IDE）② tmux 可驱动 ③ 可插模型。行业现状：65% 工程师每天用 2 个 coding agent——多 backend 本就是常态。

结论 backend 选型

Flywheel 现有四后端（Claude/Codex/agy/Kimi）已覆盖前沿。真正值得追加评估的 backend = OpenCode（MIT、Claude-Code-shaped、任意模型——最契合 agent-agnostic 策略），其次 Cline / Goose。IDE（Cursor/Windsurf）和托管平台（Devin）不契合 headless-runner 模型，不作 backend 候选（可作 Annie 个人开发工具）。参考：Terminal-Bench agent 榜 Codex CLI 83.4% 第一、Claude Code 78.9% 第二。

● Gemini 3 Deep Think + 3D 建模（FLY-451）

「Gemini 做 3D 打印模型」那个能力，agy 拿得到吗？→ 拿不到

Deep Think = 最大并行推理（"System 2"），建在 3.1 Pro 之上。2026-02 升级后能读手绘草图 → 验证结构 → 导出可制造 3D 模型：算载荷路径、建议材料厚度、为 SLA/SLS 优化拓扑——直接对口 GeoForge3D。

关键
Deep Think 仅 Google AI Ultra 订阅（Gemini app）+ 限量 API 早期访问
它是一个模式，不是广泛开放的 model slug。每次查询要几分钟。HLE 41.0%、ARC-AGI-2 45.1%、奥赛金牌级。
agy 现状
agy models = Flash / 3.1 Pro / Claude 4.6 / GPT-OSS —— 无 Deep Think slug
agy 的 Gemini 天花板 = gemini-3.1-pro 标准模式，不是 Ultra 独占的 Deep Think。Deep Think 锁在 Gemini app，不在 Antigravity CLI 货架。
怎么办
要「草图→3D 打印模型」→ 走 Gemini app 上 AI Ultra（$99.99 入门 / $200 顶配）
不是 agy CLI。agy 适合编码 / 标准 3.1 Pro 任务（视频分析、Nano Banana 生图），但今天解锁不了 Deep Think 的 3D 能力。verify-later：agy 模型表日后可能加，依赖前重跑 agy models。
走 API 多少钱
没有独立的「Deep Think」per-token SKU — 不建议自接 API
按 Gemini 3.1 Pro token 计：$2/M input（≤200K）、$12/M output，>200K 翻倍（$4/$18）。但 Deep Think 把内部 thinking token 当 output 计费 + 海量并行推理 → 单次查询的计费 output 远高于普通 3.1 Pro，实际单次成本放大数倍，每次还要几分钟。API 走 Google Cloud 早期访问（限研究/企业）。结论：Annie 走 AI Ultra 订阅（$99.99 起）最直接、最划算，别为 3D 自接 API。
