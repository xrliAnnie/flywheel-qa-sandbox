### 1. $ 重定义为「真实成本估算」+ 诚实脚注

- 现文案：「重量(weight)·非账单」。改成「**成本估算**」。
- **诚实脚注（不可省，Lead 强调）**：`USD = 按各模型公开 API 单价 × token 用量估算的成本（订阅制下为参考成本、非实际账单）`。
- 涉及文件：`render-html.ts`（summaryCard / modelCard / subtitle / footer / comparisonHero）、`render-text.ts`。

### 2. $ 自适应精度（小额不再显 $0）

新增共享 `formatUsd(micro)` 放 `pricing.ts`，HTML + text 复用（去掉两处重复的本地 `usd()`）。**先按分四舍五入再分档**（Codex R6，避免 `99.995`→`$100.00` 怪值）：

| usd 区间(已四舍到分) | 显示 | 例 |
|---|---|---|
| `>= 100` | 整数 + 千分位 | `$6,518` |
| `>= 0.01` | 两位小数 | `$77.30` / `$0.42` |
| `> 0 且 < 0.01` | `<$0.01` | |
| `<= 0` 或 非有限 | `$0` | 防御 NaN/Infinity/负数 |

边界测试（Codex R6）：`0` / 负 / `Infinity` / `NaN` / `0.009999` / `0.01` / `99.994` / `99.995` / `100` / `1000+`。

### 3. 单价表可配置

- `pricing.ts` 加 `loadPricingConfig({ file?, env? })`：base = §0 修正后的权威 `MODEL_RATES`。
- 覆盖来源：`opts.file` → `env.TOKEN_USAGE_PRICING_FILE` → `~/.flywheel/token-pricing.json`。文件存在且合法 → 逐 model 覆盖 / 新增。**每字段仅当 `Number.isFinite(v) && v >= 0` 才接受（Codex R3：负有限数也是非法外部输入，会算负成本被 formatUsd 的 `$0` 掩盖）；任一字段不合法 → 整个 model 跳过 + warn，绝不产出 NaN/负值**。解析失败 → warn + 回退默认（不 crash 报告）。warn 走 stderr，`--json` stdout 仍可解析。
- `costMicroUsd(model, t, rates = MODEL_RATES)` 加可选 `rates` 参数（向后兼容）。
- rates 经 `aggregator.aggregateDaily(records, { rates })` → `pipeline.aggregateAndPersist` → `cli.ts`（启动时 `loadPricingConfig()` 一次）注入。
- **注意**：成本在聚合时算并入库 → 改价只影响**新聚合**的当天/昨天（daily 脚本每次重聚合 today+yesterday）= 正确（历史行保留当时价）。

### 4. issue 引用可点链接

- `render-html.ts`：项目卡里「已完成 issues」的 `FLY-XXX` 包成 `<a href="https://linear.app/<ws>/issue/FLY-XXX" target="_blank" rel="noopener">`。
- `<ws>` = `TOKEN_USAGE_LINEAR_WORKSPACE` 默认 `geoforge3d`。**workspace 也是外部输入（Codex R5）：仅当匹配 `^[A-Za-z0-9-]+$` 才用，否则 warn + 回退 `geoforge3d`**。
- 仅当 issue id 严格匹配 `^[A-Z]+-\d+$` 才包链接（否则纯文本，防注入 / 脏数据）。`href` 仍走 `esc()`。
- `bars()` 行对象加可选 `href`；issue 行传 `linearIssueUrl(id)`，lead 行不传。加 `.sk a` CSS（颜色、无下划线）。
- **text-report 同补 $（Codex R2）**：`render-text.ts` 嵌套 `lead` / `done` 行现在只显 token，补 `formatUsd(cost)`（终端无链接，仅补 $）。
