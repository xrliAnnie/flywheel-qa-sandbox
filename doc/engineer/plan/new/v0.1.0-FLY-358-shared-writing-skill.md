## 0. 目标与节奏

FLY-358 = 一个 **variant-able 写作引擎**：**一套共享 core 做一次、所有内容类型复用** × 每内容类型一个 **variant**。

```
写作引擎 = 共享 core（生成 + 去AI味 + 口味记忆 + craft 护栏） × variant（per-content-type domain pack） × run spec（每次调用的 task/source/mode）
```

- **不 over-build / v0.1 聚焦（Codex #5）**：v0.1 **只实现** = 去AI味 core + craft 护栏 + L1 安全 baseline + variant schema + run spec + 两层 gate + **rewrite/deslop 模式**（拿现成文本去味）+ driver + **synthetic variant example/fixture**。**生成流水线 + memory 读写 = 后续 phase（behind flag / stub，先设计后建）**。架构含全 4 component，v0.1 建聚焦子集 + 留接口。

## 2. 共享 core(4 component;v0.1 建 ②④,①③留接口)

### 2.1 ② 去AI味层 ✅v0.1（A/B 选型落地）
- 主干 **Humanizer-zh**(4.0 满堂彩,中文原生,已含 stop-slop 精华),叠 **anti-slop ban-list**(去"等长短句"硬约束)+ **shuorenhua 场景轴**(体裁×力度,鸡汤自动轻改)+ **humanizer**(EN)+ **新规则:结尾自然收不造金句**。全 MIT。
- 注:**项目特定 gate = caller `gate_cmd`；L1 安全 baseline 机械检查 = skill 自带不可禁 `baseline-lint.sh`**（Codex #9 措辞统一,二者分离,详 §4）。

### 2.2 ④ craft 护栏 ✅v0.1（story-deslop + L1 baseline）
- 借 oh-story `story-deslop`(MIT,只取文本):**分级删除上限**(轻≤15%/中≤25%/重≤35%,**metric = 字符删除比 vs 原文**,Codex #8)+ **`[需复核]` marker**(格式 `[需复核:原因]`,拿不准不删)+ **护专名**(人名/地名/数字/章节名,来源 = variant 可声明 protected_terms + 通用 NER 兜底)+ **语气标点谱系**(避免通篇句号化,治节奏)。**违规处理**:超删除上限 → **block + 报告**；`[需复核]` → **warn + 强制人审**(不静默)。
- **L1 安全 baseline = 全局 baseline + 域分 safety profile(Asha review 关键改动,用 §5.0 留的口子落地)**。**全局禁否定会误杀合法歌词 = Asha catch**,故 positive-only/禁否定**只进 affirmation profile,不进全局**:
  - **全局 baseline(两类都强制,不可删)**:**SP-safe(他/对方泛指)+ 不写艺人名 + lyric≠affirmation 分离**。注:**`不写艺人名` 的机械检查 = `baseline.yaml` 声明的具体艺人名 list/pattern(v0.1,不 overclaim "查所有艺人名")**;项目 gate 可加更强检查(Codex R6-2)。
  - **`affirmation-safe` profile**:严格正向 + **禁否定**(无 不/no/never/without)—— 潜意识层(hidden subliminal)安全。
  - **`lyric-safe` profile**:SP-safe + **无版权文本复用** + 不写艺人名,**允许表达性否定**(歌词是演唱/surface 层、非 subliminal,「不再回头」合法)。
  - variant 经 `safety:[affirmation-safe|lyric-safe]` **opt-in;opt-in 后该 profile 规则不可弱化**(append-only)。全局 baseline 永远施加;**variant 必须声明 `safety` profile,缺则 fail-fast**(fail-closed,不默认裸跑)。详 §3.3/§4。

### 2.3 ① 生成层 🔶后续 phase(v0.1 留接口/stub,Codex #2 #5)
- 借 writing-agent 流水线**架构**(精简,非 573 文件/桌面 app/不接 hook)。**v0.1 不建多阶段生成**,只支持 **rewrite/deslop 模式**(拿现成文本去味)。
- **后续 phase 的最小 run-dir 状态模型(现在定契约,后建)**:`.flywheel/writing/runs/<run-id>/{00-run.json, 01-plan.md, 02-draft.md, 03-review.md, 04-deslopped.md, 05-export.md, events.jsonl}`;`--resume <run-id>` 从最后完成 stage 续;"evidence-tracked" = 各 stage 产物 + events.jsonl 留痕。两个 SUB variant v0.1 只用 `04-deslopped` 一段(rewrite 模式)。

### 2.4 ③ 口味记忆 🔶后续 phase(v0.1 stub,Codex #3 硬化)
- memory-packet 借 writing-agent,但**重做安全**:**v0.1 opt-in / human-approved,默认关**;不从原始稿/任意 review 文本自学。
- **schema + path**:`.flywheel/writing/memory/<caller-id>.yaml`,**只许**字段:`banned_phrases / preferred_rewrites / punctuation_preferences / do_not_store_patterns / updated_at / provenance`。
- **硬护**:写入前**脱敏 denylist**(token/key/email/URL/疑似人名 → 拒存)+ file lock + max size + `--reset/--delete` 命令 + provenance 记来源。**绝不自动写 raw draft**。
- v0.1 = stub(读已批准 memory 当**优先级见 §3.3**,不自动写);写回 = 后续 phase。

## 3. variant + run spec(Codex #1 拆分)

### 3.1 variant.yaml(稳定,per-content-type;= 旧 L2 的稳定部分)
`schema / id / lang / **output_type** / **safety[]** / persona(text|ref) / style / forbidden_words[](append) / few_shot[] / constraints[{rule,why,checked_by_gate}](append) / protected_terms[] / intensity_default / gate_cmd`。**只增不减**叠在全局 baseline + opted-in profile 上。
- **`output_type`(必填,provenance)**:`affirmation | lyric | …`。**lyric≠affirmation 分离按此声明的 output_type 判定,不靠内容启发式**(Asha 确认点 —— provenance-based,driver 不猜)。
- **`safety[]`(必填,fail-fast if missing)**:声明 opt-in 的 safety profile(`affirmation-safe` / `lyric-safe`);opt-in 后不可弱化。全局 baseline 永远另加。
- **`output_type` ↔ `safety` 兼容矩阵(Codex R6-1,v0.1 强制 exactly-one)**:`affirmation → affirmation-safe`,`lyric → lyric-safe`。**不支持的 output_type、不兼容/多个 profile → fail-fast**(防 pack 用 `output_type: affirmation` 配 `lyric-safe` 偷偷重开否定)。profile 组合留待后续 schema 版本定义。

### 3.2 run spec(每次调用,CLI args / 小文件;不进 variant)
`task(generate|rewrite|deslop) / topic / source(file|text) / evidence[] / output{count,format,target} / intensity_override`。driver: **compose run spec ∘ variant ∘ memory ∘ core**。
- **v0.1 只支持 `rewrite/deslop`**(Codex R5-1):`task=generate` 在 schema 里留位,但 v0.1 driver **fail-fast 明确报 "generate 未支持(待 Phase 5)"**,除非显式 experimental flag。

### 3.3 全局优先级不变量(Codex #4 — 关键安全)
渲染/施加优先级(**L1 baseline 永远最后、最高,不可被上层放松**):
```
run spec  <  variant  <  memory  <  de-AI/craft 规则  <  L1 末位不可放松 baseline 块
```
- prompt 里 L1 baseline 块(全局 + variant opt-in 的 profile)**末位**渲染(含 caller output/run-spec 不得末位)。
- **`baseline-lint.sh` profile-aware**:**全局检查(SP-safe/不写艺人名)永远跑**;再按 variant `safety[]` 跑该 profile 的机械可检项 —— **禁否定 grep 只对 `affirmation-safe` 跑,绝不对 `lyric-safe` 跑**(否则误杀合法歌词,Asha catch)。每次 transform/export 后都跑。
- memory 虽"高优先约束",但**低于 de-AI/craft + 远低于 L1 baseline** —— memory 不能放松全局 baseline 或任何 opted-in profile。
- **恶意 fixture**:① 恶意 memory 经 banned_phrases/preferred_rewrites 试放松 baseline → 断言 baseline 仍赢;② affirmation variant 试图去掉 affirmation-safe 或夹否定 → 被挡;③ lyric variant 含表达性否定(`不再回头`)→ **放行**(不被误杀)。

### 3.4 首批 SUB variant(内容 = Asha 域,Codex #6 + Asha review 边界)
- 本 infra PR **只发** `assets/variant.example.yaml` + schema fixtures(synthetic);引擎用 fixture 即可测。
- **真 SUB 肯定语/歌词 pack = Asha 在 `sub` 仓自己开 PR**(或单独 integration PR + Asha 内容 review);infra 不定义其内容语义、不阻塞。
- **歌词 gate 由 Asha 在 sub pack PR 写**(查 无版权文本复用 + 不写艺人名 + SP-safe,**不查否定**)→ **infra 绝不把 lyric variant 的 `gate_cmd` 默认指到 affirmation 的 style-lint**(否则误查否定)。肯定语 variant → affirmation-safe + 其 style-lint;歌词 variant → lyric-safe + Asha 的歌词 gate。两类 `gate_cmd` 各自独立(caller 提供)。
- **依赖(Asha 认领)**:① 歌词 gate = Asha sub PR;② **L1 core PR#47**(Asha 优先推可 merge)= Phase 0「字段对齐+冻 v1」的**前置**(见 §6 Phase 0)。infra 标清依赖,不替 Asha 做。

### 3.5 安全属性(沿用 Asha roundtable + Codex R1-3 + Asha review profile 化)
**域分 safety profile**(全局 baseline 永远施加 + variant opt-in profile 不可弱化,§2.2)/ **`output_type` provenance 定 lyric≠affirmation(非内容启发式)** / variant 缺 `safety`/`output_type` → fail-fast / append-only baseline / prompt 末位不可放松块(HIGH-1)/ 两层 gate(skill 自带 **profile-aware** baseline-lint + caller gate_cmd,HIGH-2;**禁否定只对 affirmation-safe**)/ fail-closed baseline preflight / gate_cmd 退出码分类 / project_root 解析 / ruby+jq 解析 / `codex-with-fallback --cd --output-last-message` / persona text∧ref 互斥+不逃逸 / `<gate_cmd> <abs_draft>` 安全传参。
