## 1. 目标 / 问题

cmux workspace 间歇显示裸 zsh 而非 attach 后的 Lead/Runner 内容。根因：`create_workspace_for_window` 的 `cmux new-workspace --command "tmux attach …"` 在 create 时可能失败（race / 时序），cmux fallback 裸 shell，无重试无校验。FLY-129 修了 watcher/ghost/refresh 但没覆盖 attach 层——本 issue 是 attach 层续集。Annie 反复看不到 Leads，手动 re-attach 每次重启复发。

**永久解（event-driven，不是 polling）**：在 attach 真可能失败的**事件边界**校验并自愈，**FLY-169 不引入任何新的周期性负载**。

> **硬约束（Annie product call，非技术 trade-off）**：Annie 机器最近持续 crash（watchman load spike / reboot），明确**否决新增周期性 polling**。
>
> **约束精确解读（assumption — 已 flag 给 team-lead/Annie，待确认）**：
> - 自愈检测用 **`tmux list-clients`（cheap，tmux-native）**，**不用 `read-screen`**（Annie 具体担心的重负载）。
> - FLY-169 **不把任何 self-heal 放进 `sync_additive`（现有 60s 周期路径）**；self-heal 只在事件边界跑。
> - **现有 FLY-129 watcher 行为（`sync_additive` 的 reconcile/refresh/create/ghost-reap/dedup）不在本 issue scope，保持不动** — 它本就每 60s 跑，删它会破坏 reconcile/dedup，且非 attach 问题。"零额外负载"指 **FLY-169 不新增** 周期扫描，**不是**删除已有 watcher。
> - 若 Annie 本意是"连现有 60s additive 扫描也要砍"，那是独立大改，需另开 issue —— 本 plan 假设否。

## 2. 设计

### 2.1 检测

> **⚠️ SPIKE 修正（2026-05-26，real-cmux E2E）**：原设计的 INTENT 信号"surface title == `tmux attach…`"**错了**。实测：surface title 反映**当前前台进程**，非创建命令——attach 失败/退出后（裸 shell，即 bug 态）title 变成 `~`，**不是** `tmux attach…`。所以"title==attach AND 0-client"两条件在现实中**互斥**（attach 成功时 title 才==attach，但此时 client>0；0-client 时 title 是 `~`）→ 自愈在生产中**永不触发**（静默 no-op）。unit test mock 了 title==attach 故没抓到——正是 Annie 坚持真 E2E 的原因。修正后 spike 9/9 PASS（0→1 client 重 attach）。

**修正后的检测**：

```
受管门控 MANAGED: workspace title == agent window name（wname）
                  — 由 workspace_refs_for(wname) + 仅对 agent window 触发自愈 强制
状态 STATE      : tmux list-clients -t '=<view_session>' 命令成功 AND 行数 == 0
MANAGED AND 0-client → 自愈，send 打到该 workspace 的 selected terminal surface
```

- **STATE 用 `tmux list-clients`**（tmux-native，cheap，不抓屏；0 client = 裸 shell fallback）。
- **安全（不打进 attached Claude prompt）现在仅靠 STATE**：0 client ⟹ 无 tmux client ⟹ surface 不可能在显示 Claude（Claude 跑在 tmux session 里）⟹ surface 是裸 shell，send 安全。+ send 前/send-key 前 TOCTOU recheck + fail-closed。
- **no-hijack 靠 MANAGED 门控**：自愈只对 title==agent-window-name 的 workspace 跑（self_heal 只被 agent window 的事件/sweep 调用）；用户随手开的 workspace title 不匹配 / 在非 agent session → 永不被碰。spike 已验证。
- **send 目标** = `workspace_terminal_surface_ref`（selected terminal surface，无 selected 则 first terminal）；保留 `--surface` 精确性。
- **范围（Annie Q1）= 全部**：`get_tmux_agent_windows` 覆盖 `flywheel`（Leads）+ `runner-*`（Runners + test-slot）。

> **⚠️ 下方 §2.3–§2.4 伪代码早于 spike 修正 + Codex CR R3，已 superseded — 实现脚本为准。** 关键差异：① `surface_intent_attach_ref`（按 surface title 匹配 attach 命令）已删，替换为 **`workspace_terminal_surface_ref`**（取 selected terminal surface）；② 新增 **`surface_looks_like_bare_shell`** read-screen 门（Codex R3 HIGH：0-client 不足以证明 surface 没 attach 到**别的** session 的 Claude；裸 shell 末行以 `% / $ / #` 结尾，attached 末行是 tmux 状态栏）；③ 重 attach 是**单次原子 send**（attach 命令 + 内嵌换行，**无**单独 send-key Enter），杜绝 text→Enter 两次注入间隙（R1+R4 HIGH）。安全三门 + 原子注入：MANAGED（workspace title==agent window）+ STATE（0-client）+ SHELL（bare-shell read-screen，positive prompt-sigil，状态栏开关无关）→ 三门通过后单次原子 send。

### 2.2 事件驱动触发点（核心 — 取代 polling）

watcher 已有的事件机制（`drain_events` 消费 tmux session-hook 写的 `$EVENT_FILE`）就是天然事件边界。自愈挂在这些边界，**不进 `sync_additive` 周期路径**：

| 事件 | 来源 | 自愈动作 | 覆盖场景 |
|------|------|----------|----------|
| **verify-at-create** | `create_workspace_for_window` 末尾 | 创完立刻 verify attach（list-clients），失败有界 retry 重发 | **attach 最常失败点**（create race） |
| **`create` 事件 + workspace 已存在** | `_drain_file` create 分支 rc=0 路径 | `self_heal_one_workspace`（单 workspace verify+heal） | 已存在 workspace 在某 window 重建事件时掉了 attach |
| **`register` 事件**（新 session 出现） | `_drain_file` register 分支 | `self_heal_sweep_session`（只扫该 session 窗口一次） | Lead restart / Runner spawn 重建 session；catch hook 注册前已存在的窗口（race gap） |
| **watcher bootstrap** | `sync_additive_bootstrap`（启动跑一次） | `self_heal_sweep_all`（扫当前所有 agent 窗口一次） | watcher startup / reboot |
| **cmux health recovery**（unhealthy→healthy 转换，R4-#2） | `cmux_health_check_or_die` 置标志 → `watch_loop` 消费一次 | `self_heal_sweep_all`（一次） | **长寿 watcher 内 cmux 重启/恢复**（无 tmux 事件的盲区） |
| **`--once` 手动 rescue（R4-#6）** | `sync_once`（operator 显式触发） | `self_heal_sweep_all`（一次） | operator 手动救援现有 bare-zsh，零 idle 负载 |

**全部一次性、事件触发。idle（无事件）→ FLY-169 零自愈工作。** 符合 Annie"不新增持续负载，只在事件边界检查"。

> **重启路径覆盖**：Lead 重启重建 session → `register` sweep；只重建窗口 → `create`（已存在路径）→ self_heal_one；只是窗口内 Claude 进程重启（session+window 都在）→ surface 仍 attached（client>0），显示重启后 Claude，**非裸 zsh**，无需 heal。cmux 重启分两种：watcher 也随之重启 → bootstrap；watcher 存活 cmux 恢复 → health-recovery sweep（R4-#2）。
>
> **linked-session 已死的 workspace（R4-#3）**：`self_heal_one_workspace` 只管 attach 层（linked session 活着才 heal）。"workspace 存在但 linked session 死"由**现有 `reconcile_existing_workspaces`**（仍在 bootstrap + 现有 60s additive 跑，未改）close + 让 create 重建 → 再触发 verify-at-create。self-heal **不重复** reconcile 逻辑（保持单一职责 + 简单）。
>
> **事件时瞬态不确定（R4-#4，已接受的 tradeoff）**：若某次事件遇到 cmux/JSON rc=2，该 workspace 这次跳过。**不建 pending-heal 队列**（over-engineering）——多重 heal 机会兜底：verify-at-create 自带 retry、health-recovery sweep、bootstrap、现有 reconcile（60s）、下一个 create/register 事件、`--once`。acceptance 定义为"在下一个相关事件/重启内自愈"，对 bare-zsh（几乎只在 create 时发生、且 verify-at-create 同步兜底）足够。

### 2.3 自愈动作（仅 0-client + intent 满足，send 精确到匹配 surface）

```bash
cmux send     --workspace <ref> --surface <intent_surface_ref> "tmux attach -t '=<view_session>'"
cmux send-key --workspace <ref> --surface <intent_surface_ref> Enter
tmux select-window -t "=<view_session>:=<window_name>"   # active window 指向 Lead/Runner 窗口
cmux refresh-surfaces
```

已 attach（client>0）分支：仅 `tmux select-window`（幂等，修 window 0 zsh 误指；不碰 surface 输入）。

### 2.4 核心函数（bash 3.2 兼容，严格沿用 fail-closed / rc=2 约定）

**(A0) `self_heal_workspace_ref <wname> <ref>`** — **ref-scoped** 单 workspace 修复原语（R5-#1）。create 时用已知 `new_ref`（rename 前也能修），event 时由 `self_heal_one_workspace` 解析出的 ref 复用。返回码：`0`=已**尝试** send（best-effort，cmux send 失败不视为错误，R6-#2）；`1`=无 attach-intent surface / 跳过；`2`=检测到 client>0（caller 应停止后续 ref）：

```bash
self_heal_workspace_ref() {
  local wname="$1" ref="$2"
  local view_session="${VIEW_PREFIX}${wname}"
  [[ -z "$ref" ]] && return 1
  # (R1-#1/#5) intent helper returns the MATCHING surface ref for THIS ref.
  local surface_ref
  surface_ref=$(surface_intent_attach_ref "$ref" "$view_session") || return 1
  [[ -z "$surface_ref" ]] && return 1
  # (R1-#4) Final TOCTOU recheck immediately before send.
  local clients
  clients=$(view_session_client_count "$view_session") || return 1   # tmux error → fail-closed skip
  [[ "$clients" -gt 0 ]] && return 2                                  # attached mid-flight → signal stop
  heal_state_log_once "$wname" "Self-heal: re-attaching '$wname' (0 clients on $view_session, ws $ref surface $surface_ref)"
  cmux_call send     --workspace "$ref" --surface "$surface_ref" "tmux attach -t '=${view_session}'" || true
  cmux_call send-key --workspace "$ref" --surface "$surface_ref" Enter || true
  return 0
}
```

**(A) `self_heal_one_workspace <wname>`** — title 解析所有 ref，逐个复用 (A0)。事件驱动调用：

```bash
self_heal_one_workspace() {
  local wname="$1"
  local view_session="${VIEW_PREFIX}${wname}"
  # Need a live linked session to attach to. Dead-session case is
  # reconcile_existing_workspaces' job (close + rebuild), not ours (R4-#3).
  linked_session_exists "$view_session" || return 0

  # (R1-#2) Mutation path uses workspace_refs_for with rc=2 handling,
  # NOT get_workspace_ref_for (explicitly unsafe as a mutation gate).
  local refs rc=0
  refs=$(workspace_refs_for "$wname") || rc=$?
  [[ $rc -eq 2 ]] && return 0          # JSON unavailable → skip (event-time tradeoff, R4-#4)
  [[ -z "$refs" ]] && return 0

  # (R1-#3) STATE: only "tmux succeeded AND count==0" = detached. Per
  # view_session (shared by all dup workspaces for this window name).
  local clients
  clients=$(view_session_client_count "$view_session") || return 0   # tmux error → fail-closed
  if [[ "$clients" -gt 0 ]]; then
    tmux select-window -t "=${view_session}:=${wname}" 2>/dev/null || true   # safe, no surface input
    heal_state_clear "$wname"
    return 0
  fi

  # 0 clients → maybe detached. (R2-#1) Don't guess dedup winner; iterate ALL
  # refs and heal each via the ref-scoped primitive. rc=2 (client appeared
  # mid-loop) → stop sending to remaining refs.
  # (R6-#1) MUST capture rc with `|| hr=$?` — bare `cmd; hr=$?` aborts under
  # the script's `set -euo pipefail` on the deliberate rc=1/2 returns.
  local healed=0 ref hr
  while read -r ref; do
    [[ -z "$ref" ]] && continue
    hr=0
    self_heal_workspace_ref "$wname" "$ref" || hr=$?
    case "$hr" in
      0) healed=1 ;;
      1) ;;          # normal skip (no intent / fail-closed)
      2) break ;;    # client appeared mid-loop → stop sending
      *) log "WARN: unexpected self-heal rc=$hr for $wname ref=$ref" ;;
    esac
  done <<< "$refs"

  if [[ "$healed" -eq 1 ]]; then
    tmux select-window -t "=${view_session}:=${wname}" 2>/dev/null || true
    cmux_call refresh-surfaces || true
  fi
}
```

**(B) `self_heal_sweep_session <session>` / `self_heal_sweep_all`** — 遍历对应 agent 窗口，对每个调 `self_heal_one_workspace`。`_all` 用 `get_tmux_agent_windows`；`_session` 过滤到指定 session：

```bash
self_heal_sweep_all() {
  local tmux_windows; tmux_windows=$(get_tmux_agent_windows)
  [[ -z "$tmux_windows" ]] && return 0
  while IFS='|' read -r _s _wid wname; do
    [[ -z "$wname" ]] && continue
    self_heal_one_workspace "$wname"
  done <<< "$tmux_windows"
}
self_heal_sweep_session() {  # arg: session; sweep only its windows once
  local target="$1" tmux_windows; tmux_windows=$(get_tmux_agent_windows)
  [[ -z "$tmux_windows" ]] && return 0
  while IFS='|' read -r s _wid wname; do
    [[ "$s" == "$target" && -n "$wname" ]] && self_heal_one_workspace "$wname"
  done <<< "$tmux_windows"
}
```

**(C) helpers**：

```bash
# (R1-#3) tmux client count for a view session. rc!=0 on tmux command failure
# (target missing / session raced away) → callers fail closed. Empty output
# = 0 clients = SUCCESS (tmux exits 0 with no lines).
view_session_client_count() {
  local view_session="$1" out
  out=$(tmux list-clients -t "=${view_session}" 2>/dev/null) || return 1
  printf '%s' "$out" | grep -c . || true
}

# (R1-#1/#5) Defensive parse: require object + surfaces list; print ref of the
# FIRST surface whose title is exactly the attach command; rc=1 if none / bad
# JSON, NO stdout, NO Python traceback (fail closed).
surface_intent_attach_ref() {
  local ref="$1" view_session="$2" raw
  raw=$(cmux_call --json list-pane-surfaces --workspace "$ref") || return 1
  printf '%s' "$raw" | python3 -c '
import sys, json
vs = sys.argv[1]
want = "tmux attach -t \x27=" + vs + "\x27"
try:
    data = json.load(sys.stdin)
    surfaces = data.get("surfaces")
    if not isinstance(surfaces, list):
        sys.exit(1)
    for s in surfaces:
        if not isinstance(s, dict):
            continue
        if (s.get("title") or "").strip() == want:
            r = s.get("ref") or s.get("id") or ""
            if r:
                print(r); sys.exit(0)
    sys.exit(1)
except Exception:
    sys.exit(1)
' "$view_session" || return 1
}
```

**heal-state 独立存储（R1-#7）**：**绝不复用 `STALE_STATE`**（它驱动 conservative cleanup，会被 stale-session 路径 drain，混进去会被立即清掉或误读）。新建 `HEAL_STATE="${HEAL_STATE:-/tmp/flywheel-cmux-heal.state}"`，`heal_state_log_once` / `heal_state_clear` 用字面 `awk -F'|'` helper，镜像 `drain_stale_state_row` 写法；watcher 启动时 GC 掉 agent window 已不存在的行。

### 2.5 verify-at-create + retry（核心，create 事件边界）

`create_workspace_for_window` 在 `cmux new-workspace` 成功后加一段**有界** verify+retry。只在 create 时执行（罕见，零持续负载）。

**关键实现点（R4-#5 + R5-#1）**：
- 函数内 local 名是 **`window_name`**（不是 `wname`）；`set -u` 下误用会 abort watcher。
- **必须 ref-scoped，不能 title-scoped（R5-#1）**：刚建的 workspace 只有 `rename-workspace` 成功后才能按 title 找到。`self_heal_one_workspace` 走 `workspace_refs_for`（按 title）→ rename 前会找不到 ref 而静默跳过，破坏主修复路径。因此 create 时用现有逻辑算出的 **`new_ref`**（line 613 的 JSON diff 结果）直接调 **`self_heal_workspace_ref "$window_name" "$new_ref"`** —— 不依赖 rename。
- verify 状态用 **`tmux list-clients`（不依赖 cmux JSON）**。
- 若 post-create JSON 不可用 / `new_ref` 为空 → **不**声称本次同步自愈；log + skip，靠后续事件 / health-recovery / bootstrap / `--once` 兜底（R4-#4 tradeoff）。
- **现有 line ~602 的 post-create JSON 早 return（R6-#3）**：现在它只 log rename 失败；改 log 文案为同时提及 **attach verify 也因 `new_ref` 不可用而 defer**（与本节行为一致），fail-closed return 保留。

```bash
# After computing new_ref (existing line ~613) — BEFORE or independent of rename:
# Verify the attach actually took; cmux falls back to bare zsh on failure.
if [[ -n "$new_ref" ]]; then
  local attempt clients
  for attempt in 1 2 3; do
    clients=$(view_session_client_count "$view_session") || break   # tmux error → stop (fail-closed)
    [[ "$clients" -gt 0 ]] && break                                  # attached — done
    self_heal_workspace_ref "$window_name" "$new_ref" || true        # ref-scoped, rename-independent
    sleep 1
  done
else
  log "WARN: no new_ref post-create for $window_name — attach verify deferred to later event/--once"
fi
```

有界（≤3 次、≤3s），仅在新建一个 workspace 后跑。`self_heal_workspace_ref` 内部已做 intent + 0-client + `--surface` 门控，复用同一安全逻辑。

### 2.5b cmux health-recovery sweep（R4-#2）

长寿 watcher 内 cmux 由 unhealthy 恢复 healthy 时，没有 tmux 事件触发，bootstrap 也不再跑 → bare-zsh 会悬而不决。补一个**恢复事件**钩子（事件驱动，非 idle poll）：

```bash
# Module-level flag, set on the unhealthy→healthy transition inside
# cmux_health_check_or_die's existing state machine (where it already logs recovery).
CMUX_HEAL_ON_RECOVERY="${CMUX_HEAL_ON_RECOVERY:-0}"

# In cmux_health_check_or_die, on transition back to rc=0 from a non-zero state:
#   CMUX_HEAL_ON_RECOVERY=1

# In watch_loop, after a healthy drain_events, consume the flag ONCE:
if [[ "$CMUX_HEAL_ON_RECOVERY" == "1" ]]; then
  CMUX_HEAL_ON_RECOVERY=0
  self_heal_sweep_all
fi
```

只在"恢复"那一次跑，不是每 tick。

### 2.6 方案 3 — create 前 ready 门禁（降低失败率，R1-#6）

`has-session` 单独太弱（只证明 `new-session` 没失败，不证明选对了 agent window）。改为**双门禁**：`cmux new-workspace` 前 require (a) linked session 存在 **且** (b) `tmux select-window` 成功：

```bash
# After step 1 (create linked session), before new-workspace:
if ! linked_session_exists "$view_session" \
   || ! tmux select-window -t "=${view_session}:=${window_name}" 2>/dev/null; then
  log "WARN: $view_session not ready (session/select-window) — deferring create for $window_name"
  return 0   # next create event retries; verify-at-create + bootstrap sweep also cover it
fi
```

## 4. 测试计划

### 4.1 单元测试（`scripts/test-cmux-sync.sh`，bash 3.2 mock）

新增 mock：`MOCK_TMUX_CLIENTS`（`view_session=N`；缺省 = tmux 错误）、`MOCK_TMUX_SELECTS`（捕获 select-window 目标）、`MOCK_CMUX_SURFACES`（per-ref surface JSON，多 surface + title + ref）、`send/send-key/refresh-surfaces` 入 `MOCK_CMUX_OPS`（含 `--surface`）。

用例：
1. **0 client + 单 surface intent==attach** → `MOCK_CMUX_OPS` 含 `send --surface <ref> … tmux attach`、`send-key --surface <ref> … Enter`、`refresh-surfaces` + `select-window` 调用。
2. **client>0（已 attach）** → **不** send，只 select-window。**防误打 Claude prompt 关键回归**。
3. **0 client 但无 intent==attach surface（用户裸 shell）** → 不碰（无 send、无 select-window）。
4. **多 surface，仅一个 title==attach** → send 的 `--surface` 精确等于匹配 ref（R1-#1）。
5. **重复 workspace ref（dup title）** → 遍历所有 ref，对每个 intent ref 各自 send（不猜 dedup winner）。注：survivor-attached 仅适用于 watcher 正常创建的 dup（都是 attach intent）；若某 dup 是手动裸 shell 且被 dedup 保留，自愈正确拒绝碰它（保 no-hijack 优先）。
6. **`list-clients` tmux 报错** → fail-closed，不 send（R1-#3）。
7. **malformed `list-pane-surfaces` JSON** → 不 send、无 traceback（R1-#5）。
8. **TOCTOU：首检 0、send 前 recheck 翻 >0** → 不 send，转 select-window（R1-#4）。
8b. **mid-loop TOCTOU（多 ref）**：两个 intent ref，第一次 send 后 client 翻 >0 → 只 send 第一个，loop break（R3 非阻塞补充）。
9. **linked session 不存在** → skip（交给 reconcile）。
10. **workspace_refs_for rc=2** → skip，不 send。
11. **verify-at-create（ref-scoped，R5-#1）**：新 workspace 有 `new_ref` 但**尚未 rename**、list-clients=0 → verify 仍用 `self_heal_workspace_ref "$window_name" "$new_ref"` send 到 `--workspace $new_ref --surface $surface_ref`（断言不依赖 title 解析）；某次 client>0 → break；`new_ref` 空 → 不 send、log defer。用 `$window_name`（R4-#5）。
12. **create 门禁**：`select-window` 失败 → 不调 `new-workspace`，下事件重试（§2.6, R1-#6）。
13. **事件驱动 wiring**：`_drain_file` 收到 `create|flywheel|@1|X`（workspace 已存在）→ 调 `self_heal_one_workspace X`；收到 `register|flywheel` → 调 `self_heal_sweep_session flywheel`。**断言 `sync_additive`（60s 周期）路径不调用任何 self_heal**（防回归到 polling）。
14. **heal-state**：HEAL_STATE 独立文件；attach 失败转换打一行、恢复清行；启动 GC 删 dead-window 行（R1-#7）。
15. **health-recovery sweep（R4-#2）**：模拟 cmux unhealthy→healthy 转换置 `CMUX_HEAL_ON_RECOVERY=1`；`watch_loop` 一次 healthy tick 后调 `self_heal_sweep_all` **恰一次**并清标志；下一 healthy tick **不再**调（断言非每 tick）。
16. **`--once` rescue（R4-#6）**：`sync_once` 路径调 `self_heal_sweep_all`；存在 bare-zsh workspace → 被 heal。
17. **linked-dead 不在 self-heal scope（R4-#3）**：workspace 存在但 linked session 死 → `self_heal_one_workspace` 早 return（不 send、不 close）；交现有 reconcile（断言 self-heal 不调 close/create）。
18. **errexit 安全（R6-#1，关键）**：在 sourced 脚本 `set -euo pipefail` 仍生效下跑 `self_heal_one_workspace`：第一个 ref 返回 rc=1（normal skip）→ 函数**继续**不 abort；某 ref rc=2 → loop break 而非退出。守 `|| hr=$?` 捕获正确。

### 4.2 Spike（手动 E2E，本机 cmux）

1. 选非 Lead 测试 view session（或临时建 agent window + workspace），`tmux detach`/kill 其 attach client → list-clients 归 0。
2. 触发**事件**（重启 watcher → bootstrap sweep；或制造 register/create 事件），观察 watcher log 打 `Self-heal: re-attaching`，workspace 重 attach、active window 指 agent 窗口、屏幕显示内容。
3. **零持续负载验证**：idle（无事件）观察 watcher，确认无周期性 list-clients/read-screen 扫描（不进 sync_additive）。
4. **误杀防护**：开一个 surface title≠`tmux attach` 的裸 shell workspace，触发事件，确认自愈**不碰它**。

## 5. 风险 / 取舍

- **持续负载 / 机器 crash（Annie 最在意）**：FLY-169 event-driven，**不新增**任何周期扫描。verify-at-create 只在新建 workspace 跑（罕见）；sweep 只在 register/bootstrap/health-recovery/`--once` 事件。**不进 sync_additive 60s 周期路径**。注：现有 FLY-129 additive 扫描（reconcile/dedup）不在本 scope，保持不动（见 §1 约束解读 — 已 flag Annie 确认）。
- **误杀真 session / 打进 Claude prompt**（最大正确性风险）：两信号门控 + `--surface` 精确 + send 前 recheck + fail-closed。单测 2/4/6/7/8 守这条。
- **事件覆盖盲区（R4-#3/#4，已接受 tradeoff）**：(a) hook 注册前建的窗口 → register-sweep + bootstrap 兜底；(b) cmux 长寿 watcher 内恢复 → health-recovery sweep；(c) linked-session 死的 workspace → 现有 reconcile（未改）；(d) 事件时 cmux/JSON rc=2 跳过 → 多重 heal 机会（verify-at-create retry / health-recovery / bootstrap / 现有 reconcile / 下一事件 / `--once`）兜底。acceptance = "下一相关事件/重启内自愈"；**不建 pending-heal 队列**（over-engineering，bare-zsh 几乎只在 create 时发生且 verify-at-create 同步兜底）。
- **verify-at-create 的有界 sleep**：≤3s 阻塞 watcher loop，仅在 create 时。Codex R4(b) 确认可接受（事件 append 到文件，下轮 drain，无锁正确性问题）；不引入后台计时器（bash 3.2 简单优先）。
- **bash 3.2 兼容**：生产 watcher 跑 macOS `/bin/bash` 3.2；verify-at-create 用 `$window_name`（非 `$wname`）防 `set -u` abort（R4-#5）。

## 6. 验收映射

| Acceptance | 满足方式 |
|---|---|
| watcher 重启 / reboot / cmux 恢复后自动 attach（一次 sweep 内） | bootstrap sweep + health-recovery sweep（确定性，非 best-effort）|
| Lead/Runner 重启后自动 attach | register/create 事件 sweep + verify-at-create |
| 事件时 cmux/JSON 瞬态不确定 | **下一个相关事件/重启/`--once` 内自愈**（非"同一 cycle 保证"，R4-#4/R5-#2 已接受 tradeoff）|
| 裸 zsh workspace 被检测 + 自动 re-attach | 两信号门控 + `--surface` send |
| active window 指向 Lead/Runner（非 window 0 zsh） | 自愈含 `select-window`（两分支都做） |
| spike 证明恢复故意 detach 的 workspace | §4.2 spike（含零持续负载验证 + 误杀防护） |
