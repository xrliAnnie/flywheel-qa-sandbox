# Plan: cmux IPC silent failure fix — Production cmux 侧栏不显示 Runner

**Version**: v1.25.0
**Issue**: FLY-129
**Date**: 2026-05-05
**Source**: `doc/engineer/research/new/FLY-129-cmux-ipc-rootcause.md`
**Status**: inprogress — Codex design review APPROVED Round 3; implementation pushed at `feat/v1.25.0-FLY-129-cmux-ipc-fix` commit 3b19f3b; awaiting Codex code review APPROVAL.

## Background (1-line)

Production cmux 侧栏不显示 Runner workspace。cmux app 配置 `socketControlMode = cmuxOnly` → 所有 IPC 请求来自非-cmux-后裔进程（如 reparent 到 PID 1 的 watcher）一律被 silently 拒绝；`cmux-sync.sh` 用 `2>/dev/null` 把真实错误丢了，只剩误导性 "cmux not running?" 警告。详见 root cause doc。

## Goal

让 `flywheel-cmux-sync.sh --watch` 在被 reparent 到 PID 1（或任何非-cmux ancestry）后仍能成功跟 cmux app IPC，并且当 IPC 真的坏了时**大声**报错而不是 silent 重试。失败时尽快释放 autostart 锁让下次 cmux pane 触发的 autostart 能真接管。

## Approach

**Option A + D 组合**（worker-fly-60 W5 已确认接受）：

1. **A — 切换 socket control mode**：cmux app preference `socketControlMode = allowAll`（关掉 caller-PID-validation；socket file mode 同步从 `srw-------` 变为 `srw-rw-rw-`，单用户 dev box 接受）。
2. **D — Watcher 失败时大声报错 + 周期检测**：移除 `cmux ... 2>/dev/null`，改捕获 stderr → log；watcher 启动时 + 周期内（每 4 个 watch tick = 60s）跑 `cmux ping` 自检；分辨「cmux 没启动」(socket 不存在 → wait+retry) vs 「cmux 启动但拒绝 caller」(socket 存在 + access-denied → exit 1) vs 「其他临时故障」(socket 存在 + 非-access-denied 错误 → warn + 继续 retry)。

短期 workaround（已在 production 跑通）：
- `defaults write com.cmuxterm.app socketControlMode -string allowAll`
- 重启 cmux app
- 重启 watcher

## Non-Goals

- ❌ 不引入 launchd agent 管理 watcher（Option C，太大 scope）
- ❌ 不切到 `automation` mode + keychain password（Option B，需要 Annie 在 cmux GUI 手动设密码）
- ❌ 不重写 cmux-sync.sh 的 polling 架构（FLY-102 设计仍然有效）
- ❌ 不清理已有的 garbage workspace（workspace:3 等历史残留 — 让 sync_additive_bootstrap 自然 reconcile）
- ❌ 不把锁从 autostart 移到 sync.sh（仍然用 autostart 当 single-instance gate）
- ✅ **修** `flywheel-cmux-autostart.sh` 让 EXIT trap 真能 fire（不再用 `exec`）

#### Change 1.1 — 把 `log()` 写到 stderr（解决 Codex Issue #1: stdout pipe pollution）

```bash
# Before:
log() { echo "[cmux-sync $(date '+%H:%M:%S')] $*"; }

# After:
log() { echo "[cmux-sync $(date '+%H:%M:%S')] $*" >&2; }
```

理由：autostart 已经 `>> "$LOG" 2>&1`，stderr 仍然落 log file；但通过 stderr 走，pipeline (`cmux_call list-workspaces | sed | awk`) 不会被 log message 污染。

#### Change 1.2 — Add `cmux_health_check()` + `cmux_call()` helpers

放在 `# ── Functions ──` 区域顶部、`log()` 之后：

```bash
# Path of cmux IPC socket. Override via $CMUX_SOCKET_PATH env (cmux's own convention).
CMUX_SOCKET_PATH_DEFAULT="${CMUX_SOCKET_PATH:-/tmp/cmux.sock}"

# FLY-129: Health-check cmux IPC. Distinguish:
#   rc=0  healthy
#   rc=1  cmux not running (socket missing — recoverable, just wait)
#   rc=2  auth-rejected (socket present + Access denied — config issue, fatal)
#   rc=3  other transient error (socket present, non-access-denied — warn, retry)
cmux_health_check() {
  local socket="${CMUX_SOCKET_PATH:-$CMUX_SOCKET_PATH_DEFAULT}"
  if [[ ! -S "$socket" ]]; then
    return 1
  fi
  local err_file out rc=0
  err_file=$(mktemp)
  # Pass --socket explicitly so override env actually reaches cmux CLI.
  out=$(cmux --socket "$socket" ping 2>"$err_file") || rc=$?
  local err_text
  err_text=$(cat "$err_file" 2>/dev/null || true)
  rm -f "$err_file"
  if [[ $rc -eq 0 && "$out" == *PONG* ]]; then
    return 0
  fi
  # Match against combined stdout + stderr: cmux may write the access-denied
  # message to either stream depending on protocol stage.
  if grep -q "Access denied" <<<"${out}${err_text}"; then
    log "ERROR: cmux IPC rejected by app — caller is not a cmux descendant and socketControlMode != allowAll"
    log "ERROR: stderr: ${err_text:-<empty>}"
    log "ERROR: To fix: defaults write com.cmuxterm.app socketControlMode -string allowAll && quit cmux app + relaunch"
    return 2
  fi
  log "WARN: cmux ping failed transiently (rc=$rc, out='${out}', err='${err_text}')"
  return 3
}

# FLY-129: wrap cmux call so stderr goes to log (via stderr, not /dev/null).
# Returns cmux's exit code; **stdout passthrough preserved** for callers in
# pipelines (e.g. `cmux_call list-workspaces | sed`).
# Honors $CMUX_SOCKET_PATH override so health-check + sync ops talk to the
# same socket (Codex Round 2 #5).
cmux_call() {
  local socket="${CMUX_SOCKET_PATH:-$CMUX_SOCKET_PATH_DEFAULT}"
  local err_file rc=0
  err_file=$(mktemp)
  cmux --socket "$socket" "$@" 2>"$err_file" || rc=$?
  if [[ $rc -ne 0 ]]; then
    local err_text
    err_text=$(cat "$err_file" 2>/dev/null || true)
    log "WARN: cmux $1 failed (rc=$rc): ${err_text:-<empty>}"
  fi
  rm -f "$err_file"
  return $rc
}
```

#### Change 1.3 — Watcher 启动 + 周期自检

把 `--watch` case 的 body 移进 `watch_main()` 函数（解决 Codex Issue #3：`local` 不能在 case dispatcher 顶层用），并加周期检测（解决 Issue #2 + #5）：

```bash
# After watch_loop() definition, add:
watch_main() {
  log "Watch mode: event-signaled polling (${CLEANUP_DELAY_SECONDS}s cleanup delay, ${CONSERVATIVE_CLEANUP_SECONDS}s conservative cleanup)"

  # FLY-129: advisory check for socketControlMode
  if command -v defaults >/dev/null 2>&1; then
    local mode
    mode=$(defaults read com.cmuxterm.app socketControlMode 2>/dev/null || echo "unset")
    if [[ "$mode" != "allowAll" ]]; then
      log "WARN: cmux socketControlMode='$mode' (expected: allowAll). If watcher fails: defaults write com.cmuxterm.app socketControlMode -string allowAll && relaunch cmux"
    fi
  fi

  # FLY-129: startup health check. Always register hooks (they're tmux-only,
  # not cmux). Only run cmux-touching operations if health passed.
  register_global_hooks
  register_hooks_on_new_sessions
  if cmux_health_check_or_die; then
    sync_additive_bootstrap
  fi
  watch_loop
}

# FLY-129: helper used both at startup and at the top of every 15s watch_loop tick.
# Returns:
#   0 — healthy (caller can run cmux operations)
#   2 — auth rejected (this function exits 1; never returns)
#   non-zero (1/3) — recoverable; caller should SKIP cmux operations this tick
# Designed for use as a gate: `if cmux_health_check_or_die; then sync_additive; fi`
cmux_health_check_or_die() {
  local rc=0
  cmux_health_check || rc=$?
  case $rc in
    0) return 0 ;;
    1) log "INFO: cmux socket missing — skipping cmux ops this tick (will retry)"; return 1 ;;
    2) log "FATAL: cmux IPC auth rejected — exiting so autostart lock releases for next cmux-pane-spawned watcher"; exit 1 ;;
    3) return 3 ;;  # transient; warn already logged in cmux_health_check
  esac
}
```

Modify `watch_loop()` to gate every tick behind the health check:

```bash
watch_loop() {
  local tick=0
  while true; do
    sleep 15
    tick=$((tick + 1))

    # FLY-129 (R2 codex code-review): gate ALL cmux-touching work behind the
    # health check, every 15s tick. drain_events / process_pending_cleanups
    # CAN call cmux via create_workspace_for_window / cleanup_workspace_for,
    # so we must health-check before letting them run.
    #
    # rc=2 (Access denied / kernel perm-denied) → cmux_health_check_or_die
    # exits 1 → autostart EXIT trap releases the lock.
    # rc=0 → run drain + cleanup; every 4th tick also run sync_additive.
    # rc=1/3 → skip cmux-touching paths this tick. sync_additive on the next
    # healthy tick reconciles by creating any missing workspaces.
    local hc_rc=0
    cmux_health_check_or_die || hc_rc=$?
    if [[ $hc_rc -eq 0 ]]; then
      drain_events
      process_pending_cleanups
      if (( tick % 4 == 0 )); then
        sync_additive
      fi
    fi
  done
}
```

### File 2: `scripts/flywheel-cmux-autostart.sh` (Codex Issue #4: lock release)

把 `exec` 改成 wait-and-exit so EXIT trap fires when sync exits:

```bash
# Before (line 37):
exec "$SYNC_SCRIPT" --watch >> "$LOG" 2>&1

# After:
"$SYNC_SCRIPT" --watch >> "$LOG" 2>&1
exit_code=$?
exit "$exit_code"
```

Trap on EXIT (line 19) already cleans up lock. With `exec`, trap doesn't fire (shell replaced); without `exec`, trap runs after sync exits → lock cleaned → next cmux pane's autostart can spawn fresh watcher.

Tradeoff: 1 extra long-running bash process per host (the autostart wrapper). Acceptable.

# Helper: spawn a python Unix-socket listener (creates the socket file).
# Echoes the PID on stdout. Caller is responsible for kill + wait + rm.
#
# Codex Round 2 #1: redirect python stdout/stderr away from the command-
# substitution capture pipe; otherwise the long-running background process
# inherits that pipe and blocks `pid=$(_spawn_unix_socket ...)` from
# returning. Use socket-file polling for readiness instead of stdout
# signalling.
_spawn_unix_socket() {
  local path="$1"
  python3 - "$path" >/dev/null 2>&1 <<'PY' &
import socket, sys, time
s = socket.socket(socket.AF_UNIX)
s.bind(sys.argv[1])
s.listen(1)
time.sleep(60)
PY
  local pid=$!
  local deadline=$((SECONDS + 5))
  while [[ ! -S "$path" && $SECONDS -lt $deadline ]]; do
    sleep 0.05
  done
  if [[ ! -S "$path" ]]; then
    kill "$pid" 2>/dev/null || true
    wait "$pid" 2>/dev/null || true
    return 1
  fi
  echo "$pid"
}

_kill_unix_socket() {
  local pid="$1" path="$2"
  kill "$pid" 2>/dev/null || true

  rm -f "$path"
}
